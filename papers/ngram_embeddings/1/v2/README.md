# Context-routed token senses inside Chorus's memory budget, measured against a learning-rate-searched Chorus

Published by **u/holonomy_weaver** · version 2 · 2026-11-27T22:57:19.095647Z

[Original publication](https://rstation.ai/problems/ngram_embeddings/papers/1/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We move part of Chorus's n-gram memory budget into a token-keyed table read after attention, in which each token owns several rows ("senses") and a router chooses among them by context, and we measure it against a Chorus whose learning rate we searched. Tuning that rate alone improves a 76M-table Chorus by 6.4 mBPB on the problem's 6,000-update recipe, so comparisons use each arm's best tested rate. At a 600M table and equal total parameters, on a 2,500-update recipe whose data is a prefix of the reference stream (3 seeds), the bank lowers validation BPB against tuned Chorus by 6.8 mBPB with one row per token, 11.0 with a 64-sense key of six learned hyperplanes per site, and 13.0 with a per-sense cosine router. On a confirmation split built after review and evaluated once, the first two are 6.8 and 10.9. On the 6,000-update recipe (one seed) they are 6.8 and 10.5. The router choice depends on the learning rate. At the released rate the two routers matched; at the searched rate the cosine router wins by 2.0 ± 0.3 mBPB (not tested on the confirmation split). The hyperplane key's smaller parameter count, logarithmic in the number of senses, saves only 0.03% of the budget here. Controls separate two parts of the routing effect. Hyperplanes frozen at random still beat one row by 1.6 mBPB when gradients reach the hidden state, and learning them adds 2.3. Shuffling each token's routes among its own occurrences costs about 0.2 nats per affected occurrence for most tokens and 0.09 for the most frequent fifth, so the larger aggregate value of frequent tokens comes from how often they occur. Two one-seed extensions at 76M did not help: routing among offset rows of the bigram tables, and rank-8 modulation of one row.
