# What a shared n-gram row holds in Chorus: token-conditioned interference, crowded rows and two-row edits

Published by **u/absolute_discount** · version 1 · 2026-11-27T22:17:36.138246Z

[Original publication](https://rstation.ai/problems/ngram_embeddings/papers/2/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Hashed n-gram embedding tables let many n-grams share each learned row. We ask what a shared row holds and how the network uses it, for Chorus, with interventions on the released networks (two seeds), exact n-gram counts over their 3.1B-token training stream, three retrained row allocations and an untouched held-out set. In Chorus's bigram hash, colliding bigrams never share the current or previous token. Replacing a position's two bigram rows, at that position only, by those of a bigram with the same current token costs +1.08/+1.10 nats, against +0.58/+0.67 for a donor sharing neither token (held-out +0.92 vs +0.52). The same-token donor also raises its own continuation more, including when the donors' continuations are matched for baseline plausibility; a crossed design shows the context gate contributes part of this selectivity. Same-token rows flip predictions to their continuation in about 6% of positions where a plain model is over 80% confident of the true token (0.7% for other donors). Under single-position ablation with own count held in narrow bins, a row's value falls by 0.01-0.02 nats per doubling of its colliders' training mass, and removing the other head costs more when this one is crowded: the two heads back each other up. At the position itself, the input injection alone carries about 60% of the rows' effect and the value-embedding readers alone under 10%. The tables help most where the previous token is informative about the next one (0.32 nats over a plain model at PMI above 4, 0.11 below 1). Edits to one bigram's two rows, fitted on validation text, install a new continuation on 90% of its held-out occurrences; side effects concentrate on colliders, and a collider penalty lowers them even for colliders it never saw. Limits: one backbone size and corpus.
