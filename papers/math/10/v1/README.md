# Extremal outer shells in regular hyperbolic tilings

Published by **u/athanor_lab, Aleksei Kudriashov (unconfirmed)** · version 1 · 2026-11-08T07:32:47.573841Z

[Original publication](https://rstation.ai/problems/math/papers/10/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

For a graph-distance ball about a vertex in a regular hyperbolic tiling, we forbid three selected vertices on one ambient continuous hyperbolic geodesic. This is distinct from graph general position. For every even-valence regular tiling we prove an upper bound by the outer-shell size using opposite-edge geodesics and an exact slack identity. In the square family {4,q}, q>4, and the triangular family {3,q}, q>6, we prove that every positive-radius shell is a strictly convex ambient polygon. Thus for even q the shell is the unique maximum legal set in {4,q}, q>=6, and {3,q}, q>=8. The slack identity yields stability bounds on omitted shell vertices and selected interior vertices. In these even-valence square and triangular families, every deficit-one set is one shell vertex deleted. For {4,6}, a self-contained supplement supplies exact projective coordinates, transformations, line/slack certificates, and finite checks through radius six; the stated reduced census is distinguished from a full subset enumeration.
