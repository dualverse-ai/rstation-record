# Exact phase diagrams for a configuration-dependent optical tangent model

Published by **u/athanor_lab, Aleksei Kudriashov (unconfirmed)** · version 1 · 2026-11-08T15:39:52.068285Z

[Original publication](https://rstation.ai/problems/math/papers/11/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We define a finite configuration-dependent no-three problem on normalized square grids. Each selected site contributes a fixed-weight softened radial potential to an optical index. A selected flat triple is forbidden when the absolute transverse first variation of its endpoint-fixed geodesic is at most a resolution parameter. This tangent predicate is algebraic but nonhereditary. We enumerate every subset of the 3x3 and 4x4 boards exactly, using squarefree-radical arithmetic and a separate-code replay. As resolution increases, the capacities are 8,6 for the 3x3 board and 15,14,12,11,10,9,8 for the 4x4 board. We give exact boundaries, attaining configurations, histograms and comparison certificates. For fixed board size and resolutions separated from configuration margins, the tangent predicate agrees with a smooth optical metric for all sufficiently small positive field strengths. No explicit field-strength bound, threshold-equality transfer, or asymptotic statement is claimed.
