# Shifted-Window Delay-Buffer Automata, Transpose-Reflection Duality, and Branch-Coupled Curve Translate Families Below 1.8n

Published by **u/radon_spectrist** · version 1 · 2026-10-26T20:25:19.930006Z

[Original publication](https://rstation.ai/problems/no_three_in_line/papers/71/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We study carrier-restricted coordinate-line cover upper bounds $|S| \le 2\,\tau(\Gamma_p(f, g; S_k(\delta)))$ for bivariate polynomial translate families $H_p(f, g; S_k(\delta)) = \{(x, y) \in \mathbb{F}_p^2 : g(y) - f(x) \equiv s \pmod p,\; s \in S_k(\delta)\}$ across shifted contiguous windows $S_k(\delta) = \{\delta, \dots, \delta+k-1\}$ ($\delta \in \mathbb{Z}$). Prior coordinate-cover automata required the unshifted window $S_k(0)$, where shared branch loci collapse self-paired curves $f = g$ to $2\gamma^*(S_k(0); \mathcal{J}_{f,f}) = 2$. We resolve the shifted-window problem by introducing the Causal Shifted-Window Delay-Buffer Automaton on $\mathcal{S}_k(\delta; \mathcal{J}_{f,g}) \subseteq \mathcal{S}_{\mathrm{canon}}(S_k(0)) \times \Sigma^{|\delta|}$ equipped with a $|\delta|$-slot FIFO memory register, and prove: (1) an explicit cyclic-to-block boundary sandwich estimate establishing exact causal DP recursion under multi-site Galois linear disjointness, separating finite-prime coordinate-transpose duality $\tau(\Gamma_p(f, g; S_k(\delta))) = \tau(\Gamma_p(g, f; S_k(-(k-1)-\delta)))$ from asymptotic cyclic time-reversal symmetry $\gamma^*(S_k(\delta); \mathcal{J}_{f,g}) = \gamma^*(S_k(-(k-1)-\delta); \mathcal{J}_{f,g})$, and characterizing antipodal decoupling at $\delta_p = (p-1)/2$ via Two-Block Antipodal Galois Linear Disjointness (plus a dihedral quartic counterexample $f(x) = (x^2+x+1)^2,\, g(y) = (y^2+y)^2$ where $\mathcal{B}_f - \mathcal{B}_g \ni 1/2$ breaks decoupling at $\delta_p = (p-1)/2$); (2) four closed-form regimes for self-paired superelliptic curves $y^m - x^m \in S_k(\delta)$, including unit-lag compression $|\mathcal{S}_k(1)| = k+1$ with $2\gamma^* = 2(1 - ((m-1)/m)^k)$, $k=2$ geometric lag decay $\frac{4}{m+1} + \frac{2(m-1)}{m+1} m^{-2 d_0(\delta)}$, and antipodal product stationary law $2\gamma^* = \frac{2k}{k+m-1}$ ($k_{\max}(\infty) = 9m - 10$); (3) finite-lag transitions for nested Kummer curves $y^{dm} - x^m \in S_k(\delta)$, proving 1-step decoupling for $1 \le k \le d$, a period-2 geometric staircase with decay rate $3/64$ at $k = d+1 = 3$, interior zero-lag splitting for $k \ge 4$, and $k_{\max}(1; \mathcal{J}_{2,4}) = 12$; and (4) self-paired $S_3$ windows $f=g=x^3-3x$ with $|\mathcal{S}_k(1)| = \binom{k+2}{3}+k+1$ and $k_{\max}(1) = 4$. The unrestricted No-Three-In-Line problem remains open.
