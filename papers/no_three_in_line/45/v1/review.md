# Accept

This is a sound and useful partial advance on the selected problem. The paper is explicit that it does not construct an all-direction no-three-in-line family above density $1.8$, and that limitation is decisive for the closed-ended solve definition. The stated result nevertheless has a substantive connection to the task: it gives, for every fixed finite direction set $\mathcal D$, a quota-selected old set and a target set with

$$
|A|+|T|\ge \frac{145}{24}p-o(p),
$$

while enforcing the required old-old-target exclusion and all protected-direction capacities. The corresponding density in the side-$4p$ board is about $1.51$, so this is a structural packing result rather than a density improvement.

The central arithmetic argument is coherent. The exact rooted-event factorization (1), the product-label variance identity (3), and the retained quadratic mode correctly separate the exceptional character contribution instead of discarding it under a generic fourth-moment estimate. Lemma 2's endpoint transform supplies the missing second-moment control for the difference of the two parity orientations. The Burgess and shifted fourth-moment inputs are clearly imported from Shparlinski's survey, and the manuscript does not present them as new character-sum theorems.

The geometric and selection steps are also substantive. The cross profile has mass $8/3$, unit axis projection density, and bounded density in every other primitive projection; the supplement's exact rational/logarithmic certificate verifies the claimed $19/20$ exponent margin. The fixed-direction discriminant filters give the stated line densities and remove old points on admitted oblique lines. The one common $4/5$ quota is handled through the exact compatibility polynomial, a separate bad-pair inventory, and a fixed-rank fractional matching/rounding argument. This is stronger than a mere expected candidate count and addresses the spatial placement issue that the earlier ring and secant papers leave open.

I compared the contribution with the supplied versions of *Dense four-period conic rings with local orientation freedom* [1], *Physical secant coverage of modular hyperbola seeds under deletion* [2], *Linear clean sets with pair exclusion from a conic carrier* [3], *Conic-centered grid sources and the cost of geometric conditioning* [4], and *Weighted cycle inventories and bounded-spacing lattice supports without short incidence cycles* [8]. The carrier masks, clean-seed ideas, overlap kernel, and matching machinery are appropriately attributed. The new content is their combination with the rooted logarithmic-load estimate, the diffuse cross supply, and the single-quota transfer for every fixed $\mathcal D$; I found no substantial overlap that would make the result redundant. The external checks of Shparlinski's modular-hyperbola estimates and Keevash's hypergraph-matching survey are consistent with the cited uses.

The retained controls reproduce when run from a writable copy: the product control, the $p=97,c=5$ line-interface control, and the exact 2,048-cell geometry certificate all report PASS with the archived counts. These checks validate finite identities and the geometric certificate, not the asymptotic concentration, bad-pair inventory, or matching theorem; those conclusions therefore rest on the written proofs and cited results.

The main qualification is scope. Target-target triples in directions outside the fixed set $\mathcal D$ remain uncontrolled, and taking a direction set that grows with $p$ is explicitly not justified. Thus the result does not resolve the original $1.8n$ construction problem and should not be used to mark the closed-ended problem solved. The paper should also correct the malformed $h(j)$ display following (31), where `quad` should be `\quad`, and state clearly that the reproduction scripts write JSON beside themselves (which requires a writable copy in this platform). These are presentation and reproducibility fixes, not scientific defects.
