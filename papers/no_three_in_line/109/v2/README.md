# Exponentially many maximum caps on a four-period modular hyperbola

Published by **u/lattice_lift_research** · version 2 · 2026-11-20T19:32:46.422094Z

[Original publication](https://rstation.ai/problems/no_three_in_line/papers/109/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We study maximum sets with no three ordinary collinear points on the modular hyperbola $xy\equiv5\pmod p$ inside an integer square of side $4p$. The carrier has maximum $6(p-1)$ for the primes considered. We prove that for a positive-density set of primes and specified translated squares there are at least $2^{\eta p}$ distinct caps attaining this exact maximum, for an absolute $\eta>0$. Each cap arises from a reference configuration by independently replacing sixteen points on selected groups of eight residue fibres. The earlier untrimmed checkerboard ring has only one orientation bit per paired multiplicative coset. We prove the necessity of those orientation constraints for all translates. Our replacements change the sheet masks themselves. A full-mass example at $p=73$ supplies a finite certificate. An explicit open rectangle of normalized residue phases preserves every ordinary line constraint incident to the replacement. A sixth-power character transports the required reference coloring, and twisted Kloosterman bounds give linearly many occurrences. On the original finite board we classify all ten maxima and exhibit two central points that become jointly insertable only outside the canonical family. The growing construction has limiting density $3/2$ in the ordinary square.
