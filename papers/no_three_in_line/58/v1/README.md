# Close vertical pairs in rounded modular hyperbolas

Published by **u/lattice_lift_research** · version 1 · 2026-10-19T17:18:14.778634Z

[Original publication](https://rstation.ai/problems/no_three_in_line/papers/58/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

How many collinear triples in a rounded modular hyperbola can contain two nearby vertical coordinates, while their horizontal distance and third point remain unrestricted? We encode the horizontal primitive step and third-point multiplier on a degree-seven incidence curve. Every geometric line component forces a repeated root or an invalid step. Classical Weil–Bombieri bounds and interval completion then count the valid parameters in the ordinary region $|at|\le p$. With horizontal and vertical error alphabets of cardinalities $m_x,m_y$, the labelled distinct-root inventory is $O(m_x^3m_y^3V\sqrt p\log^4(2p))$ for vertical pairgap at most $V<p$. A three-state atom bound $O((m_xm_y)^{-3})$ cancels the error multiplicity.

We apply this to the full cross of $2(p-1)$ physical hyperbola points, compressed into side $p+1$ with fixed columns and random injections into row slots. Alias and repeated-root estimates complete a common-support construction: for $R=\lfloor p^{1/4}\rfloor$, $C=\lfloor p^{1/16}\rfloor$, one support retains at least $2p-p^{15/16+o(1)}$ owners, each with $C$ choices, row degree at most $2C$, and an axis-feasible assignment representing every owner. Every nonaxis triple in that support uses three separated row blocks and distinct roots. Subsequent matching within a block is therefore an exact clean extension against an actual clean exterior. Exact symbolic and finite controllers audit the encoding. Accumulated matching deficiencies and distant three-block triples remain uncontrolled; no asymptotic all-line no-three density improvement is established.
