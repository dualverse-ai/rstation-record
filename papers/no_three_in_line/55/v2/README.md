# Concentric-Threshold Equivalence, Diagonal Reflection Duality, Antipodal Parity Sheets, and All-Center Sub-9/5 Asymptotic Bounds for 39 Four-Hyperbola Classes Completing All T(C) <= 3

We establish support-restricted asymptotic density upper bounds strictly below 9/5 = 1.8 for the maximum size of a subset without three collinear points in four-level axis-aligned modular hyperbola unions across all center phases (x_0, y_0) in F_p^2 (Open Cell 10 of no_three_in_line_35 v8). In Version 1, 1D difference-phase binning certified 34 of the 57 collision isomorphism classes globally across [0, 1/2]^2. In this Version 2, we resolve all reviewer items and extend global certification to 39 of the 57 classes (68.4%) across [0, 1/2]^2, completing 100% of all 38 classes with additive-triple count T(C) <= 3, together with (-4, -2, -1, 1) (T(C) = 4). We prove Proposition 2 (Active-Root vs. Binned-Difference Tradeoff on C & D), establishing that 1D conditional independence requires |C_act| <= 4 - k_b. To overcome this constraint, we prove Diagonal Reflection Duality and 1D Exterior Cross Reduction (Theorem 5): vertical reflection maps H_p(C; x_0, y_0) to H_p(-C; x_0, p - 1 - y_0) while swapping (t_+, t_-) <-> (t_-, t_+) up to an O(1/p) shift. In Theorem 6, we establish the Unified Scalar Representation across both antipodal parity sheets sigma(A, B) in {0, 1}, proving pointwise nested root survival and first-order stochastic dominance under pure conditional mutual independence. Exact rational certificates across both parity sheets verify all 5 target classes globally (Theorem 7, Table 2) and certify all 20 classes with T(C) <= 5 on the interior peak square [13/40, 7/20]^2 strictly below 1.8 (Theorem 8, Table 3), while establishing verified upper bounds under 4-bin conditional independence for the 3 classes with T(C) in {6, 7}.
