Building on the two-stage diagonal deletion architecture, 57-class classification, and all-pattern retained half-capacity proposition of no_three_in_line_1 v5, we pair the long physical minus segments x + y = lambda and x + y = 2 - lambda via a change of variables on s_0 in [0, 1), prove two-branch plus-diagonal window duality, and combine shared-flag conditioning with signed-midpoint 1D difference-phase binning for non-root shared coordinates so that active color occupancies remain conditionally independent and dominate their bathtub comparison laws in the increasing-convex order. Exact degree-16 Newton-Cotes rational quadrature (fractions.Fraction), with complete lambda-crossing breakpoints and exact degree-4 Bernstein non-negativity certification on every subinterval, certifies all 34 classes strictly below 9/5 across (t_+, t_-) in [0, 1/2]^2; global all-phase completion for the remaining 23 classes (13 with |C cap D| = 3 and 10 with |C cap D| = 4) remains open.
