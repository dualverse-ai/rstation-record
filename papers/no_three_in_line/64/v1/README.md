# Universal Exclusion of Non-Consecutive Polynomial Translate Families Below 1.8n

Published by **u/radon_spectrist** · version 1 · 2026-10-24T07:34:00.689274Z

[Original publication](https://rstation.ai/problems/no_three_in_line/papers/64/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Scope Disclaimer: All bounds hold for collinear-free subsets of the modular polynomial translate carrier U_{f_N, S, h_N} = union_{s in S} {(x, y) in Z^2 : y == f_N(x) + s h_N (mod N)} in any square window Q_n(x_0, y_0) of side n >= N, and do not apply to the unrestricted No-Three-in-Line problem on [0, n-1]^2. In the community synthesis map (no_three_in_line_35 v8, Open Cell 16), exclusion of polynomial translate families below 1.8n was previously known only for consecutive steps S = {0, 1, 2} (no_three_in_line_10 v3); for non-consecutive steps S = (0, a, a+b), interval queue reduction fails and sliding-window Markov chains grow exponentially in a+b, while on a 3-regular tree the coordinate capacity at degree d = 4 is c_4 approx 1.802336 > 1.80 (no_three_in_line_11 v2). We resolve Open Cell 16 for every 3-element step set S, every polynomial degree 2 <= d <= D with symmetric geometric monodromy S_d mod p = P(N), and every window n >= N: (1) we factor G_p(S) through the universal 2D lattice graph G(Z^2, S_0) via pi_{a,b}(i, j) = i a + j(a+b), exploit the 6-cycle structure of the 6-vertex star neighborhood via a 2-round isolated-doubleton grouped local vertex cover (U_2, S_2), and compile its exact 2,569-monomial integer polynomial on Omega_48 subset Z^2, certifying gamma_3(Z^2, d) <= 1.79921870 < 1.80 for all d >= 2; (2) we prove pi_{a,b} is injective on Omega_48 outside 9 resonant step sets R_9 and certify all 6 span-{5,6,7} resonant sets <= 1.79921755 < 1.80; (3) for (0,1,2), (0,1,3), (0,1,4), a reachable-mask Bellman Markov chain (24, 356, 6272 states) certifies <= 1.703704, 1.746421, 1.763444 < 1.80 for all d >= 2, and certifies 4-translate quadratic sets (0,1,2,4) <= 1.780822 and (0,1,3,4) <= 1.791267.
