# Exact Phase Polynomials and Multi-Period Envelopes for Three Axis-Aligned Hyperbola Levels, Support-Restricted Bellman Sub-Chains, and Five- to Nine-Translate Polynomial Carrier Exclusions Below 1.8n

All results are support-restricted exclusion bounds for structured algebraic and modular families, leaving unrestricted No-Three-In-Line open. First, for r = 3 distinct nonzero axis-aligned hyperbola levels at lambda = 1, diagonal deletion yields the exact degree-4 phase polynomial c_3(t) = 23/16 + (3/8)t^2 - t^3 + (3/4)t^4 with c_3'(t) = 3t(t - 1/2)^2 >= 0, bounded by 93/64 = 1.453125 < 3/2 uniformly across all torus phases. On multi-period diagonals 1 <= L <= 2, conditioning on split-level counts proves E[min(K_tot/2, 2)] = (r/2^r)L + 2(1 - (r+1)/2^r) is strictly phase-independent for fixed r >= 2. Due to center shifts, the two diagonal directions have window-dependent phases t_+ = dist(A - B, Z) and t_-(lambda) = dist(A + B - lambda, Z). For r = 3, the worst-phase envelope certifies sub-3/2 exclusion up to lambda = 29/28 and sub-1.80 exclusion up to lambda = 33/25 across all phases, extending to lambda = 4/3 when either directional phase aligns. Second, for polynomial translates, we establish the finite-block telescoping inequality with terminal-potential span bound and whole-block transfer under ordered limits. For consecutive 5-translates, alternating monodromy A_5^+ crosses 1.80 in (8/7, 7/6): certified below 1.80 for c <= 8/7 and exceeding 1.80 at c = 7/6. Support-restricted Bellman sub-chains classify all non-consecutive span-5 step sets at c = 2 for single-twist Dickson D_(1,5), composite two-twist Dickson D_(3,5), and Kummer C_3, while sandwiching exact rational values of the published 1D queue on consecutive translates to establish sharp horizons k = 8 for D_(1,5) and k = 9 for C_3.
