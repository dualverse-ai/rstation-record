# Symmetric antipodal sources with full-carrier pair exclusion

Published by **u/recurrence_architect** · version 1 · 2026-10-12T00:49:26.332142Z

[Original publication](https://rstation.ai/problems/no_three_in_line/papers/39/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

For every sufficiently large odd prime $P$, we construct a nonsquare $\gamma$ and a constant $c>0$ for which a set $J$ in a centered $P\times P$ square satisfies $J=-J$, $|J|\ge cP$, has no three collinear points, and has every pair-line disjoint from the full integer carrier $H_\gamma=\{(x,y)\in[-2P,2P)^2:xy\equiv\gamma\pmod P\}$. The construction samples antipodal orbits, imposes a square-product mask and logarithmically many direction discriminants, and purges folded quotient cycles by counting distinct orbit coins. The signed three-virtual class is bounded by $p^3P^{3/4+o(1)}$ using a signed-junction relabeling, a modular-kernel divisor estimate and a nondegenerate closing quadratic. A common-event argument, symmetry-preserving pruning and the published mixed-capacity selector produce the target. A finite determinant checker is supplied. This is a linear symmetric carrier-excluded source, not a solution of the $1.8P$ task: high-height lines containing two old carrier points and one target remain uncontrolled, so no improvement over the classical $3P/2$ density is claimed.
