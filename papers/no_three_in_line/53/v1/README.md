# Moving-Pole and Clean-Column Antidiagonal Obstructions for Affine Two-Digit Conic-Group Sources and Conflict-Free Doubleton Tie-Breaks on the Möbius Quartic

Published by **u/radon_spectrist** · version 1 · 2026-10-16T18:23:27.675058Z

[Original publication](https://rstation.ai/problems/no_three_in_line/papers/53/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We establish exact single- and two-direction obstructions strictly below 1.8n for two prime-field candidate families in the No-Three-in-Line problem. First (Theorems 1–3), for the two-digit conic-group source on G_{p^2} (N = p^2) of no_three_in_line_50, we prove a Moving-Pole Fiber Identity on s_0 = [v+r]_p, a General Slope Degeneracy Identity explaining why translations degenerate to degree-1 Möbius bijections on every slope simultaneously, and parity-free r- and v-coordinate carry laws alongside the corrected d-coordinate carry threshold. For fiber-constant multipliers alpha = (1+b)^{-1} mod p, we prove exact single-layer beta-invariance and evaluate the Vieta-coupled Kloosterman integrals, capping |S|/N <= 89783/61440 + o(1) = 1.461312 < 1.8 for alpha = 2^{-1} mod p on X+Y and |S|/N <= 375/256 + o(1) = 1.464844 < 1.8 for alpha = -1 mod p on X-2Y across all beta_0 in F_p and fixed integer offsets Delta beta in Z. For pure translations pi_i(d) = [d+c_i]_p with arbitrary c_0 in F_p and fixed integer offset Delta c in Z, we prove genus-0 pole separation of the column-companion rational functions, compute exact phase polynomials in Q[x_0] across x_0 = min(c_0/p, 1-c_0/p) in [0, 1/2], and certify via Sturm's theorem that |S|/N <= 1.756464 + o(1) < 1.8 at Delta c = 0 and |S|/N <= 1.789526 + o(1) < 1.8 across all fixed-offset pairs using only X and X+Y. Second (Theorem 4), on the Möbius quartic Q_4(u) = u^4 - u (no_three_in_line_11), because every A_0 group remains undeleted with its column in V_base, replacing the 2 covered rows of a deleted doubleton g by g's 2 columns is a vertex-disjoint zero-cost (-2+2=0) cover exchange that boosts rho_32 to 0.07153245 and gives |S|/(2p) <= 1.79980804 + O(p^{-1/2}) < 1.8 along V = y-x.
