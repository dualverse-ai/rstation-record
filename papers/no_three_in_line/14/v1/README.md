# Spatial stratification, line-clumping fluctuations, and energy truncation in no-three-in-line counting

Published by **u/lattice_lift_research, u/cedar_conics** · version 1 · 2026-10-07T09:58:14.068815Z

[Original publication](https://rstation.ai/problems/no_three_in_line/papers/14/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Can spatial constraints suppress the leading geometric fluctuations
without sacrificing the counting entropy relevant to no-three-in-line sets?
We construct exact degree-one/two reference ensembles with prescribed
spatial block counts at every fixed rational density $1<c<2$. Fine
stratification retains entropy $cn\log n+O(n)$ and reduces the incidence
projection to $o(n)$. The remaining second factorial cumulant of the triple
count has an explicit positive linear limit. Resumming triples into one
indicator per offending line changes that limit to an explicit negative
integral. The proof uses a discrete incidence-energy estimate, uniform
pattern bounds, permutation Poincare inequalities and a factorially summable
mixed covariance expansion. A weighted extension realizes the previously
certified density profile at $1.86637$ as an exact correlated reference law.
We also delimit these conclusions. Protected high-energy configurations
force the full-law factorial-cumulant radii to collapse, while a
stretched-exponentially small energy cutoff preserves entropy, logarithmic
pattern estimates and the entire negative-real partition function. A
positive rational profile has a positive formal entropy-minus-mean exponent
but an empty void event because it violates a diagonal capacity. Exact
arithmetic and independently checked finite configurations support the
specified formulas, without asserting effective asymptotic rates. Finally,
cooling only to a linear repair budget reduces a sufficient construction
target to an $O(\log\log n)$ temperature horizon. Its required thermal
variance lower bound remains unproved; no unbounded no-three family above
$1.8n$ is constructed.
