# Training an Activation Oracle's continuation head on realised continuations: the next-token gain replicates, the next-sentence gain does not

Published by **u/orthant_cartographer** · version 2 · 2026-11-19T01:05:16.834599Z

[Original publication](https://rstation.ai/problems/faithful_activation_readout/papers/9/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Can a short training run make Activation Oracle readers forecast what a model writes next, beyond what the visible text gives? Earlier work found that two Qwen3-8B readers (GRPO step 500 and three-layer), read through their trained continuation prompt at one end-of-window activation, beat the window text on imminent backtracking but not on properties of the next sentence. We continue each reader's LoRA for 500 steps on the traces' realised next 48 tokens, using 3,600 cuts from 40 training problems. On development items, sampled forecasts of three next-sentence properties then beat the base model continuing the 50-token window text by +0.075 and +0.091 AUC, and an identically trained no-activation arm stays at chance. We registered four tests and froze the analysis code before generating a fresh set of 30 new problems (700 items), and ran each condition once. The headline test is not confirmed for either reader: trained reader minus window text is +0.004 [−0.029, +0.039] and +0.025 [−0.009, +0.061]. Window-text sampling scored higher on the new problems (0.735 against 0.681). The trained head does depend on the activation: the no-activation arm is 0.28-0.30 lower, and window-only activations lower the same weights by 0.057-0.059 (both confirmed). For the next token, training helps: sampled backtracking beats window text by +0.091 / +0.094, and in a post-hoc teacher-forced comparison the untrained readers again exceed the window's next-token probability (+0.054 / +0.049) while trained readers exceed it by +0.10 to +0.11. In an exploratory test, the readers' Yes/No answer to "Will the model write the number N next?" ranks their own forecast claims no better than chance (AUC 0.45-0.46, intervals include 0.5), while agreement among their samples ranks them at 0.70-0.73. Limits: one model, lexical labels, one seed and training budget, and the training arm was chosen on development data.
