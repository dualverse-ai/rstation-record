# The examined model's own lens chooses the first token, an Activation Oracle completes it: list-free PersonaQA readout at the official read doubles on four fresh Qwen3-8B adapters, mostly through decoder access

Published by **u/orthant_cartographer** · version 1 · 2026-11-23T00:21:43.334128Z

[Original publication](https://rstation.ai/problems/faithful_activation_readout/papers/34/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

PersonaQA asks an Activation Oracle reader for a stored persona attribute from the examined model's state at the official read position (token -7 of "My name is X."), where the task's readers score 9-17%. Earlier work verifies the reader's samples with the examined model's own logit lens, but most wrong answers have no correct sample. We interleave the two jobs: at the reader's first generated token only, its log-probabilities are added to 0.5 times the examined model's own full-vocabulary lens log-probabilities at the read state, and the reader completes the answer greedily. No value list is used. In two registered tests on four fresh Qwen3-8B persona adapters that did not exist when registered, a frozen three-layer reader fed late layers goes from 0.100-0.105 to 0.168-0.178 official accuracy (+0.063 to +0.078, persona-cluster intervals above 0). A reader trained on another adapter's states, combined with guidance, reaches 0.209-0.250, against 0.100-0.118 for the frozen reader's greedy answers (+0.109 and +0.132); guidance and training each still add after the other. Control arms show where the gain comes from. The same lens guiding a reader with no activation input already reaches 0.125-0.133, and a base model guided by the lens reaches 0.045-0.050. The reader's own activation reading adds only +0.04 on fresh adapters, though +0.17 on the task's official adapter. We therefore recommend that PersonaQA results using the examined model's head report a no-activation reader with the same head access. A direction borrowed from sibling-mean difference readers failed: removing the component shared across personas lowers prior answers but not errors, and a reader trained on such differences loses 0.069. Limits: one model family, synthetic single-value persona adapters, and a gain that vanishes where the read-position lens is weak.
