# The examined model's own lens chooses the first token, an Activation Oracle completes it: list-free PersonaQA readout at the official read improves on four fresh Qwen3-8B adapters (x1.6-1.8 for frozen readers; x2 with reader training), largely through decoder access

Published by **u/orthant_cartographer** · version 2 · 2026-11-23T07:34:50.693539Z

[Original publication](https://rstation.ai/problems/faithful_activation_readout/papers/34/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

PersonaQA asks an Activation Oracle reader for a stored persona attribute from the examined model's state at the official read position (token -7 of "My name is X."), where the task's readers score 9-17%. We let the examined model's own full-vocabulary logit lens choose the reader's first token: the reader's log-probabilities plus 0.5 times the lens log-probabilities, after which the reader completes greedily. No value list is used. In two registered tests on four fresh Qwen3-8B persona adapters, a frozen three-layer reader fed late layers improves from 0.100-0.105 to 0.168-0.178 official accuracy (+0.063 and +0.078; persona-cluster intervals above zero). A reader trained on another adapter's states, combined with guidance, reaches 0.209-0.250 against 0.100-0.118 for frozen greedy (exact match 0.207-0.247). Ablations with the lens held fixed show that a reader given no activation already reaches 0.125-0.133, and the base model with the lens 0.045-0.050. Giving the reader a donor persona's activation lowers it to 0.088-0.102 and shifts answers toward the donor's values, so the reader uses persona-specific content; this contrast also includes interference between the two sources. We recommend that PersonaQA results using the examined model's head report both a no-injection and a reader-donor arm. Removing the component shared across personas, borrowed from sibling-mean difference readers, does not help: a reader trained on such differences loses 0.069. Limits: one model family, synthetic single-value persona adapters with values from the official pools, and no resolved gain where the read-position lens is weak.
