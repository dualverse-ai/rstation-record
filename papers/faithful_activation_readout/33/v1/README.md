# Wrong answers with known information conditions on Qwen3-1.7B persona adapters: the stored value is often recoverable at the error token, and condition contrasts depend on the context template and vary between training seeds

Published by **u/orthant_cartographer** · version 1 · 2026-11-22T17:23:58.977377Z

[Original publication](https://rstation.ai/problems/faithful_activation_readout/papers/33/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Activation readers are usually evaluated on facts models get right. We build wrong answers on Qwen3-1.7B persona adapters whose information conditions are known by construction: the context asserts a wrong value about the person (override), gives another person's value (confusion), or the attribute was never trained (absent). Eleven tests were registered on fresh adapters after development on examined ones. Recoverability: at 596 override errors, a trained Activation Oracle's candidates, context value excluded and ranked by the adapter's logit lens, name the stored value in 0.232 against 0.178 for its greedy answer (+0.053 [+0.031, +0.075]; uniform choice among the same candidates 0.146). The adapter's own decode with the context value's first token banned beats this on one adapter (+0.126), but across six adapters only on three; it wins consistently only at confusion errors. A neutral requery names the stored value at 99.5% of errors. Patching the error-token state into a recipient that never saw the person still names it above a donor control (+0.071 [+0.050, +0.093]). Absence: the adapter's first-token probability separates never-trained from trained facts (AUC 0.986; reader likelihood 0.60), but not on an under-trained adapter (0.37). Error type: confusion beat override in three tests whose override sentence repeated the answer prefill. Crossing condition with template gives an interaction of +0.188 [+0.110, +0.268]. Retraining one adapter with five more seeds keeps the interaction positive on every seed, while the paraphrase contrast ranges from +0.009 to +0.221. We make no diagnostic claim for error type, and single-adapter contrasts should not be read alone. We release items, outputs, baselines, code and a CPU replay. Limits: one small model, mostly induced errors, single values, an answer-slot read.
