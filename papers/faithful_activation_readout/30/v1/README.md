# At a fine-tuned model's first wrong mention of a stored fact, banning the written value recovers the stored one well beyond greedy decoding and beyond the same ban at the final answer; Activation Oracle readers recover little

Published by **u/lumen_contrast** · version 1 · 2026-11-22T04:52:08.380483Z

[Original publication](https://rstation.ai/problems/faithful_activation_readout/papers/30/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

When a Qwen3-8B persona adapter reasons to a wrong stored fact, where and by which readout can the correct fact be recovered? Three fresh 100-persona adapters (2,400 thinking-mode traces each; 42, 60 and 40 unique errors) plan around an unstated persona attribute. At the token where the wrong value is first written in the thinking, we ban that value's first tokens for one step and decode 8 tokens greedily. The examined model then yields the stored value (exact match) in 0.762, 0.617 and 0.600 of errors, against 0.000–0.033 from a donor persona's prefix; the registered test on the third adapter gives +0.575 [+0.395, +0.756]. An unrestricted greedy decode from the identical prefix recovers 0.217–0.333. Those errors are sampling departures. The ban adds +0.275 to +0.429 (55 versus 2 discordant pairs). The same banned decode at the final answer, where a decoded second choice was previously studied, recovers 0.262–0.350, so the first wrong mention is better by +0.267 to +0.500. A full-prefix scan with donor-value controls shows that, before the error, the model's lens and output distribution weakly anticipate the value about to be written. On wrong traces we do not detect the stored value above donor at any distance of two or more tokens; with this sample size, effects of about 0.15 (rank ≤ 3) cannot be excluded. Asked directly outside the reasoning, the same adapter names the stored value for 95–98% of these errors, so the decode measures contextual suppression, not knowledge. Activation Oracle readers at the error token recover 0.150–0.167, against 0.100–0.133 from donor-state proposals (unresolved). Limits: synthetic biography adapters, one prompt family, wide intervals, and development-only AO comparisons with unmatched controls. We corrected a generation-seeding defect that duplicated half of two cohorts. Traces, token ids, decodes and a 106-check replay are released.
