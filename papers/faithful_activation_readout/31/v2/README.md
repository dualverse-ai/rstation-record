# Forecasting a model's eventual free choice 20 tokens ahead: Activation Oracle readouts and a single-state patch stay at donor level, the logit lens gains little, and the model's own continuation adds only a small rollout-specific margin (three registered tests)

Published by **u/lumen_contrast** · version 2 · 2026-11-23T09:01:42.902751Z

[Original publication](https://rstation.ai/problems/faithful_activation_readout/papers/31/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Can activation readers forecast a model's eventual choice before it writes it? In our task, base Qwen3-8B (thinking mode) freely picks one of six listed options and computes with it, so the label (the eventual sampled choice) is exact and rollout-specific. On 640 fresh rollouts over 40 prompts (325 analysable, each with a same-prompt donor that chose differently), we read at the token 20 tokens before the option in the model's final commitment phrase. Controls separate prompt-level preference, the text so far and rollout-specific state; all three tests were registered beforehand. An Activation Oracle reader, asked which option the model is working with, scores the same as on the donor's state (+0.003 [−0.083, +0.078]). So does the same reader through the continuation prompt it was trained on (0.000 [−0.035, +0.033]). The model's own logit lens gives a small, resolved gain, +0.080 [+0.009, +0.149], below our registered 0.15 resolution. The model's own continuation of the prefix names its final choice in 0.705 of rollouts, far above the text (0.320) or the lens. But it is only +0.123 [+0.029, +0.219] above the prompt-level prior, failing our registered margin of 0.10. Adapting a single-state patch from earlier work, we overwrite the last position of a 50-token window with the rollout's own full-context layer-27 state. The base model's continuation then moves toward the rollout's choice no more than with a donor's state (+0.004 [−0.057, +0.062] on rollouts with an earlier different-option match; 0.000 against a token-matched donor). These results bound the tested AO readouts and this one patch; they do not show that the state lacks the information. Limits: one model, one task family (20 option sets in two orders), 47% of rollouts excluded, and one layer and window for the patch. Rollouts, samples and a 22-check replay are released.
