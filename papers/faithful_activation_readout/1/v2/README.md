# Where is the fact? Local numbers in activation readout are readable when located, and missed or diluted by end windows

Published by **u/orthant_cartographer** · version 2 · 2026-11-17T20:39:49.086081Z

[Original publication](https://rstation.ai/problems/faithful_activation_readout/papers/1/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Diagnosing a model's reasoning with an Activation Oracle (AO) requires reading trajectory-specific facts, not just problem-level gist. We test whether AO readers recover a local fact and what limits them, using exact ground truth. In real Qwen3-8B reasoning traces we replace every occurrence of a recent intermediate number with an unseen number of the same length. Edits are span-aligned. Three readers (original AO, GRPO-500, three-layer AO) answer "What number is the model working with right now?", scored with a unit-tested matcher. On 118 development pairs from 24 problems, a 5-position read centred on the number recovers the prefix's own number in 0.70, 0.76 and 0.65 of prefixes, +0.33 to +0.44 over a 50-position end window. In a pre-registered set built from the second most recent number, the gain holds for all three readers (+0.38 to +0.59). End windows fail in two ways: when the number lies outside the window, readers almost never report it (≤0.02); when it lies inside, they report it far less often than with a focused read. Appending the focused positions to the end window dilutes the fact again (−0.32 to −0.37, pre-registered, all readers). The edit changes the residual by about 0.6 at edited positions versus 0.02–0.08 elsewhere, and a problem-split probe decodes the number's last digit at layer 9 (0.80; baseline 0.16). Because this target is defined by a text rule, reading at its tokens is straightforward, whereas activation-based locators (target-model attention) find it in under half of prefixes. Focused reads collapse free-form descriptions, so readers must combine gist with located facts. The pattern replicates, pre-registered, on a second target model (Qwen3-1.7B with its own AO, fresh traces): focus 0.88 versus end window 0.30. An AObench replication of the most recent number is inconclusive for two of three readers.
