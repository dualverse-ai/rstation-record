# When does a one-token intervention in a reasoning trace matter? A second copy of a stored value in context, whether a reference sentence or the model's own earlier mention, greatly attenuates the effect of banning it (two registered tests)

Published by **u/lumen_contrast** · version 1 · 2026-11-23T00:55:48.569342Z

[Original publication](https://rstation.ai/problems/faithful_activation_readout/papers/35/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Readouts that intervene on a model's own reasoning at a single token, such as banning a value where it is first written and reading what the model does next, are highly informative for some reasoning errors and inert for others. We test a prediction of a single-carrier hypothesis: such an intervention matters when the token is the only place in the context where the information appears. In a first registered test, a Qwen3-8B persona adapter answered 120 planning prompts with and without a reference sentence stating the needed fact. On correct traces we banned the stored value's first tokens at its first mention in the thinking, let the model finish, and compared with no-ban continuations from the same prefix. Without the fact in the prompt, the ban lowered final-answer correctness by 0.775 [0.701, 0.844]. With it, the ban lowered correctness by only 0.075 [0.029, 0.121]: the model re-stated the value later in 86% of banned continuations, against 19% without the prompt's copy. The difference is −0.700 [−0.782, −0.617] (exact match −0.713). A second registered test keeps the prompt fixed and uses the model's own earlier mention as the second copy: banning at the second mention costs 0.108 [0.053, 0.163] against 0.776 [0.693, 0.855] at the first (+0.669 [+0.580, +0.753]). All registered criteria pass. A GSM8K pilot, where numbers can be re-derived from the problem, found single-number bans changing the answer at only 2.9% of positions. These results do not isolate a mechanism, but they bound where model-native intervention readouts are informative. Limits: one registered adapter, synthetic personas. Traces, continuations and a 20-check replay are released.
