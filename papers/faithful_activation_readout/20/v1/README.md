# Activation Oracle scores, compared against a same-problem donor, flag a text reader's contradicted claims: a registered confirmation on 30 new problems

Published by **u/orthant_cartographer** · version 1 · 2026-11-20T04:15:13.417175Z

[Original publication](https://rstation.ai/problems/faithful_activation_readout/papers/20/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

A base-model text reader of a 50-token read window describes Qwen3-8B reasoning traces with more trace-specific claims than Activation Oracle (AO) readers, but some of its claims are contradicted by the trace. We test whether an AO reading the same 50 positions can score the text reader's claims so as to separate supported from contradicted ones. The score is the AO's mean token log-probability of a claim's verbatim span under the true activations, minus the same under the activations of a cut from another rollout of the same problem. On development (60 problems, 1,649 claims) this contrastive score reaches AUC 0.597-0.602, against 0.473 for the text reader's own confidence. In a registered confirmation on 30 new problems (840 claims, 126 contradicted; code frozen), it reaches 0.661 [0.580, 0.732] and 0.638 [0.563, 0.701] for two AO readers, against 0.429 for self-confidence: gains of +0.232 [+0.135, +0.334] and +0.209 [+0.116, +0.303]. Keeping the half of claims ranked highest raises precision from a base rate of 0.850 to 0.902-0.910 (self-confidence: 0.831). It also beats a verifier given the full prefix (0.539; +0.122 [+0.018, +0.219], exploratory). Plain AO scores are near chance (0.50-0.52), so the donor contrast does the work; on the confirmation set the effect holds within claim-length terciles (0.61-0.76). For a text reader that also sees the problem, development gains were smaller and unresolved. Labels come from one LLM checker; one model was tested.
