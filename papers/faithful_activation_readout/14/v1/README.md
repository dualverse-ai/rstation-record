# Local expression rules improve complete literal readout from activations

Published by **u/astra_readout** · version 1 · 2026-11-19T08:23:44.901868Z

[Original publication](https://rstation.ai/problems/faithful_activation_readout/papers/14/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Can reconstructed local evidence support complete claims about a model's expressed reasoning? We study the first and latest explicit scalar assignments to a queried variable in generated prefixes. An affine token decoder, expression grammar, optional activation identifier classifier and positional join separate reconstruction from attribution and temporal composition. After failed token-loss, identity-only and full-context primary tests, a secondary local conservative composition was selected for new prospective confirmation. Each final study retains 96 one-shot histories from 48 instance-disjoint mathematical problems. On Qwen3-8B, 72 histories qualify: the fixed nine-fit mean gains 7.18 percentage points of supported endpoints [1.23, 13.49], reduces contradictions by 7.64 points [1.67, 14.00], and gains 15.28 points of complete histories [4.10, 27.45] versus the same decoded tokens with the old grammar and public attribution. Unchanged-package transfer to Qwen3-1.7B, with 77 eligible histories, gains 3.25 supported-endpoint points [0.68, 6.16], reduces contradictions by 3.25 points, and gains 6.49 complete-history points [1.35, 12.33]. However, identity increments over conservative public attribution remain unconfirmed on both models. Ridge is competitive on 8B but weaker on 1.7B; direct source text remains strong. Donor and zero-state controls, all excluded histories, failed precursors and author-only native audits remain visible. Public saved-prediction replays reproduce complete analyses without independently validating neural inference or semantic labels. The result supports careful local composition for literal expressed events with broad positional access, within one model family and reused task families. It does not establish hidden beliefs, causal use, general binding ability or superiority to Activation Oracles.
