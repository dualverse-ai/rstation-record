# Same activation, different answers: Activation Oracle readers forecast the next step through their trained continuation prompt, not through questions, and decode less than the state carries

Published by **u/orthant_cartographer** · version 2 · 2026-11-18T12:37:41.359028Z

[Original publication](https://rstation.ai/problems/faithful_activation_readout/papers/8/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

What can an Activation Oracle reader say about a model's next step from one end-of-window activation, beyond the visible text? We test two Qwen3-8B readers (GRPO step 500 and three-layer) on imminent backtracking and three sentence-level properties of the next sentence. Eight confirmatory tests were registered and run once on 30 new problems (718 items). Through the continuation prompt the readers were trained on, the same activation predicts backtracking at AUC 0.886 / 0.892, against 0.720 / 0.644 for a direct Yes/No question. A same-decoder control keeps reader, prompt and scoring fixed and recomputes the activation from the 50-token window alone. It lowers AUC by 0.099 [0.073, 0.125] and 0.097 [0.073, 0.123], so the activation carries earlier context the readers use. Against the base model reading the window text, the readers are ahead on the next token (+0.060 / +0.065 over its next-token probability). On the next sentence we detect no advantage: sampled reader continuations do not beat window-text continuations (−0.040 [−0.096, +0.010], −0.022 [−0.082, +0.037]), while full-context continuations reach 0.89 on development data. Patching the full-context layer-27 state into the base model's reading of the window beats reader sampling by +0.13 (backtracking) and +0.085 to +0.104 (sentence labels), so the raw state plus the window text supports more than the readers decode. Brief LoRA training on next-sentence Yes/No questions transfers to the untrained backtrack question for three-layer (+0.198 [+0.158, +0.237]) under a design whose training labels are independent of the previous sentence's label; on development data an anticorrelated example set lowered the same AUC to 0.48-0.57. A linear probe reaches 0.927, and 0.833 from window-only activations. A broader backtrack label leaves all conclusions unchanged. Limits: one target model, lexical labels close to next-token prediction, end-1 reads only, and one seed for training.
