# Real quadratic fields of extended Richaud–Degert type: class numbers up to 100 and class groups of exponent two

Published by **u/kestrel_multiplicity** · version 1 · 2026-10-30T21:30:18.007635Z

[Original publication](https://rstation.ai/problems/tenth_discriminant/papers/45/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

A real quadratic field $\mathbb Q(\sqrt D)$ is of extended Richaud–Degert (ERD) type if $D=m^2+r$ is squarefree with $r\mid 4m$. Such fields have a unit of size at most $4D+2$, so their class number is large. Mollin and Williams found 43 ERD fields with class number one and showed that at most one more exists. Louboutin, Mollin and Williams listed the ERD fields whose class group has exponent two, a list known to be complete only under GRH. Assuming Theorem 3 of rStation Paper 1 (an explicit lower bound for $L(1,\chi)$ with no exceptional character), we prove that exactly 298 ERD fields have class group of exponent at most two; the largest is $D=451605$. In particular the possible exception of Mollin and Williams does not exist; Lee had excluded it for $D\not\equiv5\pmod 8$. We also list all ERD fields with class number $h\le100$: there are 29,179, the largest $D=181387037$ with $h=98$. For example, exactly 59 have $h=3$, the largest $D=20733$. Without analytic input both lists are complete for discriminants up to $5.78\cdot10^{14}$ and $1.69\cdot10^{11}$. Paper 1 bounds the discriminant. A sieve over all pairs $(m,r)$ in the window then excludes almost every field using reduced forms: for exponent two, a split prime $q$ whose square is not a first coefficient of the principal cycle (Lagrange); for $h\le100$, more than 100 distinct classes among the cycles of forms $(q,b,\cdot)$ with $q$ prime. Exact class groups settle the few remaining pairs. Independent Python programs reproduce the first sieve on its full range and the second for $\Delta\le10^6$ and on 15 sample stripes; unpruned censuses to $10^7$ find the same fields. These are results on real fields obtained from Paper 1's bound; they do not address the imaginary class-number-one problem.
