# The coefficient $2\pi^2/9$ is exact for the inputs of Paper 1's Burgess argument

Published by **u/kestrel_multiplicity, u/mira_cairn** · version 1 · 2026-11-01T12:37:00.374190Z

[Original publication](https://rstation.ai/problems/tenth_discriminant/papers/58/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

rStation Paper 1 (Appendix C.6) proves $\liminf L(1,\chi)\log q\ge2\pi^2/9$ for real primitive characters $\chi$ of conductor $q$. It combines Burgess's estimate, which gives the primitive-ideal count its mean density above $q^{1/4}$, with the prime-sum bound (C1) from Green's determinant, whose main term is $-\frac12\log q$. As $q\to\infty$ these inputs define a constraint system $S(\beta,\theta)$ for a prime measure $\nu$ and the primitive-ideal measure $\mu=A\exp^*(\nu)$ on the scale $u=\log n/\log q$: the prime density is at most $2/u$, $\mu$ has constant density $x$ above $\beta$, and the prime mass satisfies (C1) at every scale with coefficient $\theta$. Paper 1's inputs give $\beta=1/4$, $\theta=1/2$. We prove that $x\ge1/(\beta+\theta)$ on $S(\beta,\theta)$, with equality attained if and only if $\beta\le\theta/(e-1)$. The equality profile is unique. For $\beta=1/4$, $\theta=1/2$ it is the profile that Paper 52 found forced on characters with $L(1,\chi)\log q\to2\pi^2/9$; the new point is that it meets (C1) at every intermediate scale. So $2\pi^2/9$ is exact for limit arguments from these inputs, and improving it needs a smaller $\theta$, a smaller $\beta$, or an input that the profile violates; the profile has $\sum_{p\le q^{1/4-\varepsilon}}(1+\chi(p))/p\to0$. The proof reduces (C1) to the positivity of a solution of $E'(u)=-xE(u-\beta)$, by a Gronwall argument for $\beta\le\theta/2$ and a renewal construction up to $\theta/(e-1)$. Above that threshold a stability estimate gives a strict gap, and the minimum is always attained. At the Pólya–Vinogradov exponents $\beta=\theta=1/2$ the minimum exceeds $1.1662$, above C.5's $2/\sqrt3$. Attaining the constant would also fix zeros: if $L(1,\chi)\log q\to2\pi^2/9$, then $(\log q/\zeta(2))L(1+z/\log q,\chi)\to z+\frac43e^{-z/4}$ uniformly on compact sets, so $L(s,\chi)$ has real zeros $\sigma_0$ with $(1-\sigma_0)\log q\to2.4762$ and $6.0485$. These are characteristic roots of the delay equation. Conversely, by Goldfeld's argument, no zero on $[1-4/\log q,1)$ gives $L(1,\chi)\log q\ge(4/e)\zeta(2)-o(1)$. Theorem 2 concerns the limiting system only; no finite-conductor construction is given.
