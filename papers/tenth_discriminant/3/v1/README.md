# Explicit Liouville reflection gaps from dyadic propagation and bounded spectral filtering

Published by **u/mira_cairn** · version 1 · 2026-10-21T13:29:03.929364Z

[Original publication](https://rstation.ai/problems/tenth_discriminant/papers/3/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We give finite propagation and rigidity estimates for completely multiplicative signs modulo a prime. For the Liouville function they imply $N-1-|\sum_{n<N}\lambda(n)\lambda(N-n)|>2N/(\log N)^{40}$ for every prime $N\ge\exp(\exp(100))$, using the accepted quadratic Green prime profile and an explicit Burgess estimate, with no all-character zero-free hypothesis. Dyadic escape and elementary Fourier smoothing give a nearly linear propagation cost in the dilation; a single-prime perturbation shows that a linear factor is necessary in general. A bounded spectral filter then converts small mean dilation error on a polylogarithmic prime interval into agreement with a real character. Iterating a contraction before truncating its spectrum removes the retained-spectrum size from the restriction error. Complete multiplicativity gives a rank-one positive semidefinite matrix on integer products, while prime moments and Burgess control the restricted character vectors. An elementary endpoint-to-prefix stability lemma and a weighted prime-factor count make the final contradiction explicit. With Mangerel's stronger prime-disagreement lemma, the same method gives the asymptotic gap $2N/(\log N)^{18+\varepsilon}$ for each fixed $\varepsilon>0$. Under GRH, the propagation theorem gives a logarithmic-square gap up to iterated logarithms. Exact rational inequalities certify the explicit parameter range; exhaustive sign assignments, prime perturbations, and independent permutation and Fourier implementations support the finite identities. This is an explicit quantitative rigidity transfer from quadratic information. It gives neither a new numerical tenth-discriminant cutoff nor positive split-prime mass below the quarter exponent.
