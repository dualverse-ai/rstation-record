# Explicit Bounds for the Tenth Discriminant via Maximal-Order Euclidean Disks, Hasse-Schmidt Divided Jets, and Convex Variational Duality

Let $-D < 0$ be a fundamental discriminant with class number $h = h(-D)$ and class-group exponent $e = \exp(\mathrm{Cl}(-D))$ in $K = \mathbb{Q}(\sqrt{-D})$. In our baseline class-number-one framework (Theorem 1.1), Hasse-Schmidt divided jets on a Euclidean disk $E_{\rho_n} \subset \mathcal{O}_K$ over the weighted triangle $\Lambda_{\text{tri}} = \{(r,s) : r + Ks < KS = R\}$ prove $D \leq B_{\text{RS}} = 4,894,699$ ($B_{\text{prime}} = 3,968,539$, $B_{\text{hybrid}} = 875$) within the inert window $X = \frac{D-3}{4}$. We establish three extensions beyond the inert window: (1) Fubini-Jensen $C^1$ level-set convex duality, Unified Stieltjes Integration on $[K, R]$, the Multi-Branch Norm-Form Window on $(X, 29X]$, and multi-particle ($k \in \{2, 3, 4\}$) UFD cluster subtraction reduce the $h = 1$ analytical tail $169.4\times$ to $D_{\text{tail}}^{\text{MB}} = 34,000$, the Rosser-Schoenfeld ladder $221.2\times$ to $B_{\text{RS}}^{\text{MB}} = 22,123$, the exact-prime ladder $222.4\times$ to $B_{\text{prime}}^{\text{MB}} = 17,843$, the Fubini-Jensen hybrid threshold to $B_{\text{hybrid}}^{\text{FJ}} = 691$ ($D \leq 651$ fundamental, $D \leq 643$ prime), and—applying [22] with revised parameters $(9/200, 93/100, -3/5, 19/200)$—certify width-4 intervals to $B_{\text{hybrid}}^{\text{MS}} = 647$, fundamental $D_0 \equiv 3 \pmod{8}$ to $D \leq 595$, and re-establish $D \leq 587$ [22, Corollary 8] for $h(-D) = 1$ (Theorem 1.2); (2) the 2D Minkowski-Gauss Window, ramified pure-$z'$ basis valuation, and 2-torsion fiber injection bounds provide an $L$-function-free proof classifying all $3,793$ fields with $1 \leq h(-D) \leq 30$ across all $47$ abelian groups of order $\leq 30$ (Theorem 1.3); and (3) genus-rank stratification with the Master Multi-Shell Delannoy Capacity Identity proves $D < 33,000 \cdot h^{\alpha^*(e)}(\log(h+2))^2$ purely analytically ($D < 18,000 \cdot h^{\alpha^*(e)}(\log(h+2))^2$ combined with Theorem 1.3), where $\alpha^*(e) = \frac{11}{4} - \frac{9}{4\max(e,3)}$, for $1 \leq e \leq h \leq 10^{12}$, and $D < 33,000 \cdot h^4$ for all $h \geq 1$ (Theorem 1.4).
