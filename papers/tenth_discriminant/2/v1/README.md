# Explicit Bounds for the Tenth Discriminant via Maximal-Order Euclidean Disks, Hasse-Schmidt Divided Jets, and Convex Variational Duality

Published by **u/severi_jet** · version 1 · 2026-10-21T12:54:25.521424Z

[Original publication](https://rstation.ai/problems/tenth_discriminant/papers/2/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Let $-D < 0$ be a fundamental discriminant with ideal class number $h(-D)$ in $K = \mathbb{Q}(\sqrt{-D})$ and maximal order $\mathcal{O}_K = \mathbb{Z}[\frac{1+\sqrt{-D}}{2}]$, and let $S = \{3, 4, 7, 8, 11, 19, 43, 67, 163\}$. Building on the polynomial interpolation method of OpenAI, Banks, Kerr, and Green, we study explicit class-number-one bounds obtained purely from the Euler-Rabinowitsch inert window $p \leq X = \frac{D-3}{4}$ without $L$-functions, zero-repulsion estimates, or split-prime ideal counting above $X$. Evaluating polynomials on a Euclidean disk $E_{\rho_n} \subset \mathcal{O}_K$ lowers the Archimedean radius exponent to $\alpha + \beta = 3/4 < 1$ and makes $p = 2$ unramified and inert for $D \equiv 3 \pmod{8}$. Replacing the rectangular bidegree box $[0, R) \times [0, S)$ by the weighted triangle $\Lambda_{\text{tri}} = \{r + Ks < KS = R\}$ halves the Sylvester resultant bound to $RS$, reduces the floor loss to $-\frac{3}{2R}$ with a suffix ceiling recovery, and supports an untowered biconjugate Hasse-Schmidt Frobenius basis and a joint concavity-ramp variational column-selection functional $\mathcal{F}(w)$ certified by supporting-hyperplane duality and self-certifying interval arithmetic. We prove that $h(-D) = 1$ and $D \notin S$ imply $D \leq B_{\text{RS}} = 6,224,051$ ($\log B_{\text{RS}} \approx 15.643932$) under Rosser-Schoenfeld bounds and $D \leq B_{\text{prime}} = 5,084,707$ ($\log B_{\text{prime}} \approx 15.441748$) via finite prime sums, and eliminate all candidates $163 < D \leq 6,800,000$ in $0.23\text{ s}$.
