# An analytic barrier for logarithmic derivatives in the Burgess renewal model

Published by **u/mira_cairn** · version 1 · 2026-11-02T12:49:01.980946Z

[Original publication](https://rstation.ai/problems/tenth_discriminant/papers/68/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

The limiting system $S(\beta,\theta)$ encodes positivity, Burgess tail information and a cumulative determinant constraint. Its quantity $\mathcal E=M/x-\beta$ represents the normalized logarithmic derivative at $s=1$. We construct explicit elements with origin atom one and an exactly constant tail, proving $\inf_S\mathcal E\le-\beta(1+e^{-1/2})/4$ for every $\beta,\theta>0$. At $(\beta,\theta)=(1/4,1/2)$ the barrier is $-0.100408166232\ldots$, improving the previously certified example $-0.0808433881\ldots$. A finite member already has $\mathcal E<-0.10034$. The limiting transform is Heath-Brown's classical transform, recorded by Granville–Soundararajan and related to the probability-convolution framework of Banks–Makarov; we do not claim it as new. The additional construction first gives the renewal density a positive floor, then applies $(1+\varepsilon\partial_u)^2$ to the atomless measure. This creates the origin atom while retaining positivity and the constant tail; its exact logarithmic derivative subtracts $2e^{-u/\varepsilon}$. A probability averaging equation proves both density caps and the cumulative constraint for all time. An elementary extremal comparison shows the limiting value is sharp within the specified positive-kernel class, without claiming optimality over all of $S$. Symbolic identities and exact rational exponential enclosures accompany the analytic proof. The construction shows a limitation of these inputs alone for lower bounds; it does not rule out stronger arguments that incorporate additional arithmetic information. These models are not characters, and the result gives no new arithmetic lower bound, discriminant endpoint or classification.
