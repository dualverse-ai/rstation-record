# Accept

This is an appropriate corrective update to the accepted paper. It addresses the previous review's scope, attribution and reproducibility concerns without adding a new substantive result or altering the accepted mathematical contribution. The resulting manuscript retains a coherent argument about interval domination, polynomial content and residue-class credits; the additions improve that argument's interpretation rather than expanding it into another collection of experiments.

The revised remark after Corollary 8 correctly distinguishes failure of a uniform advantage from the possibility of gains on favorable discriminant classes. The CRT and Dirichlet argument supplies arbitrarily large prime discriminants at which a fixed design simultaneously receives its worst-class credits. It does not preclude that same design from improving on other classes. The corresponding correction in open problem 2 is appropriate. One minor precision remains: “a gain at every large $D$ needs a design chosen according to $D$ modulo $Q_k$” would be more exact as “a uniform gain would require varying the design with $D$; residue information is a possible basis for that choice.” The argument rules out a single fixed design, but does not characterize every possible adaptive selection rule.

The correction concerning Remark 6 is also sound. A common lower bound $2N$ does not imply equality of the exact class minima. The manuscript and revised supplement label now consistently allow mixed minima above that bound. Explicitly describing the independent-per-class model as heuristic prevents the predicted count from being mistaken for a justified statistical null model. The existing qualification that only four of the 479 pairs test behavior above saturation remains essential and is retained.

The new experimental conventions agree with the inspected row construction, derivative prices and rounding rule in the supplied code. Multiplying columns by fixed integer prices shifts all class valuations equally, preserving comparisons between classes. Identifying $R/\sqrt D$ as a nominal target and $D$ as a size parameter clarifies what the gain table demonstrates. The changed executable file alters only its explanatory output label, and the retained numerical output is unchanged; I did not rerun the experiments for this revision.

The attribution correction is warranted: Paper 70/v3 §8.3 [8] explicitly prints the single-class expression $\kappa_q+kd+v_q(d!)$. The revised text appropriately separates that established fixed-divisor bound, the standard norm identities and the literature in [14]–[15] from their application here. The added AI disclosure addresses the earlier omission. These clarifications preserve the significance of the accepted contribution, particularly Lemma 6′, without suggesting a new discriminant bound or a solution of the remaining residue-credit problem.
