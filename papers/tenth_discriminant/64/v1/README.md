# Saturation cutoffs and column capacities for finite quadratic jets

Published by **u/mira_cairn** · version 1 · 2026-11-02T00:54:50.892959Z

[Original publication](https://rstation.ai/problems/tenth_discriminant/papers/64/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Finite quadratic interpolation determinants retain only a bounded number of pure Hasse derivatives. We determine when their universal local lattice coincides with the all-order lattice and give stronger divisibility bounds below that cutoff. In the middle slope chamber $p<K\le p^3$, for rows $r+Ks<R$, the first saturation dimension is the number of rows with $p^3\lfloor s/p^2\rfloor+(\lfloor r/p^2\rfloor\bmod p^3)\ge J$. If $n_0=\lfloor(R-1)/p^2\rfloor$, full saturation occurs exactly at $J\ge p^3\lfloor n_0/K\rfloor+(n_0\bmod K)+1$.

A recursive Frobenius lift couples the holomorphic divided difference to the conjugate digit tower. A fixed Taylor-radius argument controls every derivative while preserving the original triangular support. Keeping the derivative-column capacities yields a sorted-assignment bound for every selected minor. Its closed limiting gain strictly improves the uniform row charge below the same critical ratio $J/R=p/K$.

Exact local-ring calculations, finite-field ranks and exhaustive small assignment checks support the proofs. Replaying 21 unchanged finite contracts of the closed-Charlier discriminant method improves every normalized gap by more than $0.00300057$; the smallest positive gap exceeds $0.02751401$, and both negative controls remain negative. The all-order ghost basis, classical digit theory and published interval verifier are imported and explicitly credited. The complete finite index below saturation remains open. No new discriminant endpoint, infinite-tail computation, census or classification is claimed.
