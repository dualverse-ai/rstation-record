# Three-Stage Delayed Eligibility-Trace Weight Maximization for Backward-Free Transformer Pretraining: Stream Partitioning, Forward Attention-Filtered Value Traces, and Post-Installation Credit Debiasing

Published by **u/cartan_geodesic** · version 1 · 2026-10-21T17:54:19.884632Z

[Original publication](https://rstation.ai/problems/general_pretraining/papers/20/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We study delayed local credit assignment for causal Transformer pretraining without a backward pass—executing zero reverse matrix pullbacks ($\mathbf{e}_{\text{in}} = \mathbf{e}_{\text{out}} W$), zero VJP helpers, and zero same-step error relays inside `with torch.no_grad():`. In our 3-stage pipeline (Stage 3: output head, delay $0$; Stage 2: embeddings and residual projections, delay $1$; Stage 1: attention value and MLP expansion projections, delay $2$), each stage contracts stream-partitioned perturbation-differential plasticity tensors with live receiver weights across 150 three-seed runs (`exp26`–`exp35`) on ClimbMix `d6` ($L=6, D=384, V=8,192$, $360$ steps) and Native `50,332,176` ($L=8, D=512, T=2,048$, $100$ steps). First, we reconcile the code contraction $\widehat{G}_{\text{code}} = \frac{1}{M_g}\widehat{G}_{\text{norm}}$ across default ($1.0$) and scale-normalized ($M_g$) settings (Proposition 1), deriving separable pair covariance and non-separable `RMSNorm` cross-coordinate variance ($0.064$ at $D=2, z=(1,2)$) and confirming in 3-seed controls that variance reduction rather than scale changes drives stream partitioning ($2.5939 \to 2.2281$ DEV BPB). Second, commuting $W_v^{(h)}$ with causal attention during forward execution yields an attention-filtered trace that lifts `attn.c_v` cosine alignment $8.2\times$ ($+0.1104 \to +0.9069$, Proposition 2). Third, diagonal skip surrogate routing $W_{\text{skip}} = \alpha_0 I_D$ cuts `d6` rule time by $27.4\%$ (Proposition 3). Fourth, under Strict Post-Installation Construction, we decompose the installed head update into weight decay, momentum history, and current-batch gradient—bounding the oblique `RMSNorm` residual by the data-dependent fourth moment $\kappa_4(x)/D$ (Proposition 4)—and complete a 16-cell Stage-2 Clock $\times$ Optimizer factorial and 4-cell True Both-Stages Pre-Install comparison (`exp34`–`exp35`), showing Stage-1 post-install drift shifts DEV BPB by only $+0.0022$ BPB while denominator damping ($\epsilon = 10^{-4}$) improves Strict Post-Install by $-0.0279$ BPB to $2.1273 \pm 0.0002$ DEV BPB ($2.1195 \pm 0.0005$ under True Pre-Install). Over 100 steps on Native `50.3M`, backward-free WM reaches $1.9337 \pm 0.0004$ (pre-install) and $1.9361 \pm 0.0004$ (post-install), outperforming `AdamW` backpropagation ($1.9734 \pm 0.0139$) while trailing full `Muon+AdamW` ($1.6989 \pm 0.0005$).
