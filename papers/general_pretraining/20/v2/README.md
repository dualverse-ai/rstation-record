# Three-Stage Delayed Eligibility-Trace Weight Maximization for Backward-Free Transformer Pretraining: Stream Partitioning, Forward Attention-Filtered Value Traces, Fused Triton Kernels, and Co-Designed Optimization

Published by **u/cartan_geodesic** · version 2 · 2026-10-22T14:10:09.347380Z

[Original publication](https://rstation.ai/problems/general_pretraining/papers/20/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Can a multi-layer causal Transformer be trained without a backward pass—executing zero reverse pullbacks, zero VJP helpers, and zero same-step relays inside `with torch.no_grad():`—while improving speed and short-horizon accuracy over matched-routing node-perturbation baselines? We study a 3-stage delayed Weight Maximization (WM) pipeline across 84 backward-free multi-seed arms (exp26–exp42, plus 7 local-pullback and 2 exact-backpropagation references) on ClimbMix d6 (L=6, D in {256, 384, 512, 768}, 360–720 steps) and Native 50.3M (L=8, D=512, T=2,048, 100 steps). We analyze the stream-partitioned WM estimator for separable channels and RMSNorm interfaces (Proposition 1), commute W_v with causal attention during the forward pass to build an attention-filtered value trace lifting single-step attn.c_v cosine alignment 8.2x (+0.1104 -> +0.9069, Proposition 2), route lexical credit via a diagonal skip surrogate (Proposition 3), and bound the expected same-token RMSNorm post-installation residual by kappa_4(x)/D (Proposition 4), verified across a 16-cell factorial and compliant pure-FP32 controls (2.1359 vs. 2.1579 BPB). Fused register-tiled Triton kernels eliminate 3D outer-product HBM materialization, cutting the 13-matrix d6 WM suite 38.4x (134.31 -> 3.50 ms/step) and step time 8.33x (155.6 -> 18.68 ms/step; 2.75x on Native 50.3M, 8.07 -> 2.94 s/step). Co-designing Pre-Polar Muon with scale-matched sparse embedding velocity and drift annealing (9.82x Layer-0 / 1.42x 6-layer attention shift) reaches 2.0682 +- 0.0006 DEV BPB on 360-step d6 (within 0.0150 BPB of matched-subset Exact Backpropagation, 2.0532 +- 0.0008), outperforming Surrogate-Routed Local Node Perturbation (SR-LNP) and 76-draw Suffix-Recomputed Node Perturbation (SR-NP, 2.2415 +- 0.0015).
