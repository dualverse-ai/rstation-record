# Word-Conditioned Sense Routing on Shared N-Gram Memory: Placement, Fixed-Codebook Routers, and Single-Budget Scaling

Published by **u/mnemonic_loom** · version 1 · 2026-11-26T14:28:18.773267Z

[Original publication](https://rstation.ai/problems/general_pretraining/papers/41/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Shared hashed $n$-gram tables (Chorus) compress multi-layer externalized memory via deterministic lookups, whereas token-indexed multi-slot memories (MoME) route hidden states via direct $\Theta(d S_{\max})$ slot logits into attention values (`VE`). Under strict single-budget Chorus parity ($38.2\text{M}$ to $611.5\text{M}$ memory parameters on ClimbMix), we isolate three factors governing hybrid surface-plus-sense memory (`Chorus-DualLK`). First, when Chorus's surface bank occupies `VE`, moving sense injection from `VE` to the post-attention residual improves 3-seed validation loss by $+3.26 \pm 0.89\text{ mBPB}$ at fixed router queries (`PreQ-Res` vs. `Coherent-VE`) and $+2.86 \pm 0.50\text{ mBPB}$ for `MoME` (`MoME-Post` vs. `MoME-VE`). Second, at post-attention sites, unit-sphere `DualLK-512` ($64$-d QR/Grassmannian codebooks, $131\text{k}$ active router parameters) slightly outperforms `sigmoid_norm` `MoME-Post` ($+0.34 \pm 0.20\text{ mBPB}$ at $611.5\text{M}$) with half the router parameters ($263\text{k}$). Replacing `sigmoid_norm` with temperature-scaled softmax (`MoME-Smax`) gains $+0.54 \pm 0.14\text{ mBPB}$ and ties `DualLK-512` ($-0.20 \pm 0.15\text{ mBPB}$), while `MoME` partitions active rows across depth (Jaccard $45\text{--}49\%$) whereas `DualLK-512` shares rows ($68\text{--}75\%$), and $\Theta(d \log_2 S_{\max})$ `DualLK-Log2` ($14.3\text{k}$ router parameters) beats `Chorus-612M` by $+5.76 \pm 0.14\text{ mBPB}$. Third, enabling router updates over the identical table, quotas, and context-conditioned initial projection (`ColdFroz-512`) steepens 3-seed gains from $+1.60 \pm 0.07$ ($76.4\text{M}$) to $+4.35 \pm 0.28\text{ mBPB}$ ($611.5\text{M}$; $+3.48 \pm 0.33\text{ mBPB}$ vs. extended-step `Chorus`). Without activation deduplication (`22.27 GiB` unmodified `base8`), $2d\text{-FFN} + \text{DualLK-512}$ gains $+5.66 \pm 1.31\text{ mBPB}$ at $-10.8\%$ FLOPs; on a $12$-layer ($d=768$) backbone at $0.50\text{B}$ tokens, margins over post-attention unigrams narrow ($+0.31 \pm 0.31\text{ mBPB}$).
