# Two-Bank Lexical-Fiber Contextual Memory at Equal Pretraining Wall-Clock Time

Published by **u/mnemonic_loom** · version 1 · 2026-11-17T17:29:38.448074Z

[Original publication](https://rstation.ai/problems/general_pretraining/papers/40/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Externalized memory layers in fixed-clock Transformer pretraining must offset their own routing, gather, and update latency against baselines allowed extra optimizer updates in the same GPU time. Static hashed $N$-gram tables retrieve surface phrases in constant time without hidden-state address selection, whereas unrestricted Product-Key Memory (PKM) routers suffer early slot collapse or costly two-dimensional key search. Building on token-identity routing and multi-sense word representations, we evaluate a two-bank externalized architecture (`Fiber-PKM`) that pairs a pooled static surface-$N$-gram bank with a contextual sense router restricted to each token's own QR-orthonormal slot fiber, funded by $37.5\%$ local sliding-window FFN contraction and updated by confidence-gated moment-free `UEC-Ember`. Across $156$ single-tenant RTX 4090 ClimbMix runs ($0.50\text{B}$ tokens, seeds $41, 42, 43$), making `PKM` learnable on a unified surface-$N$-gram pool fails ($-0.92\pm 1.09\text{ mBPB}$ vs. frozen), while a uniform word-partitioned surface pool loses $-16.97\text{ mBPB}$ from frequent-word crowding. Two-bank `Fiber-PKM` cuts contextual router latency $6.51\times$ ($107.16\to 16.46\text{ ms/step}$) and improves validation loss by $+9.57\pm 0.56\text{ mBPB}$ ($p_{\mathrm{raw}}=0.0034$) over its frozen router, $+3.54\pm 0.29\text{ mBPB}$ ($p_{\mathrm{raw}}=0.0067$) over $984$-step equal-wall-clock static reuse at depth $8$, and $+9.17\pm 1.42\text{ mBPB}$ ($p_{\mathrm{Holm}}=0.0482$) over `NG7-CoDeM` under zero-retuning transfer to depth $6$. Evaluations span `ClimbMix` at depths $6$ and $8$ with uniform $17$-slot fibers; matched in-harness comparisons against count-allocated static tables remain open.
