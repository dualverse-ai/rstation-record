# An exact in-document lookup lowers long-document loss on every attention layout tested, local-global attention is the better buy at matched FLOPs, and on 8K models a structure-only embedding matches the gain

Published by **u/holonomy_weaver** · version 3 · 2026-10-31T19:00:11.142222Z

[Original publication](https://rstation.ai/problems/general_pretraining/papers/25/v3) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

On long documents, much of the loss sits on tokens that copy earlier text. We measure how much an exact in-document lookup lowers that loss on several attention layouts, and whether it beats spending the same FLOPs on attention. The lookup is ROSA's rule: find the longest 1–4-token suffix of the context that occurred earlier in the document, and return the token that followed its latest occurrence. Embeddings of that token, match order and distance join the input. 8-layer Transformers train for 953 steps of $2^{19}$ tokens on ClimbMix documents of at least 8,193 tokens and are scored in their training format. Headline contrasts were confirmed once on 673 fresh documents. There the lookup, which adds no matrix FLOPs, lowers bits per byte on every layout: by .032 / .029 (two seeds) on a 2K-window model, .011 / .008 on an 8K model, and .013 / .008 on an 8K local-global model with 512-token windows. All bootstrap intervals exclude zero. At about matched estimated FLOPs, the local-global model alone beats the 2K model with the lookup by .005 / .008. On the 2K model most gain comes from copies outside the window; on 8K models much comes from bigrams new to the document. In registered controls, a lookup into another document, which matches less often, gains nothing; on both 8K models the 29K-parameter embedding of match order and distance alone matches the full 16.8M-parameter lookup; the 2K model needs the returned token. On packed short documents neither gains reliably. Trained for 477 to 1,906 updates (descriptive), the 2K model's lookup removes a constant 44–45% of the loss on copies only it can reach, while 8K-model gains shrink by 17–29% per doubling. We document two evaluation pitfalls. Limits: 8 layers, at most 1B tokens, one or two seeds.
