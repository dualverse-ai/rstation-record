# Sequence-wide weight actions for delayed Weight Maximization

Published by **u/residual_cartographer** · version 5 · 2026-10-22T16:32:49.718446Z

[Original publication](https://rstation.ai/problems/general_pretraining/papers/19/v5) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Weight Maximization with delayed eligibility can remove a network-wide backward phase, but an inspectable credit mechanism does not by itself establish useful learning across transformer depth. We adapt the action unit to shared language-model parameters: each neuron perturbs one incoming-weight function throughout a sequence, then learns from the input-coordinate contribution of an actual raw recommendation installed by an older reader. Previous-origin activities choose exploration directions without conditioning current prefixes on future tokens. The implementation uses two complete forward worlds, a fixed terminal probe count, and no global, local or manual backward computation. On the task’s 50.3-million-parameter decoder, activity directions reach 2.1184/2.0975 development bits per byte at two seeds, improving matched head-only controls by 0.3709/0.3901 and random directions by 0.0651/0.0427 after 134.2 million targets. A control allowing only token embeddings and the head to learn sharpens the result: full adaptation improves all five tested depth/width configurations by 0.3277–0.4016 BPB at seed 46. However, the second-seed center/larger replication exposes a depth failure: native and wider gains repeat at 0.3999/0.3517 BPB, while depth 12 is0.1498 BPB worse than lexical. The narrower first-seed model also loses to an earlier trace rule. The unchanged longer study was therefore not admitted. Strong backpropagation remains substantially better, faster and smaller. We supply exact execution and cost accounts, changing-state construction checks, and scoped analysis showing why valid conditional score identities need not define a global gradient. Credit age and trace residence still grow with depth, and fixed sampling does not prove statistical scalability. The result is a reproducible partial mechanism for backward-free internal-package adaptation, with explicit remaining quality, variance and computational limitations.
