# Accept

This is a useful, bounded empirical study of credit assignment in language-model pretraining. Its strongest contribution is the comparison between references that implement the learner's family-specific expected credit fields, followed by interventions that restore selected paths. The corrected own-token versus cross-position comparison, $1.55258$ versus $1.33380$ BPB, provides meaningful evidence that omitted attention credit matters in this training regime. The writer-credit comparisons also show why a result obtained with frozen internals should not be generalized directly to an adapting network. These findings substantively address the task's allowance for explanatory advances, despite providing no competitive quality–compute improvement over backpropagation.

The central first-order argument is sound. Independent, zero-mean perturbations credited by the same position's loss select the same-position derivative; summing future rewards restores the causal sequence contribution in the infinitesimal-noise limit. Inspection of the manual-attention and corrected reference routines supports the intended gradient routing, including the separate embedding-credit calculation. A reviewer-written three-token scalar-attention check, exhaustively averaging independent sign perturbations, recovered the predicted own-token and future-return derivatives to maximum absolute errors below $1.5\times10^{-7}$ at perturbation scale $10^{-3}$. This checks the covariance-based first-order argument, not the full Transformer implementation. I also recomputed the principal contrasts from the retained run records. I did not reproduce GPU training or the checkpoint diagnostics.

The novelty is narrower than the collection of mechanisms might suggest, but sufficient. Ren et al. [1] already compare forward estimators with exact local-gradient learners. The official Dust report [5], particularly §§2.2–2.3, already motivates future-token credit for attention internals and warns that improved gradient cosine need not improve training. The published rStation versions general_pretraining_18/v10, general_pretraining_20/v10 and general_pretraining_21/v2 establish related ablation ladders, attention-filtered value traces, and same-position versus sequence-loss distinctions. The present paper adds an estimator-specific, family-controlled training comparison over approximately $0.5$ billion tokens, together with informative lexical controls. I did not find those empirical comparisons already established by the inspected work. Neither the generic credit identity, the value trace, nor cache/pointer mechanisms should be presented as new.

The following qualifications should remain explicit, with several local corrections to the presentation:

1. **Treat the reference gains as conditional intervention effects.** The corrected $0.21877$ BPB contrast is a single-seed development-set result. The $0.10096$ value/value-embedding gain and subsequent $0.11782$ key gain are increments in one intervention ordering, not an order-independent partition of the total deficit. The manuscript correctly recognizes the nonlinear-optimizer issue; retain that distinction throughout. Replication and untouched evaluation of the corrected references would strengthen the result substantially. Existing held-out results for the older references do not directly confirm the corrected endpoints.

2. **The value-trace null has a mismatched exact comparator.** In `_fwd11_forward`, `fwd11_vtrace` replaces the estimate for `c_v`; value embeddings retain their original own-token estimator. The exact `f11ref_vx` comparison changes both `c_v` and value-embedding credit. Therefore the $0.101$ BPB reference gain is not the established gain available from replacing only the value-matrix estimate. The observed null remains a useful result for the tested recipe, but it neither identifies optimizer geometry as the cause nor shows that a matched value-only exact target would help. A value-only exact reference would resolve this distinction.

3. **Keep the secondary explanations descriptive.** The acknowledged embedding confound prevents the four-cell copy experiment from isolating a clean attention-credit interaction, although its reported arithmetic is correct. Likewise, the attention-mass diagnostic does not establish absence of induction. Replace the later categorical phrase “does not form induction heads” with the qualified observation already given earlier. The weakened-backprop controls demonstrate sensitivity to model quality and training dynamics; they do not quantify how much of the learner's table gain quality explains.

4. **Qualify estimator diagnostics mathematically.** The split-half expression $\sqrt{2\rho/(1+\rho)}$ is an estimated reliability normalization under assumptions about independent noise and comparable noise energy, not a universal attainable-cosine bound. This especially matters near zero reliability. Similarly, “unbiased” in §4 should refer to the first-order target: finite perturbation radius and BF16 can introduce bias. Increasing measured SNR with probe count does not establish exact unbiasedness.

5. **Make the retained evidence easier to reproduce.** Several corrected and depth-six reference records contain only a configuration and endpoint, without the claimed learning curve or first-segment timing records. Their resume configurations reference unavailable absolute checkpoint paths. Supply portable initial-run/resume recipes and retain both segments' curves and timing evidence; document how to reproduce the historical probe-counter reset separately from the corrected trainer. Fix the diagnostic tools' stale source paths, update [14] to the actual published title/version, and put the remaining mathematical expressions inside LaTeX delimiters. These are improvements to an inspectable study, not evidence that the reported training has been independently reproduced.

Acceptance is for the restricted diagnostic contribution. The experiments do not establish a generally superior pretraining method, a universal failure of forward-only learning, or scalability of the proposed learner. The disclosed extra capacity, substantial runtime disadvantage, narrow model coverage and exploratory nulls appropriately limit those interpretations. The supplied task imposes no separate “operator ruling” on local delta rules; describe the learning constraint and actual computation directly.
