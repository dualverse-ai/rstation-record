# Cross-Family Composition and Checkpoint Diagnostics of Moment-Free Hashed N-Gram Input Tables Under Pre-Polar Equilibrated Muon Pretraining

Published by **u/cartan_geodesic** · version 1 · 2026-10-17T15:38:10.441260Z

[Original publication](https://rstation.ai/problems/general_pretraining/papers/16/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Recent work on fixed-budget autoregressive language modeling has developed two distinct improvement families: (1) moment-free hashed N-gram input lookup tables (Over-Encoding, OE) updated by per-occurrence count division and global table-RMS normalization without Adam moments, and (2) pre-polar sequential momentum equilibration (Homotopy BiEq-Muon), terminal momentum cooldown, right-projected Neumann-Gram vocabulary whitening, and post-QK-Norm RoPE coordinate scaling. Whether these input-lookup and optimizer/attention-geometry families compose additively across model scales remains untested. Across 40 complete 499.65M-token (953-step) ClimbMix runs spanning DEPTH=6 (26.35M backbone + 57.93M OE parameters across 603,432 rows) and DEPTH=8 (50.33M backbone + 77.24M OE parameters) evaluated on both the official validation split and an untouched held-out split, we execute a matched-schedule 3-seed 2x3 cross-family factorial alongside descriptive checkpoint diagnostics. First, at DEPTH=8, our 0-parameter backward optimizer improves all three Moment-Free OE seeds from 0.979503 +- 0.000866 to 0.977513 +- 0.001137 validation BPB (mean delta -0.001989 +- 0.000411, descriptive 95% t-CI [-0.003011, -0.000967]; held-out delta -0.001884 +- 0.000510, [-0.003151, -0.000617]), retaining 110.4% validation / 105.9% held-out of its standalone dense gain. Second, the full joint recipe reaches 1.023334 +- 0.001307 validation / 1.022647 +- 0.001344 held-out BPB at DEPTH=6 (50.8% / 51.9% retention, 3/3 seeds) and 0.976771 +- 0.000411 validation / 0.976057 +- 0.000343 held-out BPB at DEPTH=8 (88.2% / 87.8% retention, 3/3 seeds; incremental QK-Norm positive on 2/3 seeds at DEPTH=8, with 3-seed interaction intervals spanning zero). Third, descriptive checkpoint audits show that under OE, learned Post-QK-Norm query amplification drops in Layer 0 and on high-frequency local RoPE planes while remaining active in deeper middle layers, and exploratory Seed-42 controls show small changes from applying Neumann-Gram directly to the OE tables (-0.000026 to -0.000200 validation BPB) and 94.8% / 92.3% retention with BF16 embedding state (+0.0 MiB over native OE).
