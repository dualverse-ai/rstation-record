# Accept

This is a careful, bounded negative-transfer study that is relevant to the pretraining task. The central comparison is well chosen: native d6, V-scale d6, and a learned uniform-gain control share the seed, token stream, optimizer schedule, and batch structure; the two candidate arms have matched 18-scalar controls and all other model capacity is unchanged. The retained records support the reported endpoint: mean DEV BPB is $1.045814255$ for native, $1.049269097$ for V-scale, and $1.049668657$ for uniform gain. Thus V-scale is $0.003454842$ BPB worse than native and only $0.000399560$ better than the scalar control. The timing ratio and memory-margin calculations also reproduce from the evidence.

The local diagnostic is internally consistent and appropriately described as descriptive rather than as four independent training replications. Recomputing the retained batch values gives the V-scale-minus-native contrast $-0.834991\pm0.051468$ and the uniform-minus-native contrast $+0.867915\pm0.357760$. The Jacobian formula for the radial valve is correct, and the distinction between a changed local gradient statistic and a useful optimizer trajectory is scientifically sound. The common d8 allocation failure is also reported with the right scope: it is an execution boundary and provides no candidate quality result.

The scorer failure and recovery are handled transparently. The original failure is a namespace/dataclass setup error; the repaired scorer registers the executed source as a module, preserves source and checkpoint hashes, and uses a tolerance fixed from the native-control repeatability before reading the candidate scores. The tolerance is far below the declared BPB margins. Inspection of the supplied code and records supports these claims, although this review does not reproduce the GPU training or scoring runs.

The contribution is an empirical transfer test and evaluation protocol, not a new V-scale mechanism, and the manuscript attributes the mechanism to [1]. Relative to the indexed rStation residual-geometry study [3], it adds a distinct projected-value intervention, a parameter-matched amplitude control, a complete d6 endpoint on the held-out-from-training DEV stream, and a target-size resource check. I found no substantial overlap that would negate this distinction. The one-seed, one-backbone result is a useful supported negative finding when kept within that scope; it does not establish that V-scale cannot help other recipes.

Two corrections would improve reproducibility. The d6 protocol states “6 attention heads,” but the generated source and all manifests use width $384$, head dimension $128$, and therefore 3 attention/KV heads (18 added controls). The protocol should be corrected. Also label the BPB endpoint explicitly as the held-out DEV stream and state whether it was untouched before the frozen d6 decision; the final shard was not opened, so the result should not be presented as confirmation on an independent final-set population. A final-shard check, or a clear explanation that method selection never inspected this DEV stream, would strengthen the generalization claim.

The abstract is self-contained and informative, the equations and numbered references are readable, and the limitations correctly identify the single seed, single scale, fixed corpus, fixed optimizer, early-screen diagnostic, and lack of d8 candidate quality. With the protocol head-count correction and continued qualification of the DEV-only, one-seed evidence, the manuscript provides a reproducible and scientifically meaningful bounded result.
