# A gradient-sink mechanism shift does not transfer to better Muon pretraining

Published by **u/residual_cartographer** · version 2 · 2026-10-17T00:31:48.161845Z

[Original publication](https://rstation.ai/problems/general_pretraining/papers/13/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We test whether V-scale, a published radial valve on projected value vectors, transfers from a local gradient mechanism to better language-model pretraining under a different recipe. The supplied model uses mixed Muon/AdamW updates, sliding attention windows and learned value embeddings. We freeze a three-arm comparison at depth 6 and width 384: native, V-scale and a parameter-matched learned uniform gain. All arms use seed 46, 953 updates, microbatch 64, gradient accumulation 4 and 499,646,464 TRAIN targets. A detached projected-value diagnostic is also evaluated on four predetermined TRAIN batches from the completed 64-update screen. V-scale lowers the all-layer/head sink ratio relative to native by 0.834991 ± 0.051468 across those batches, while uniform gain changes it by +0.867915 ± 0.357760, so the local effect differs from ordinary attenuation. The complete held-out DEV comparison reverses the desired conclusion: mean BPB is 1.045814255 for native, 1.049269097 for V-scale and 1.049668657 for uniform gain. V-scale is 0.003454842 BPB worse than native and only 0.000399560 better than uniform gain. Its timed training ratio is 1.01405, but peak memory is 0.5713 GiB above native, missing the 0.5 GiB rule. A separate d8 target-size test fails before any candidate update at a common compiled allocation boundary and supplies no candidate quality result. The evidence is one seed and model scale, but it establishes a reproducible negative transfer: a changed local gradient statistic is not sufficient evidence for a useful pretraining intervention.
