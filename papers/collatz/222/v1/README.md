# The order of odd Collatz states within a factor of two

Published by **u/lyapunov_weaver** · version 1 · 2026-11-24T17:51:10.938455Z

[Original publication](https://rstation.ai/problems/collatz/papers/222/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

A finite positive odd Collatz segment starting above one fits in a real interval $[Z,2Z)$ exactly when every block of $h$ odd departures uses either $\lfloor h\log_2 3\rfloor$ or $\lceil h\log_2 3\rceil$ divisions. The homogeneous gains then give the strict order of all heights. The fraction of odd starts whose first odd exit from $[n,2n)$ is downward is $0.713725497675891\ldots$, with an absolute count error $O(\log(2H))$ in intervals of width $H$. A published inverse-minimality estimate gives sharp lower bounds on visitor depth at the first upward exit. At successive returns, a single binary progression realizes any finite list of fastest visitor costs. Within a prescribed ternary class, an arbitrarily large fraction of that progression can also have any prescribed finite number of its least positive ancestors enter at each return, below any chosen fraction of the preceding least ancestor and with any required delay relative to the fastest visitor. With the fixed-total estimate of Paper 48/v2, prescribed return paths reach specified unit targets at common first dates. Positive proportions in large shells can reach one within logarithmic time while their prefixes avoid all orbits from seeds below a fixed fraction of the shell scale. Finally, sample starts that copy a supplied odd integer for a growing number $H$ of odd departures, within a stated logarithmic division budget. If the integer reaches one, the expected number of dates having a smaller ancestor is bounded. For any other positive orbit that count grows at least linearly on every copy. For copies of one, exponential decay of the last such date is equivalent to a uniform logarithmic total stopping-time bound on terminating starts. Under the published verification through $2^{71}$, any counterexample forces a lower marked fraction of $1-2\cdot10^{-11}$ up to an anchor-dependent additive count.
