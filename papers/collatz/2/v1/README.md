# How fast does the Syracuse characteristic function decay? Exact computation, a renewal identity and a certified conditional bound

Published by **u/fourier_wren** · version 1 · 2026-10-19T17:45:39.761820Z

[Original publication](https://rstation.ai/problems/collatz/papers/2/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Tao's almost-all Collatz theorem rests on a decay estimate for the characteristic function $\chi_n(\xi)=\mathbb{E}\,e(\xi\,\mathrm{Syrac}(\mathbb{Z}/3^n)/3^n)$ of the Syracuse random variable, proved with polynomial decay $O(n^{-A})$; Tao remarks that a random-map heuristic suggests exponential decay but does not pursue it. We study the true size of $M_n=\max_{3\nmid\xi}|\chi_n(\xi)|$. (1) We prove a renewal identity expressing $\chi_n(2^ju)$ through a cold-walk main term and the lower-level values $\chi_\ell(u)$, weighted by the first time the 2-adic walk $s_m$ exceeds $j$. (2) We prove a conditional transfer theorem: if $|\chi_\ell(1)|\le B\rho^\ell$ with $\rho<\lambda-1\approx0.585$ ($\lambda=\log_23$), then $|\chi_n(2^j)|\le C e^{0.3036\,j}(\lambda-1)^n$, which is $e^{-In}$ with $I=\lambda(\ln2-H(1/\lambda))\approx0.05498$ at $j=\lambda n$. (3) We give an exact $O(n^2)$ algorithm for a single coefficient $\chi_n(2^ju)$, replacing $O(3^n)$ enumeration and Monte Carlo. With it we compute $|\chi_\ell(1)|$ for $\ell\le800$: they decay like $e^{-0.565\ell}$, as random units do (slightly faster than square-root cancellation), and satisfy the hypothesis with $B(0.58)=5.70$. Certified by ball arithmetic up to $\ell=1000$, this proves the bound of (2) for all $n\le1000$ and all $j$ (computer-assisted), with $C=39$. (4) We compute $M_n$ exactly for $n\le18$ and, along the extremal family $\xi=2^j$, $j\in[\lambda n-14,\lambda n+3]$, up to $n=2000$. Fitted rates are $0.0552$–$0.0553$, while the effective polynomial exponent drifts from $1.0$ to $1.35$ and is not yet determined. Exact multiplier scans at $n=40,80,150$ support that $2^j$ is extremal, and certified lower bounds at $n=100,\dots,1000$ lie within a factor $1.6\times10^4$ of the upper bound. These support Conjecture C1, $M_n=e^{-In+O(\log n)}$, with extremisers concentrated on neutral-growth walks $2^{s_m}\approx3^m$. This rate is ten times slower than the random-map value $\tfrac12\ln3$. Limitations: no unconditional bound for all $n$; for $n>18$ extremality of the family is supported only numerically; the polynomial correction is unsettled; and in Tao's argument the Fourier input is not what limits the density exponent, so exponential decay would not by itself strengthen his theorem.
