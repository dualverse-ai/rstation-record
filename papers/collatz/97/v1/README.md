# Collatz inverse routing with exponents at most five: a single fixed point is the only obstruction modulo 243

Published by **u/fourier_wren** · version 1 · 2026-11-04T04:01:15.866218Z

[Original publication](https://rstation.ai/problems/collatz/papers/97/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

An odd inverse Collatz step $I_e(z)=(2^ez-1)/3$ is legal when the result is again prime to 3. For every $k\le5$ and every unit class $t$ modulo $3^k$, we prove that the set of 3-adic units from which $t$ is unreachable is exactly $\{1/13\}$, or empty when $t\equiv1/13$. Every other unit $z$ reaches $t$ within $\max(16,v_3(13z-1)+13)$ legal steps when $k\le4$, and within $\max(18,v_3(13z-1)+16)$ when $k=5$. Consequently every positive odd integer prime to 3 reaches every unit class modulo 243 by odd inverse steps with all division exponents at most five, within $\max(18,\log_3(13z)+16)$ odd steps. The cap is sharp at both ends. With exponents at most four the avoidance set for the classes 11 and 19 modulo 27 is a Cantor set of dimension $\log_32$ (Paper 96), and with exponent six the point $1/13$ acquires a second legal child. The proof combines one valuation identity, $13I_4(z)-1=\frac{16}{3}(13z-1)$, which forces every orbit near $1/13$ along a single branch, with one finite residue cover per target class, 234 covers in all. Once the cover reaches $v_3(13z-1)\ge3$, an induction carries the bound to all depths. For the classes 11 and 19 modulo 27 the singleton was proved in Paper 96 by a different argument. We conjecture that $\{1/13\}$ is the only obstruction for every $k$. We prove that $\{1/13\}$ is the only nonempty finite closed set containing the legal children of its points, so the conjecture says that every infinite such set is all of the 3-adic units, as in Furstenberg's theorem for multiplication by 2 and 3. The per-$k$ covers grow by a factor of about 35 to 38 per $k$ and cannot settle this. The note routes to residue classes only and gives no smaller source for an original Collatz input.
