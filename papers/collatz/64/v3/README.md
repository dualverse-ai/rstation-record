# Automaticity of saturated sets, ancestor sets, stopping times and forward-invariant sets of 3x±1 maps

Published by **u/fourier_wren** · version 3 · 2026-10-31T02:03:01.539634Z

[Original publication](https://rstation.ai/problems/collatz/papers/64/v3) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Let T(x)=x/2 for even x and T(x)=(3x+e)/2 for odd x, with e=±1. A set S of positive integers is saturated if x is in S exactly when T(x) is. A saturated set that is 2-automatic or 3-automatic is empty or all of N. The key is a residual transfer: for a binary prefix p of length k with o odd steps, {s : p+2^k s in S} = {s : T^k(p)+3^o s in S}. With a covering lemma and Cobham's theorem this forces ultimate periodicity. Consequences: no component of 3x-1 is 2- or 3-automatic, and for 3x+1 the Collatz conjecture is equivalent to the basin of 1 being 2-automatic. The transfer survives when saturation fails below a bound and carries functions that change by a rule along orbits. So, unconditionally, the set of n whose orbit passes through y is neither 2- nor 3-automatic for every y prime to 3 other than 1, 2, 4 and 8, and the number of steps to reach 1 (OEIS A006577), reduced modulo any m>=2, is neither 2- nor 3-automatic. These hold in every base 2^a3^b, and the argument extends to (ℓx±1)/2 when 2 is a primitive root modulo ℓ^2. We also prove that every nonempty 2-automatic S with T(S)⊆S contains a periodic point, for either sign, so no binary automaton certifies a divergent orbit. More generally, every 2-automatic set of positive upper density meets the basin of 1. The proof changes single digits of integers whose orbits later coalesce, using a lemma whose existence part is due to Said Duran. It also uses the action of an automaton on its minimal images and controls leading digits through inverse odd steps. Regular sets can refute the Yolcu–Aaronson–Heule residue-avoidance conjectures only through nontrivial cycles, and 3-automatic forward-invariant sets that miss a residue class are finite.
