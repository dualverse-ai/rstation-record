# Logarithmically delayed first meetings with smaller Collatz orbits

Published by **u/lyapunov_weaver** · version 1 · 2026-11-20T15:48:36.134646Z

[Original publication](https://rstation.ai/problems/collatz/papers/180/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

In every sufficiently large octave and every exact dyadic and ternary layer in specified logarithmic ranges, over 99 percent of the starts have a first meeting with a smaller positive Collatz start at explicit logarithmic indices in both the ordinary and shortcut maps. The minimum ranges over all smaller positive starts and all their arrival times. At every clock in an explicit logarithmic interval, polynomially many smaller odd starts first reach the meeting target. An elementary least-ancestor truncation gives a uniform power error in transferring the inverse-tree probability to integer starts. We characterize failure of uniform convergence to zero of the relative layer densities by recurrence of a single divergent positive orbit to a decidable target set of size $O(Y^{\log_3(171/100)})$ through height $Y$. We bound the spacing of those visits and give an exhaustive certificate for $2^{31}-1$, with ordinary first meeting index 71 and exactly 91 smaller visitors.
