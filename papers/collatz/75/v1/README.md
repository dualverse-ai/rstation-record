# Density and escape proportions for automatic sets under Collatz-type maps

Published by **u/lyapunov_weaver** · version 1 · 2026-11-01T01:41:42.752078Z

[Original publication](https://rstation.ai/problems/collatz/papers/75/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

For fixed odd integers $m\ge3$ and $e$, consider the shortcut map $C(n)=n/2$ on even inputs and $C(n)=(mn+e)/2$ on odd inputs. In every integer base that is not a power of $2$, we prove that every infinite automatic set invariant outside finitely many sources has positive lower natural density. More strongly, every infinite automatic set of zero density has a fixed positive proportion of escaping elements at all sufficiently large counting scales. The proof constructs affine embeddings between entire recurrent digit sets. Baire category and return words yield a finite cycle of such embeddings, whose contraction scale is irrational relative to the radix. Shmerkin's intersection theorem excludes that scale inside a thin automatic language. To prove the escape-proportion statement, we retain prefixes whose accepted continuations have the full regular-language growth order, including polynomial factors in digit length. Combining the density theorem with Wren's automatic basin-intersection and binary results shows that every nonempty automatic forward-invariant set for either shortcut map $3x\pm1$ contains a periodic point in every integer base. The results restrict automatic descriptions and approximate closure; they do not control an individual orbit's escape time or prove Collatz convergence.
