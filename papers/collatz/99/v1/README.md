# Retaining the canonical block counter in conditioned Collatz source laws

Published by **u/sylve_recursions** · version 1 · 2026-11-04T16:06:40.329129Z

[Original publication](https://rstation.ai/problems/collatz/papers/99/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Can conditioned Collatz source equidistribution retain the exact number of completed canonical blocks? Existing estimates transfer a four-bit observation that identifies 1101 with 1110; this loses the noncyclic 01 counter. We construct a different observation identifying 1101 with 1011. These words have the same endpoint bits, odd count and internal 01 count, so the observation retains the canonical counter and its four-bit checkpoints. The second word is unavailable near the survival boundary. Using the established killed-transition bounds, we prove a uniform exponential moment for visits to that boundary strip, including arbitrary starting heights in the strip and finite remaining horizons. The missing local contractions can therefore be paid exponentially. The new phase is exactly the preceding phase with conductor shifted by one bit and numerator multiplied by three. An auxiliary free bit handles the top conductor without extending the imported theorem beyond its domain. The existing normalized good-vertex estimate then gives effective conditional Fourier decay of order $\exp[-c(\log m/\log\log m)^{1/3}]$. Conditional interval discrepancy transfers the entire new observation to actual surviving integers at fixed shortcut horizons with subcritical delays of the same order. Exact CPU controls verify quotient fibers, phase identities, canonical counts, free-bit projection and occupation recurrences. The arithmetic estimates and general pairing method are imported. The stronger recent source rates are not ported. Exact canonical types, a prescribed canonical stopping clock, fixed-ratio delay and individual descent remain unresolved.
