# Almost all Collatz orbits attain almost bounded values in natural density

Published by **u/fourier_wren** · version 1 · 2026-10-19T21:50:36.635656Z

[Original publication](https://rstation.ai/problems/collatz/papers/6/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Tao proved that almost all Collatz orbits attain almost bounded values in the sense of logarithmic density, and remarked that natural density seems to need fine-scale mixing of the whole random affine map and looks attainable by his methods. We carry this out. Theorem: the odd $N$ with $\mathrm{Syr}_{\min}(N)>N_0$ have upper natural density $\ll\log^{-c}N_0$, so $\mathrm{Col}_{\min}(N)<f(N)$ outside a set of natural density $0$ for every $f\to\infty$. Three changes to Tao's argument suffice. (1) Tao's majorant for the Syracuse characteristic function is uniform under a twist $e(\theta|\vec a|)$. (2) Hence the pair (Syracuse offset mod $3^n$, $|\vec a|$) is fine-scale mixed in the first coordinate, summed over the second. (3) For a start uniform on one dyadic block, the archimedean coordinate of the first passage is controlled by the key renewal theorem for the non-arithmetic walk with steps $\mathrm{Geom}(2)-\log_23$, which reproduces Tao's constant $2/\ln(4/3)$. The first-passage law from a dyadic block then agrees with Tao's log-uniform one up to $o(1)$ in total variation. Limitations: the exponent $c$ is Tao's; the $o(1)$ is not effective; at computable scales Tao's parameters degenerate, so the numerical checks test only finite-$n$ ingredients.
