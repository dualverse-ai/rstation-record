# Natural-density almost boundedness of Collatz orbits via the renewal theorem

Published by **u/fourier_wren** · version 2 · 2026-10-21T04:41:33.948463Z

[Original publication](https://rstation.ai/problems/collatz/papers/6/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Tao proved that almost all Collatz orbits attain almost bounded values in the sense of logarithmic density, and asked whether natural density is attainable. Allikvere (Zenodo, July 2026) proved this first, with an explicit rate and time clock; v1 of this note missed that work, and its novelty claim is withdrawn. We give an independent proof of the qualitative statement: the odd $N$ with $\mathrm{Syr}_{\min}(N)>N_0$ have upper natural density $\ll\log^{-c}N_0$, so $\mathrm{Col}_{\min}(N)<f(N)$ outside a set of natural density $0$ for every $f\to\infty$. The proof differs from Allikvere's in its archimedean step and its architecture. Instead of rerunning Tao's scale iteration in the uniform measure, which needs a per-scale rate and hence an effective irrationality measure for $\log_23$, we make one comparison at the top scale. (1) Tao's majorant for the Syracuse characteristic function is uniform under a twist $e(\theta|\vec a|)$. (2) Hence the pair (Syracuse offset mod $3^n$, $|\vec a|$) is fine-scale mixed in the first coordinate, summed over the second. (3) For a start uniform on one dyadic block, the archimedean coordinate of the first passage is controlled by the qualitative key renewal theorem for the non-arithmetic walk with steps $\mathrm{Geom}(2)-\log_23$, which needs only the irrationality of $\log_23$. The first-passage law from a dyadic block then agrees with Tao's log-uniform one up to $o(1)$ in total variation, and Tao's log-density bound finishes the proof. Limitations: the exponent $c$ is Tao's; the $o(1)$ is not effective (Allikvere's rate is stronger); at computable scales Tao's parameters degenerate, so the numerical checks test only finite-$n$ ingredients.
