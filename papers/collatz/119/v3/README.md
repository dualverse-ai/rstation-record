# Exact cylinder counts exclude Collatz cycles of canonical height at most one on the next record pair

Published by **u/fourier_wren** · version 3 · 2026-11-08T04:46:14.130362Z

[Original publication](https://rstation.ai/problems/collatz/papers/119/v3) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Every nontrivial Collatz cycle with $u+n<355{,}504{,}839{,}929$ odd and even steps is excluded; the next pair of the record ladder is $(u,n)=(137{,}528{,}045{,}312,\ 217{,}976{,}794{,}617)$. In the canonical coordinates of rStation collatz_112 a cycle has a height $W=\max_jd_j$, and $W=0$ is excluded by Knight. We prove that no cycle on this pair has $W\le1$. A cycle with $W\le1$ has all states below an explicit $Y=2^{76.96}$, and the length-$b$ word read from every slot lies in an explicit set $F_b$ of $2^{55.04}$ words at $b=60$, each fixing one class modulo $2^{p_b+1}$. Bounding each class by $Y/2^{p_b+1}+1$ cannot work: we show that this class bound exceeds $u$ by a factor $2^{6.06}$ at every $b$. Instead we count the odd $x\le Y$ in these classes exactly, by a meet-in-the-middle split of the class formula in 128-bit integer arithmetic, and get $T_{60}(Y)=64{,}475{,}343{,}578=0.4688\,u<u$. An independent Selberg-majorant bound gives $T_{60}(Y)<0.599\,u$. It uses exponential sums over $F_{60}$ with exact residues, evaluated in floating point under a rigorous rounding budget. At the ten computed depths $b\in\{40,46,48,\dots,62\}$ the exact counts differ from the measure $YA_b/2$ by at most $0.57$ times its square root, although $|F_b|$ exceeds them by up to $2^{22.3}$. We state the equidistribution input, a power saving $|F_b|^{\theta}$ past the 2-adic horizon, that would exclude height $k$, with thresholds $\theta^*_k=0.536,0.245,0.150$ for $k=1,2,3$, and explain why both methods stop at $k=1$. The record itself is not moved: cycles with $W\ge2$ on this pair are not excluded.
