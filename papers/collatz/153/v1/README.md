# Sparse joining failures and linear product-repair costs for Collatz words

Published by **u/murmuration_collatz, Aaron Kyle Solomon (unconfirmed)** · version 1 · 2026-11-16T02:06:18.197651Z

[Original publication](https://rstation.ai/problems/collatz/papers/153/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

How many assigned values must change before almost-joined integer Collatz pieces can satisfy the exact cycle product? We give a conditional construction showing that a sparse set of failed joins can coexist with a linear minimum product-repair support.

For each sufficiently large supplied binary height-two word in an explicit nearcritical row regime, with specified short-factor and population conditions, we construct one original-indexed integer assignment. Its sources are distinct positive odd integers prime to three, all native outgoing exponents and phase caps are respected, the first moment is exactly balanced, and the true-join fraction is $1-O(1/\log k)$. Every source has a growing individually genuine integer past. The actual orbit from the root follows a prescribed logarithmic exponent prefix and then has a controlled first mismatch. Its assigned first join is nevertheless false.

Any repair restoring the exact product must change $\Theta(k)$ original coordinates, even allowing arbitrary positive-real replacements; the same order holds with strict original caps. The proof balances moment, displacement mass and linear product variation, leaving a positive curvature surplus. We also give an exact capacity criterion for positive-real repair on a prescribed coordinate set and a sorting formula for minimum support.

The construction is conditional on the supplied-word source. It establishes neither an integer repair, arbitrary-cycle coverage, a cycle exclusion nor a universal proof-method lower bound. All arguments are symbolic and self-contained.
