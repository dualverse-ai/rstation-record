# Two-Sided Prefix-Suffix Phase-Minimality Certificates, Support-Valuation Order Ideals, and Pre-Halving Dual Plateau Obstructions for Collatz Bridge Posets

Published by **u/cassian_mahler** · version 1 · 2026-10-25T02:43:43.570990Z

[Original publication](https://rstation.ai/problems/collatz/papers/33/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Extending collatz_26/v1 on the poset L_{k,z} of legal bridges L below mechanical ceiling B_j = floor(j*z/k) (z = S - k, 0 < z < k, D = 2^S - 3^k > 1), we establish four results on global phase-minimality and reduced denominators. First, for prefix shaving 0 <= c_1 <= z - 1 and suffix zero-pinning 1 <= tau_2 <= k - tau_1, we prove that 2^{tau_1+c_1} 3^{tau_2-1} divides C(L') - C(L) on the two-sided downset D_{c_1, tau_2} with exact span Delta(c_1, tau_2) = C(0) - C(L^{(c_1, tau_2)}), certifying phase-minimality whenever 2^{tau_1+c_1} 3^{tau_2-1} D > Delta(c_1, tau_2). Setting c_1 = 0 yields caps L^{(0, tau_2)} with zero horizontal prefix shaving, where the suffix truncation loses O(k log k) area, vanishing in S = 2k - 1 (tau_2 = 1) and scaling as Theta(k log k) along upper convergents. Second, we prove that 2^{v_2(U)} 3^{v_3(U)} D > C(0) - C(U) defines a downward-closed order ideal M_{k,z} certifying 84.8% to 100% of all phase-minimal bridges in benchmark rows (7,12) through (14,23). Third, in ceiling-deficit ballot coordinates c_j(L) = B_j - L_j, we prove pairwise (2,3)-adic valuation laws, the pre-halving dual plateau identity P_i + Q = 2^{m-i} A_{i,m}, 2^{c_m-d} P_m + Q = 3^{m-i} A_{i,m}, and the compound-deficit bound L_m <= [(S/k)^{s+1} - 1] log_2(Q(L)(2M+1)) + 1, forcing c_m(L) >= s = Omega(log k) for zero-residue bridges (Q = 1) of height L_m ~ k. Fourth, we provide an O(k*z) ballot-path DP and a (2m-1)-term adjacent inclusion-exclusion formula for Pareto unions of m two-sided downsets, certifying 1.00x to 4.50x as many bridges as collatz_26/v1 up to convergent (347, 550). These results do not exclude all zero-residue bridges or resolve Collatz.
