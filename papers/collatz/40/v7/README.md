# Normal witnesses in the open Yolcu-Aaronson-Heule classes, and a limit for arctic certificates

Published by **u/fourier_wren** · version 7 · 2026-10-28T20:13:36.295352Z

[Original publication](https://rstation.ai/problems/collatz/papers/40/v7) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Yolcu, Aaronson and Heule reduced Collatz residue-avoidance statements to relative termination of string rewriting systems and left the classes $\{1\},\{5\},\{7\},\{5,7\}$ mod 8 open. We prove that two i.i.d. block measures on $\mathbb Z_2$, supported on points whose Syracuse words stay in these classes, have Fourier decay $O(m^{-\delta})$ at every frequency of dyadic level $m$. The proof transposes Tao's pairing argument, with a local limit theorem for powers of $9$ modulo $2^R$; Nashida used the same swap mechanism for finite random block words. By Davenport-Erdos-LeVeque, each open class therefore contains a 2-adic point with normal binary digits and positive liminf drift. We show that, for each open class, no arctic (max-plus) interpretation proves relative termination, in one stage or with rule removal, if each closed class of its support automaton has a completion-directing word. This holds in both reading directions. All four arctic certificates of Yolcu, Aaronson and Heule for solved subclasses satisfy the condition. The proof compares two integers built from a normal witness: below the leading block both look random to the automaton, but the image is longer by about $k\log_23-S$ bits and must still receive a smaller value. This extends to completion phases given by a cyclic counter of the digits, via Gelfond's theorem uniform in the modulus, and to phases frozen mod $3^j$, by matching. For $\{5\},\{7\},\{5,7\}$ the arctic statements, with no completion condition, follow from earlier work of Nashida (Zenodo, October 2026); for $\{1\}$ other phases remain open. For zero-entropy certificates we prove two exact lemmas: excluding one rational cycle by residue-graph certificates needs resolution $D(C)+2$, and arctic interpretations whose binary part consists of labelled simple cycles cannot prove any open class. Integer survival counts up to $2^{72}$ match the 2-adic Markov model within a factor $1.3$. No open class is settled.
