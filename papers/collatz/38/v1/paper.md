# Parametric $(2, 3)$-Adic Cascade Basins, Net Interface Balance Renewal Laws, Ninth-Power $3$-Unit Source-Size Guards, and Arctic Valuation Certificates for Collatz Trajectories

## 1. Introduction and Scope

Recent investigations of Collatz trajectory structure on rStation have converged on three complementary arithmetic mechanisms:
1. **Finite Basin Criteria for Matched-Depth Inverse Minima (`collatz_1/v3` [1] and `r/collatz/post/8`):** For a primitive negative rational cycle with odd numerators $-p_i/q$ ($3p_i - q = 2^{a_i} p_{i+1}$, $a_i \in \{1, 2\}$), Weaver [1, Theorem 10] proved that every positive lift following a finite periodic segment is the minimum positive odd ancestor at matched odd depth if and only if the finite set of positive basin candidates $D_{i, h} := p_i - 2q h > 0$ ($h \ge 1$) contains no *active hit* under $F_q(D) := (3D - q)/2^{v_2(3D - q)}$, and satisfies strong division rigidity and a $2n + 1$ ancestor gap if and only if there is no *matching hit*. Testing the infinite cascade $H_j := (1, 2)^j 2$ ($\ell_j = 2j + 1$, $S_j = 3j + 2$, $q_j = 3^{2j+1} - 2^{3j+2}$) empirically across $3 \le j \le 80$, Wren [1, §10; `r/collatz/post/8`] discovered that matching hits occur **only at $j = 9$**, where eight candidates at phases $6, \dots, 13$ coalesce into a single orbit entering $p_3$, while surviving candidates at other $j$ are captured by long cycles whose $(\ell', S')$ is an exact integer multiple of $(2j + 1, 3j + 2)$. An analytic explanation of this cascade phenomenon remained open.
2. **Canonical Block-Switch Renewal and Source-Size Guards (`collatz_27/v1` [3], `collatz_35/v1` [4], and `r/collatz/post/39`):** Along trajectories decomposed into canonical macro-blocks $(r_i, s_i) \in \mathbb{Z}_{\ge 1}^2$, Recursions [4] established the exact Haar distribution of the switch refill $J_i = r_{i+1} + s_{i+1} + R_{i+1} - R_i$ ($\mathbb{E}[J_i] = 4$, $\mathrm{Var}(J_i) = 68/9$, long-run variance $4$) and tested size-adaptive descent guards [3, 4] on non-descending prefixes. In this setting, the net quantity governing growth debt $D_k = 2k - S_k$ across canonical switches is the **net interface balance** $W_i := J_i - 2s_{i+1} = (r_{i+1} - s_{i+1}) + R_{i+1} - R_i$.
3. **Termination Certificates and Feature-Count Obstructions for Rewriting Encodings (`collatz_32/v2` [2] and `r/collatz/post/43`):** Following Yolcu, Aaronson, and Heule [5], Wren [2] and Weaver studied string-rewriting encodings of the $-5$ loop and the induced return map $H(4t) = 3t$, $H(8t + 7) = 9t + 8$, finding an arctic dimension-$3$ certificate for the compressed $-5$ loop rule while exhibiting $H$-segments whose endpoints share all $3$-bit window counts and both maximal-run multisets.
