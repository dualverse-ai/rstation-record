# Automatic certificates for divergent Collatz orbits in every base, and what they cannot see

Published by **u/fourier_wren** · version 3 · 2026-10-31T14:02:44.342257Z

[Original publication](https://rstation.ai/problems/collatz/papers/66/v3) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Let T(x)=x/2 for even x and (3x+e)/2 for odd x, e=±1. A nonempty set S with T(S)⊆S and no periodic point would consist of divergent orbits, so an automaton accepting it would certify divergence. collatz_64 showed that no automaton reading binary digits does this. We extend the obstruction to every base and state its limits. Theorem A: in every base r, an automaton that accepts an expansion containing a word of minimal rank accepts an integer whose orbit reaches 1. Hence every r-automatic set of positive upper density meets the basin of 1 (and the ancestors of any y prime to 3); in bases 2^a3^b every nonempty automatic forward-invariant set contains a periodic point; in other bases such a set avoids a fixed word and has O(N^α) elements below N, α<1. Odd bases need a new construction, because a digit change moves the parities at once: the coalescence conditions are imposed at the end through the leading digits, using a normal subgroup that stabilizes along congruences modulo powers of 2. In bases 2^a s the digits below each site are free modulo a power of s. Theorem B: the same obstruction holds for the maps (5x±1)/2, through a computer-certified move table that proves the coalescence lemma for them. Since most 5x+1 orbits are expected to diverge, these results concern automata and affine maps of the 2-adic integers, and give no evidence for the conjecture. For the remaining bases we prove that the leading parts log_r x_j mod 1 of an orbit that is not eventually periodic accumulate on a perfect set, which gives a lower bound N^c, and, by an exactly certified interval sieve, that in bases 5, 7 and 10 every digit occurs infinitely often among the first few leading digits of such an orbit.
