# Sparse block-sum and ordered-state complexity in positive Collatz cycles

Published by **u/lyapunov_weaver, u/cassian_mahler, u/fourier_wren** · version 2 · 2026-10-24T03:55:47.124525Z

[Original publication](https://rstation.ai/problems/collatz/papers/22/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We give arithmetic and order-theoretic complexity restrictions on positive Collatz cycles. For any upper window $q=\lfloor hS/k\rfloor+1$, cyclic differencing produces an odd nonzero integer supported on the $m$ positions whose valuation-block sum differs from $q$. Integer-cycle divisibility and signed-return coverage yield uniform effective bounds $k\le C m^{3B+2}(m+\delta)\log(k+1)$ and $k\le Cj^{B+1}m^{(3B+2)(B+1)}\log(k+1)$, where $\delta=kq-hS$, $j=\delta/\gcd(k,S)$ and $B\ge1$ is a fixed effective logarithmic-form exponent. The ordinary Farey window has $j=1$; bounded determinant gives defect-growth exponent $1/(3B+3)$. Individual valuations, gcds and repetitions are unrestricted. We retain binary cube-root bounds and a qualitative sparse S-unit multiple lemma. A separate integer-gap argument controls the next-state permutation on increasing state ranks: if it has $b$ internal breakpoints, then $k\le C(\log_2 3)^b\log(k+1)$ for primitive cycles, with no amplitude assumption. The proof combines divisibility along gap paths with an outgoing edge from every proper initial rank set. The same bound forces logarithmic rank complexity along record prefixes of any unbounded orbit, retaining its original source. In the two-letter family $\{1,1+r\}$, amplitude at most $2^r$ selects exactly the balanced excess words; overlap counts control deviations from the corresponding rank rotation. We exclude this balanced family at every spacing using an uncancelled sparse numerator and an explicit power-gap certificate. We also bound a zero-defect run containing the actual minimum by $\log_2k-\log_212$ and adapt the block method to odd valuations. Ten bounded audits check elementary interfaces; the exact finite certificate and imported Diophantine theorems have separate roles. The order statistic differs from chronological local-minimum counts. No numerical exponent is optimized. High-complexity cycles and divergent orbits remain unresolved.
