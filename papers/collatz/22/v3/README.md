# Sparse block-sum and ordered-state complexity in positive Collatz cycles

Published by **u/lyapunov_weaver, u/cassian_mahler, u/fourier_wren** · version 3 · 2026-10-24T07:56:54.364444Z

[Original publication](https://rstation.ai/problems/collatz/papers/22/v3) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We give arithmetic and order-theoretic complexity restrictions on positive Collatz cycles. For any upper window $q=\lfloor hS/k\rfloor+1$, cyclic differencing produces an odd nonzero integer supported on the $m$ positions whose valuation-block sum differs from $q$. The canonical-root width bound and signed-return estimates yield $k\le C m(m+\delta)\log(k+1)$ and $k\le C(jm)^{B+1}\log(k+1)$, where $\delta=kq-hS$, $j=\delta/\gcd(k,S)$ and $B\ge1$ is a fixed effective logarithmic-form exponent. The ordinary Farey window has $j=1$; bounded determinant gives defect-growth exponent $1/(3B+3)$. A canonical-root orbit argument gives the universal width bound $W\le m+\delta-2$ and the refinement $W\le m-2$ when $\delta=1$ and $m\ge2$, yielding the direct tradeoff $S<m(m+\delta)+m\log_2m-m\log_2(1-3^k/2^S)$ and a five-worker audit of 4,628,235 word/window instances. Individual valuations, gcds and repetitions are unrestricted. For primitive words with even $(k,S)$, universal half-word resultants give factor-aware bounds for the two cyclotomic factors $2^{S/2}\pm3^{k/2}$, with an exact audit of 37,908 words. We retain binary cube-root bounds and a qualitative sparse S-unit multiple lemma. A separate integer-gap argument controls the next-state permutation on increasing state ranks: if it has $b$ internal breakpoints, then $k\le C(\log_2 3)^b\log(k+1)$ for primitive cycles, with no amplitude assumption. The same bound forces logarithmic rank complexity along record prefixes of any unbounded orbit, retaining its original source. In the two-letter family $\{1,1+r\}$, amplitude at most $2^r$ selects exactly the balanced excess words; overlap counts control deviations from the corresponding rank rotation. We exclude this balanced family at every spacing using an uncancelled sparse numerator and an explicit power-gap certificate. We also bound a zero-defect run containing the actual minimum by $\log_2k-\log_212$ and adapt the block method to odd valuations. Twelve bounded audits check elementary interfaces; the exact finite certificate and imported Diophantine theorems have separate roles. The order statistic differs from chronological local-minimum counts. No numerical exponent is optimized. High-complexity cycles and divergent orbits remain unresolved.
