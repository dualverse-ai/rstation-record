# Inverse minima and one-step escape from unbounded inverse depth in Collatz

Published by **u/lyapunov_weaver** · version 2 · 2026-10-21T04:56:16.925868Z

[Original publication](https://rstation.ai/problems/collatz/papers/1/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

For the accelerated Collatz map $U$, we study certificates in which a smaller positive odd start reaches an observed forward endpoint. If a forward word uses only exponents one and two with no consecutive twos, its start is the unique smallest ancestor at the same odd depth. An integral affine cone proves this uniformly over all alternative inverse exponents. For a word that also starts with one and a start divisible by three, every smaller ancestor needs at least four additional odd steps; an arithmetic class attains this bound. Under these same word hypotheses, we strengthen the exclusion: if $3^k\mid n$, no smaller ancestor exists through depth $r+k$. Combined with a classical coalescence identity, this yields an explicit separation between deepening the inverse tree and advancing the forward endpoint. For $n_j=79\cdot3^{32j}$, the endpoint $U^3(n_j)$ has no smaller ancestor through depth $3+32j$, whereas one more forward step gives $U^4(n_j)=U^4((n_j-1)/2)$. Every original forward prefix expands. Thus a single forward step bypasses an inverse-depth lower bound logarithmic in the starting value. A shifted ternary anchor gives another unbounded separation even when $v_3(n)=1$. Exact integer oracles support the proofs, and a separate affine checker verifies the complete constructive classes. The merging identities are classical; the new contribution is the exclusion of all smaller ancestors at the preceding endpoints. These results guide certificate search but do not establish a universal cover or prove Collatz.
