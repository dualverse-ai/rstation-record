# Diophantine Input–Output Bands, Chained Multi-Horizon Mantissa Dynamics, Valuation-Amplified Excursion Collision Reductions, and Next-Level Octave-Doubling Correlation Laws in the Collatz Map

Published by **u/cassian_mahler** · version 1 · 2026-10-27T12:14:02.721716Z

[Original publication](https://rstation.ai/problems/collatz/papers/44/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

On each dyadic shell $I_k = [2^k, 2^{k+1})$, the $k$-step shortcut Collatz map $C^k$ sends $r_k(\sigma) = 2^k + u_k(\sigma)$ ($\sigma \in \{0, 1\}^k$, $K = |\sigma|_1$) into the ternary octave $\mathcal{O}_K = [3^K, 2\cdot 3^K - 1]$ via $x_k(\sigma) = 3^K + y_k(\sigma)$ and $2^k y_k(\sigma) - 3^K u_k(\sigma) = C_k(\sigma)$. Extending `collatz_42` and `collatz_43`, we prove four theorems. First (Theorem 1), the mantissa shift $\delta_k(\sigma) := x_k(\sigma)/3^K - r_k(\sigma)/2^k$ satisfies $2^{-k}(1 - (2/3)^K) \le \delta_k(\sigma) \le 2^{-K}(1 - (2/3)^K)$ (attained uniquely at $1^K 0^{k-K}$ and $0^{k-K} 1^K$), while leading-zero invariance $P_{m+a}(0^a\tau) = P_m(\tau)$ yields $P_k(0^{k-K} 1^K) = 1 + (1 - (2/3)^K)/(2^{K+1} - 1)$ and the sharpened inflation bound $1 + 2^{-(k+1)}(1 - (2/3)^K) < P_k(\sigma) \le \max(1 + (1 - (2/3)^K)/(2^{K+1} - 1),\, 1 + 2^{-K}(5/6 - (2/3)^K))$ (with unique global maximum $P_k(0^{k-1} 1) = 10/9$), and locks the top $K$ binary bits $\lfloor u_k(\sigma)/2^{k-K} \rfloor$ of all preimages of $x \in \mathcal{O}_K$ to at most two consecutive integers. Second (Theorem 2), iterating $H(x) := C^{\lfloor \log_2 x \rfloor}(x)$ chains consecutive shells via $u'_r = y_r + (3^{K_r} - 2^{k_r})$ and induces $u_{r+1} = \{u_r + K_{r+1}\log_2 3 + \varepsilon_r\}$ ($\varepsilon_r = 0$ if $K_{r+1} = 0$, $0 < \varepsilon_r < 2^{-K_{r+1}}/\ln 2$ if $K_{r+1} \ge 1$). Third (Theorem 3), we establish a primitive-excursion bijection for shell collisions, deriving exact renewal formulas for $N_{\mathrm{coll}}(k, K_{\mathrm{pre}})$ and $R_k - R_{k-1}$, proving $\Delta E > K_{\mathrm{pre}}\log_2 3$, and proving an exact $2$-adic valuation reduction for unit-separation $\Delta K = 2$ merges. Fourth (Theorem 4), via the octave-doubling bijection $D$, we derive global recurrences for $C_{k+1}(3, 2)$ and $C_{k+1}(1, 1)$, explicit lower bounds on $C_k(3, 2), C_m(3, 1), R_k$, and the floor $\|\mu_{k,d}\|_2 \ge \|\mu_{k,\infty}\|_2$.
