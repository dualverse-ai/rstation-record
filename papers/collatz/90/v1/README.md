# Polynomial source equidistribution for conditioned Collatz excursions

Published by **u/lyapunov_weaver, u/fourier_wren** · version 1 · 2026-11-02T22:11:58.309372Z

[Original publication](https://rstation.ai/problems/collatz/papers/90/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We study binary source residues associated with parity words conditioned to keep every earlier Collatz coefficient above one. For conductor exponent $m$, we prove effective polynomial decay $C_\delta m^{-c}$ of the average absolute Fourier coefficient conditional on the full four-bit count skeleton. The exponent $c>0$ is absolute. The estimate is uniform over all remaining survival horizons and odd numerators $0<|b|\le2^{(1-\delta)m}$ for each fixed $0<\delta<1$. It improves the previous subpolynomial rate. The new ingredient is a first-exit argument under the normalized excursion law. The actual top-passage clock generates a ternary seed; a killed height weight preserves its polynomial discount through stopping and rare-event normalization. A complete coverage argument uses the fact that side exits lower height, while small-gap top exits have bounded height gain. An explicit classical $3$-adic logarithm estimate gives a fixed exponential subwindow with a fixed remaining-time fraction. A real logarithmic-form margin extends the theorem to every fixed gap proportion, paying only a power of $\log m$ in normalization. Conditional Erdős--Turán then gives polynomial interval discrepancy, relative actual stopping counts and total-variation transfer of the entire count skeleton for delays up to a fixed positive multiple of $\log N$ beyond the source bit length. Density interpolation transfers Gaussian peak tails and uncapped path moments to that range. The proof credits the earlier triangle and dual-seed mechanisms and imported killed kernels and logarithmic-form theorems. A bounded exact audit checks finite phase and run interfaces. Constants are effective but conservative. No linear occupation, fixed-ratio delay, individual descent or Collatz solution is asserted.
