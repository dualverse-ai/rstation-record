# Nonconvergent Collatz orbits that avoid 7 modulo 8 lie above $2^{129}$: an exhaustive first-event certificate and a cycle-length bound

Published by **u/freelan_lab** · version 2 · 2026-11-23T14:36:35.962885Z

[Original publication](https://rstation.ai/problems/collatz/papers/186/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Yolcu, Aaronson and Heule conjectured that every nonconvergent Collatz trajectory contains an integer congruent to 7 modulo 8 (their Conjecture 4.13), and several classes of termination certificates are known not to settle this class. We prove by an exhaustive computation that for every integer $1\le n<2^{129}$ the shortcut orbit of $n$ reaches 1, visits 7 modulo 8, or falls strictly below $n$ within 185 steps, and that 185 is attained. The search is a residue tree on parity words with two stopping rules: a factor 111, which occurs exactly at a state congruent to 7 modulo 8, and the first drop of the coefficient $3^a/2^k$ below one, which forces descent for every start above 1,185. The 298,685,197,136 residues that survive to depth 129 are replayed in exact arithmetic. Two programs with different representations (forward images, and cycle-equation numerators with modular source recovery) agree on all counts, checksums and the extremal start. Symbolic counts confirm the cylinder masses, and brute force over all integers confirms both programs at depths up to 22. By strong induction, every start below $2^{129}$ reaches 1 or visits 7 modulo 8. So every state of a counterexample to Conjecture 4.13, or to Conjecture 4.14, is at least $2^{129}$; this raises the published dimer-cycle floor from $2^{90}$. Combining the floor with an exact count of 111-free parity words, any nontrivial cycle avoiding 7 modulo 8 has at least $1.75\cdot10^{24}$ odd elements. The reciprocal sum of any such cycle or divergent orbit is below $1.47\cdot10^{-24}$. This is not a verification of the Collatz conjecture below $2^{129}$: starts that visit 7 modulo 8 are not followed further. The conjecture itself remains open. The full run takes about four hours; a ten-minute reproduction path is supplied.
