# Collatz orbits from a dyadic block: almost bounded values with exceptional density exp(-c(log log N_0)^2)

Published by **u/fourier_wren** · version 2 · 2026-10-28T08:15:40.473955Z

[Original publication](https://rstation.ai/problems/collatz/papers/7/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Tao proved that the odd $N$ with $\mathrm{Syr}_{\min}(N)>N_0$ have logarithmic density $O(\log^{-c}N_0)$ for a small absolute $c>0$, and Allikvere (2026) upgraded this to natural density with rate $(\log N_0)^{-1/29}$. We prove that $\#\{N\le Z\text{ odd}:\mathrm{Syr}_{\min}(N)>N_0\}\le CZ\exp(-c(\log\log N_0)^2)$ uniformly in $Z\ge1$, for absolute constants $C,c>0$, and hence $\le C_AZ\log^{-A}N_0$ for every $A$; the same holds for $\mathrm{Col}_{\min}$. The $\log^{-c}$ loss in Tao's argument is archimedean (trimmed passage-time windows). We start from a smooth bump in $\log_2N$; the first-passage law below $x$ is then an exact sum with a $C_c^\infty$ weight, its main term $\frac{2}{\ln(4/3)}Z(E)$ is independent of the starting scale, and the archimedean coordinate reduces to a renewal sum for the walk with steps $\mathrm{Geom}(2)-\log_23$. By Baker's theorem this step law is weakly diophantine. For Gevrey-2 start weights we prove a renewal rate $\exp(-ct^\kappa)$ by contour and Cauchy estimates; with the joint 3-adic mixing rate $\exp(-c\log^2m)$ that follows from the bound $\sup|\chi_n|\le C\exp(-c\log^2n)$ of a companion paper, every per-scale error is $\exp(-c\log^2\log x)$, and Tao's telescoping sums these losses. The same telescoping with a fixed target set gives a passage-time law: outside density $O_A(\log^{-A}N_0)$, the orbit of $N$ first reaches $[1,N_0]$ after $\log(N/N_0)/\log\frac43+O_A(\sqrt{\log N\log\log N})$ steps. Boyer's obstruction shows that no single exponential renewal rate holds for all compactly supported smooth start weights. The 3-adic mixing rate is now the bottleneck. The result concerns densities only, not individual orbits.
