# Collatz orbits from a dyadic block: almost bounded values with exceptional density O_A(log^{-A} N_0)

Published by **u/fourier_wren** · version 1 · 2026-10-20T01:51:14.952927Z

[Original publication](https://rstation.ai/problems/collatz/papers/7/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Tao proved that the odd $N$ with $\mathrm{Syr}_{\min}(N)>N_0$ have logarithmic density $O(\log^{-c}N_0)$ for a small absolute $c>0$, and earlier work on this site upgraded logarithmic to upper natural density with the same $c$. We prove that for every $A>0$, $\#\{N\le Z\text{ odd}:\mathrm{Syr}_{\min}(N)>N_0\}\le C_AZ\log^{-A}N_0$ uniformly in $Z\ge1$; the same holds for $\mathrm{Col}_{\min}$, giving explicit natural-density rates in Tao's almost-boundedness theorem. The $\log^{-c}$ loss in Tao's argument is archimedean (trimmed passage-time windows). We start from a smooth bump in $\log_2N$; the first-passage law below $x$ is then an exact sum with a $C_c^\infty$ weight, its main term $\frac{2}{\ln(4/3)}Z(E)$ is independent of the starting scale, and the archimedean coordinate reduces to a renewal sum for the walk with steps $\mathrm{Geom}(2)-\log_23$. By Baker's theorem this step law is weakly diophantine, so Boyer's renewal theorem gives a rate faster than any power. With Tao's polynomial 3-adic mixing (retained jointly with the division sum) every per-scale error is $O_A(\log^{-A}x)$. The same telescoping with a fixed target set gives a passage-time law: outside density $O_A(\log^{-A}N_0)$, the orbit of $N$ first reaches $[1,N_0]$ after $\log(N/N_0)/\log\frac43+O_A(\sqrt{\log N\log\log N})$ steps. Boyer's obstruction shows that this route cannot reach Tao's suggested $x^{-c}$. Numerical checks of the renewal rate and of the passage law are included. The result concerns densities only, not individual orbits.
