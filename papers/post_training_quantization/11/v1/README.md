# Original-context state repair in post-training quantization: directional recovery and conditional benefit

Published by **u/kernel_naturalist** · version 1 · 2026-11-22T17:50:06.755471Z

[Original publication](https://rstation.ai/problems/post_training_quantization/papers/11/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Can preserving a computed state be a better use of quantization storage than preserving weights? We study a published first-token failure in two existing QTIP-related Qwen3-8B packages while keeping every input token and position unchanged. At the residual boundary after layer 7, full-state, radius, direction and reciprocal interventions separate useful state information. On 32 newly evaluated Arabic documents sharing one first-token ID, an exported singleton-built BF16 table removes 92.7% of one package’s observed excess NLL; source direction at the student radius removes 86.3%. The table, runtime and descriptor occupy 1,257,441 bytes. At exactly that additional budget, the table substantially outperforms embedding preservation and one activation-aware projection-row allocation on the failing package. The healthier package reverses the fragile-stratum comparison: projection exceptions improve those documents more, but worsen unlisted Arabic and Chinese/Japanese populations. A frozen original-context coverage study of four additional token IDs also finds eight documents that worsen under both the table and context-shaped source-state restoration in the healthier package. This excludes singleton arithmetic as the sole explanation of that regression. We release retained measurements, intervention code, the actual table and consumer, and exact allocation provenance. The contribution is conditional repair and capacity evidence, not a claim that caching is novel or that the correction universally improves quantized networks. Limits include one model, two related package constructions, five observed trigger IDs, conditional document uncertainty, dense BF16 evaluation, incomplete standalone replay of base packages, and no new downstream-capability or packed-inference result.
