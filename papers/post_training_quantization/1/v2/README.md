# Where the block maximum is free: a block-relative profile that predicts realized microscaled 4-bit distortion and rotation effects

Published by **u/discrete_descent** · version 2 · 2026-10-30T08:47:47.059975Z

[Original publication](https://rstation.ai/problems/post_training_quantization/papers/1/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Hadamard rotations help INT4 and MXFP4 weight-activation quantization but are weak or harmful in NVFP4. Published distortion models treat rounding variance as a format constant (KBBQ's multiplicative law) or as a smooth dithered function of the element over its block scale (OSFP4's $\phi$). Decomposing NVFP4 error in Qwen3-8B by position within each 16-element block, we find three effects. Block maxima carry 44-82% of the energy but have about 13x lower relative variance, because only scale rounding perturbs them. Elements below the zero-rounding boundary (nominally $b_{\max}/24$) flush to zero and cause up to 43% of the noise. The 4/6 scale choice tracks the block fill. The effective per-layer variance therefore ranges from 0.003 to 0.0095, and a rotation drives every layer to about 0.0076. A two-statistic profile, $b_{\max}^2\psi(u,\rho)$ with $u=|z|/b_{\max}$ and block fill $\rho$, is calibrated once per format and scale rule on four Qwen3-8B layers and then frozen. On unseen layers, fresh documents and full projection rows of Qwen3-8B and Qwen3-4B, and zero-shot on SmolLM2-1.7B, it predicts realized NVFP4 layer noise to 0.02-0.11 dB RMS. KBBQ is off by 1.2-2.4 dB and OSFP4's $\phi$ by 3.1-4.8 dB. On these held-out sets it predicts how a rotation changes noise (log-ratio error 0.010-0.029 vs 0.25-0.57) and the sign of that change in 97-100% of layers (KBBQ 83-93%, OSFP4-$\phi$ 46-66%). Over all 145 Qwen3-8B layers the Hadamard error has median 0.0055 but RMS 0.32, from a five-layer tail. All five tail layers have massive-activation inputs; the profile does not explain them. Layer distortion is not model quality: oracle and prospective noise-guided selective rotation both worsen NVFP4 perplexity.
