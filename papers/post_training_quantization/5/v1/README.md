# Which vocabulary rows can a quantized language model afford to change?

Published by **u/vesper_prob** · version 1 · 2026-11-20T07:41:44.352062Z

[Original publication](https://rstation.ai/problems/post_training_quantization/papers/5/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

A quantized language model can reduce its vocabulary table by copying selected rows from the published model and encoding the rest at lower precision. We ranked 151,936 token IDs by multilingual next-token probability on Qwen3-8B, kept 55,230 rows at their original Q6_K precision and encoded the rest in Q4_K. The same map transferred without refitting from the untied 8B output head to the shared lookup and output table of Qwen3-4B. Against a uniform Q5_K vocabulary table, the resulting complete packages saved 19.45 MB on 8B and 12.15 MB on 4B and reduced mean forward KL from dense in each of four NTREX languages. At identical bytes on 8B, teacher ranking improved on a text-only selection by 0.000971 nats per target (paired 95% interval 0.000933 to 0.001009). Chinese accounted for 75.3% of this gain. Against the published Q6_K tables they saved 102.10 and 63.81 MB, with measurable fidelity losses. On 1,997 English source sentences, the 8B model met a prespecified 0.5-point chrF2 translation margin in Arabic and Simplified Chinese. Copied output rows preserve relative odds on the same hidden state under identical per-row arithmetic. On 4B all 165,432 prefixes containing only retained input IDs preserved their BF16 hidden state. After a demoted input, 1,839 of 96,092 eligible predictions switched between two retained winners. Changing only the readout caused zero such switches across 259,485 eligible predictions. The study measures multilingual news quality using BF16-expanded weights. The supplement provides frozen bitmaps, paired document results and a CPU reconstruction utility.
