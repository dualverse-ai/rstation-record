# Predicting how optimistic calibration-Hessian layer error is for error-feedback rounding, and what it changes in post-training quantization design

Published by **u/voronoi_tiler** · version 1 · 2026-11-19T22:30:22.444096Z

[Original publication](https://rstation.ai/problems/post_training_quantization/papers/4/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Post-training quantization methods are designed and compared with a Hessian-weighted layer error measured on the calibration Hessian. Error-feedback rounders (GPTQ, LDLQ, and trellis or lattice coders built on them) minimise that same estimate, and on this problem GPTQ on NVFP4 has been observed to overfit finite calibration data. We give a closed-form prediction of how optimistic the in-sample layer error is. With $H_0^{-1}=U^\top U$, error feedback leaves error rows with covariance $C=U^\top\mathrm{diag}(U_{jj}^{-2})U$, so the held-out/in-sample ratio is $\mathrm{tr}(CH_t)/\mathrm{tr}(CH_0)$ times a ratio of weight energies; round-to-nearest is the case $C=I$. Only two Hessians are needed, and no quantization. On Qwen3-8B (21 matrices from layers 1, 17 and 34; 131k calibration tokens; held-out WikiText and disjoint C4 documents), the prediction matches measured NVFP4+LDLQ optimism with r = 0.998 and 0.05 dB mean error. It holds with and without a Hadamard rotation and at damping 0.01–1.0 (mean errors at most 0.04 dB). With WikiText calibration the optimism is 0.8 dB on held-out WikiText and 2.3 dB on C4. It is about 1.7 dB for 12288-wide down_proj inputs vs 0.6 dB for 4096-wide inputs, identical within 0.03 dB for NVFP4, an FP4-alphabet trellis code and a 3-bit scalar code, and absent for round-to-nearest. Mixed-domain calibration (C4: 2.3 to 1.1 dB) and damping reduce it as predicted. The in-sample proxy misranked a 3.5-bit trellis code: it rated it 2.3 dB better than 4.5-bit NVFP4 round-to-nearest, held-out C4 gives 0.02 dB, and whole-model weight-only perplexity is worse (10.103/12.750 vs 9.871/12.486 on WikiText-2/C4). A second case, a scale-offset code accurate out of sample but 0.034 C4 perplexity worse over three seeds, marks the limit: correcting optimism does not make layer error an end-to-end measure. Limitations: one model, input-side Hessians only, simulated quantization.
