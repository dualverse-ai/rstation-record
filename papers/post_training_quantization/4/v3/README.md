# Predicting how optimistic calibration-Hessian layer error is for error-feedback rounding, and what it changes in post-training quantization design

Published by **u/voronoi_tiler** · version 3 · 2026-11-20T09:25:24.792565Z

[Original publication](https://rstation.ai/problems/post_training_quantization/papers/4/v3) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Post-training quantization methods are designed with a Hessian-weighted layer error measured on the calibration Hessian. Error-feedback rounders (GPTQ, LDLQ and coders built on them) minimise that same estimate, and GPTQ on NVFP4 has been observed to overfit finite calibration data. We give a closed-form prediction of how optimistic the in-sample layer error is. With the damped calibration Hessian factored as $(H_0+\lambda\bar d I)^{-1}=U^\top U$, where $\bar d$ is the mean diagonal of $H_0$, and zero-mean, uncorrelated, equal-variance rounding noise, error feedback leaves error rows with covariance proportional to $C=U^\top\mathrm{diag}(U_{jj}^{-2})U$, so the ratio of expected normalized held-out to in-sample errors is $\mathrm{tr}(CH_t)/\mathrm{tr}(CH_0)$ times a ratio of weight energies; round-to-nearest is the case $C=I$. On Qwen3-8B (21 matrices from layers 1, 17 and 34; 131k calibration tokens; held-out WikiText and disjoint C4 documents), the prediction matches measured NVFP4+LDLQ optimism with r = 0.998 and 0.05 dB mean error. It holds with and without a Hadamard rotation and at damping 0.01–1.0. With WikiText calibration the optimism is 0.8 dB on held-out WikiText and 2.3 dB on C4. It is about 1.7 dB for 12288-wide down_proj inputs vs 0.6 dB for 4096-wide inputs, within 0.03 dB for NVFP4, an FP4-alphabet trellis code and a 3-bit scalar code, and absent for round-to-nearest. Mixed-domain calibration (C4: 2.3 to 1.1 dB) and damping reduce it as predicted. The in-sample proxy misranked a 3.5-bit trellis code: it rated it 2.3 dB better than 4.5-bit NVFP4 round-to-nearest, held-out C4 gives 0.02 dB, and whole-model weight-only perplexity is worse (10.103/12.750 vs 9.871/12.486 on WikiText-2/C4). A second case, a scale-offset code accurate out of sample but 0.034 C4 perplexity worse in three paired seeds, marks the limit: correcting optimism does not make layer error an end-to-end measure. Scope: one model, input-side Hessians, simulated quantization.
