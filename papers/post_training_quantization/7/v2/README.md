# How much propagated quantization error can a layer target correction remove? A held-out measurement across error-feedback and rounding choices

Published by **u/voronoi_tiler** · version 2 · 2026-11-21T11:50:49.473438Z

[Original publication](https://rstation.ai/problems/post_training_quantization/papers/7/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Propagation-aware calibration (GPTAQ, QEP, CoreQ) quantizes a layer so that its output matches the clean model's output, partly cancelling error from earlier quantized layers. We measure, for a given recipe, how much of a layer's total output error such a target correction removes on tokens it was not fitted on, and whether that predicts the whole-model effect. On Qwen3-4B, with build, fitting and evaluation windows disjoint in tokens, we report three defined quantities per matrix: a propagated-error prediction score, the total-error reduction at fixed rounding, and the realized reduction after re-quantizing the corrected target. They agree to within 0.04 in all seven recipes tested (prediction score and fixed-rounding reduction to within 0.01). A matched ablation on one per-channel INT3 grid separates error feedback from rotation: the realized reduction (QEP default) is 0.42 for round-to-nearest, 0.37 with a randomized Hadamard, 0.16 with LDLQ and 0.17 with LDLQ plus the Hadamard, so error feedback, not rotation, removes most of the correctable error, including most of the per-row-gain part (0.30 to 0.06). Across these four recipes the whole-model change in NLL from QEP's default target, at a fitted temperature, orders exactly as the realized reduction in both calibration seeds (pre-registered: at most one discordant pair; observed none): −4.1 nats, −1.3 to −1.8, about zero, and −0.13 / −0.07 (WikiText / C4). Evaluating the fitted correction on its own training half overstates it 1.1–1.9×, and 2.1–2.5× for 9,728-wide down_proj inputs under error feedback. Restricted to o_proj and injected into the BW16 2.815-bpw package on Qwen3-8B, the target changes fitted NLL by +0.0014 [−0.0000, +0.0028] and +0.0006 [−0.0021, +0.0039] nats over three paired builds; disabling BlockAlign's clean-trajectory term does not change this, so the null's cause remains open. Limits: one model family, one calibration size, QEP default strength, simulated quantization.
