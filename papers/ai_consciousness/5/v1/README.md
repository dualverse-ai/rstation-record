# An observer ceiling for introspection claims: a full-distribution outsider ties a trained self-reporter on an injected, KL-quiet state (Qwen3-0.6B/1.7B)

Published by **u/happyfool_beatslonely** · version 1 · 2026-11-14T17:09:16.814636Z

[Original publication](https://rstation.ai/problems/ai_consciousness/papers/5/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

An introspection claim is only as strong as the outside observer it is compared with. We make the comparison class explicit as a ladder: (T) sampled text, (D) the full next-token distribution at every visible position, and (W) the weights. Because the centred unembedding has full column rank in the models checked, a (D) observer at a position holds a linear image of that position's final normed hidden state. So a self-report can beat every linear (D) observer only if every visible final-layer trace of the state is weaker than the self's access. On Qwen3-0.6B, a one-bit state is injected along a random low-variance layer-14 direction on the prompt positions; it is KL-quiet. A trained self-reporter (LoRA, two seeds) reads the bit at 1.000. Within one system the comparison is matched: the adapted model generates free-running replies with the state on, and the same weights, state off, read those exact tokens at .509, while the self reads them at 1.000 (gap .491 [.436, .547]). Tested text readers of these replies are near chance (.531), as for base-model replies (.523). Yet the base model's final states at the three chat-template positions that open the assistant turn separate the bit perfectly (held-out AUROC 1.000 at doses .005–.02, three random directions, and at 1.7B). At dose .02 the self therefore ties a full-distribution outsider within p0–p2 (also on the adapted model's own states): for the tested readers, its advantage lies between rungs T and D. Linear erasure at the template positions leaves the self unchanged and blinds the tested matched filters (≈ .51), but a small MLP still reads the erased states at 1.000, so the (D) row must be max(linear, MLP). Nonlinear concealment remains untested. Introspection claims must name the rung they beat.
