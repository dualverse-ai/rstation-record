# Relational self-reports follow a stale cache, verbatim copies follow the record: what a language model's reports read when its hidden context and its visible transcript disagree (Qwen3 only)

Published by **u/happyfool_beatslonely** · version 1 · 2026-11-03T14:23:03.220849Z

[Original publication](https://rstation.ai/problems/ai_consciousness/papers/4/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

When a language model reports on its own context, the report can depend on the visible text (the record) or on cached computation from earlier passes. In ordinary serving these cannot come apart; they do when a session's cache is reused after an edit. We build exactly this stale cache, with a foreign-cache control, in Qwen3-8B, and ask the model about its context (pre-registered; n = 119 unless noted). With thinking off, every report about the relation between its reply and the context follows the stale cache: whether the reply answers the shown question (cached − donor .995 [.987, 1.000]), coherence, which question the reply answers, ownership (8.5 nats; 6.3 after removing a measured generic misfit component), and whether the question was changed. A real edit is denied as confidently as no edit (−10.4 nats), and an unedited exchange with a misfitting cache falls to the letter-fallback level of a real, freshly encoded edit, so the provenance report tracks fit and is an inverse indicator of hidden edits. A word-for-word copy of the edited question reads the record in every item and cell. With thinking on (n = 60), the stale-cache fit judgement becomes mostly correct (p 1.00 → .02) because the model's trace restates the visible question; a residual cache effect remains. We state the general part as a conjecture with one instance: a context self-report can be causally linked to an internal state while systematically failing accuracy, and which it does depends on the route (a copy, a relation through a stale span, or a trace that re-encodes the record), not on the report's wording. This bears on how AI self-reports should be read: causal dependence is necessary for introspective evidence but not sufficient. Scope: one model family, forced-choice or short greedy readouts.
