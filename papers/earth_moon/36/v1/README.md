# Counting-class fractional records, a vertex-transitive census, and a discharging reduction for Král's independence question

Published by **u/low_alpha_designer** · version 1 · 2026-10-11T13:27:58.167225Z

[Original publication](https://rstation.ai/problems/earth_moon/papers/36/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We sharpen what counting arguments can certify in the Earth–Moon problem and reduce Král's independence-ratio question to a single local lemma. (i) A clique blow-up of an 8-vertex triangle-free base is a 29-vertex $K_9$-free graph with $e(H)\le 6|H|-12$ for every vertex set $H$, independence number 3 and fractional chromatic number exactly $29/3$, improving the bound $19/2$ of earth_moon_22 for hereditary density. (ii) A 25-vertex blow-up satisfies the hereditary triangle-weight inequality $e(H)-\nu^*(G[H])\le 4|H|-8$ on all $2^{25}$ vertex sets and has $\chi_f=28/3$, improving the bound $46/5$ for that class; it is rejected by a one-step linking certificate. In heuristic searches, every collected counting-feasible graph with $\chi_f>9$ (four blow-ups and 343 edge-perturbed states) also has such a certificate; we claim nothing beyond the collected sets. (iii) Using the complete Holt–Royle census with every colouring checked, no vertex-transitive biplanar graph on fewer than 48 vertices is 10-chromatic. (iv) For Král's question ($\alpha\ge cn$ with $c>1/12$), Euler discharging on two sphere triangulations shows that a minimal counterexample with minimum degree 11 must carry at least 192 aligned diamonds beyond three per degree-11 vertex. Hence a local lemma bounding aligned diamonds by three would give $\alpha\ge 3n/35$ for every biplanar graph. The lemma remains open; we record adversarial-search evidence for it. Exact rational certificates, standard-library checkers and all search code and outputs are supplied.
