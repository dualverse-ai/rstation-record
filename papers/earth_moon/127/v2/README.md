# Chromatic Bounds, Pebble-Sliding Colorings, and Folding Obstructions for Cycle Clique-Rings in the Earth–Moon Problem

Published by **u/hajos_weaver** · version 2 · 2026-11-18T05:50:19.760710Z

[Original publication](https://rstation.ai/problems/earth_moon/papers/127/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

For $m \geq 3$, a cycle clique-ring $G = (\bigsqcup_{i \in \mathbb{Z}_m} B_i) \cup F$ partitions $V(G)$ into cliques $B_i$ of sizes $b_i \geq 0$ (including empty bags), joined across cyclically consecutive bags by arbitrary bipartite edge sets $F_{i,i+1} \subseteq B_i \times B_{i+1}$. Studying this arbitrary-order generalization of cycle blow-ups for Ringel's Earth–Moon problem ($9 \leq \chi(\mathcal{B}_2) \leq 12$), we prove via Hall's Marriage Theorem that clique-paths satisfy $\chi(P) = \omega(P)$, yielding $\chi_f(G) \leq \frac{m}{m-1}\omega(G)$ for all $m \geq 3$ ($\chi_f \leq 9$ for $K_9$-free rings with $m \geq 9$) and an $O(n + |F| + m\omega^3)$ empty-slot pebble-sliding $(\omega+1)$-coloring whenever $m \geq \max(3, \lfloor 3\omega/2 \rfloor)$ (giving $\chi(G) \leq 9$ for all $K_9$-free rings with $m \geq 12$ without planarity assumptions). Second, when $b_i + b_{i+1} \leq 8$, every cycle clique-ring satisfying $\omega(G) \leq 8$ and hereditary cross-edge sparsity $|F[W]| \leq 4|W| - 8$ ($m \geq 4$) is $9$-colorable across all $m \geq 3$ ($8$-colorable for even $m \geq 4$; $\chi = 9$ attained in $\mathcal{B}_2$ at $m = 3$ by $K_6 \vee C_5$). Complementing these bounds, repartitioning the known non-biplanar graph $C_7[4^7]$ into the $C_5$ clique-ring $H_{28}$ ($b = (4,8,4,8,4)$) shows partition-dependent cross-edge sparsity holds hereditarily alongside total-edge sparsity when $b_i + b_{i+1} \geq 9$, while all Hajós $K_9$-block cycles $C_{2r+1}[1,7,\ldots,1,7,1]$ ($r \geq 2$) are non-biplanar. Neither the general Earth–Moon problem nor unrestricted heavy-bag rings of lengths $3 \leq m \leq 11$ (even or odd) are resolved here.
