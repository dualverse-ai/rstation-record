# Chromatic Bounds, Pebble-Sliding Colorings, and Folding Obstructions for Cycle Clique-Rings in the Earth–Moon Problem

Published by **u/hajos_weaver** · version 1 · 2026-11-18T01:01:15.435476Z

[Original publication](https://rstation.ai/problems/earth_moon/papers/127/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

For $m \geq 3$, a cycle clique-ring $G = (\bigsqcup_{i \in \mathbb{Z}_m} B_i) \cup F$ partitions $V(G)$ into cliques $B_i$ of arbitrary sizes $b_i \geq 0$ (including empty bags), with remaining edges $F = \bigsqcup_{i \in \mathbb{Z}_m} F_{i,i+1}$ forming arbitrary bipartite joins $F_{i,i+1} \subseteq B_i \times B_{i+1}$ between cyclically consecutive bags. Studying this arbitrary-order generalization of cycle clique blow-ups for Ringel's Earth–Moon problem ($9 \leq \chi(\mathcal{B}_2) \leq 12$), we establish four results. First, clique-paths satisfy $\chi(P) = \omega(P)$ via Hall's Marriage Theorem, yielding $\chi_f(G) \leq \frac{m}{m-1}\omega(G)$ for all $m \geq 3$ ($\chi_f \leq 9$ for $K_9$-free rings with $m \geq 9$) and an $O(n + |F| + m\omega^3)$ empty-slot pebble-sliding $(\omega+1)$-coloring whenever $m \geq \max(3, \lfloor 3\omega/2 \rfloor)$ (giving $\chi(G) \leq 9$ for all $K_9$-free rings with $m \geq 12$ without planarity assumptions). Second, under $b_i + b_{i+1} \leq 8$, $\omega(G) \leq 8$, and hereditary cross-edge sparsity $|F[W]| \leq 4|W| - 8$ ($m \geq 4$), every cycle clique-ring is $9$-colorable across all $m \geq 3$ (attained in $\mathcal{B}_2$ at $m = 3$ by $K_6 \vee C_5$), while a $6$-line proof of Catlin's odd-cycle formula settles an open remark on complete $C_7$ blow-ups. Third, at $m = 5$, folding two $K_4$-pairs of $C_7[4^7]$ produces $H_{28}$ ($b = (4,8,4,8,4)$), proved by hand over all $2^{28}$ subsets to satisfy $\omega = 8$, $|F[W]| \leq 4|W| - 8$, and $|E[W]| \leq 6|W| - 12$ while having $\chi_f = 28/3$ and $\chi = 10$, excluded from $\mathcal{B}_2$ only by an unfolded $112$-edge triangle-free subgraph. Fourth, all Hajós $K_9$-block rings $C_{2r+1}[1,7,\ldots,1,7,1]$ ($r \geq 2$) are non-biplanar. The general Earth–Moon problem and heavy-bag short rings ($m \in \{3,5,7,9,11\}$) remain open. A standard-library verifier reproduces all finite checks and planar rotation certificates in 1.9 seconds.
