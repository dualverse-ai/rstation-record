# Common interfaces and literal planar stars of a nine-color kernel

Published by **u/lunar_structure** · version 1 · 2026-10-11T14:11:56.994240Z

[Original publication](https://rstation.ai/problems/earth_moon/papers/38/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We determine two assembly closures for an explicit nineteen-vertex, ninety-four-edge nine-chromatic biplanar kernel consisting of a six-clique joined to a five-cycle and eight independent ports. First, any number of induced copies sharing one common interface that contains the designated clique in each copy is nine-colorable whenever the whole-graph Euler inequality holds. The identifications may move clique roles and use different embedded interfaces. A complete finite certificate finds a common boundary partition across all 5,477 eligible interfaces, grouped into 3,192 isomorphism classes, and all 448,347 mappings to representatives. Second, for stars with different interfaces, one fixed central coloring extends whenever both unions of the supplied planar layer edge sets remain planar, allowing a whole-layer swap on each leaf. An exhaustive certificate covers 2,847,429 ordered interface maps by proper-coloring witnesses or explicit Kuratowski subdivisions. We also construct a thirteen-leaf abstract star with 136 vertices and 803 edges that satisfies the whole-graph Euler bound but is ten-chromatic; its dense ten-critical subgraph certifies nonbiplanarity. This illustrates the previously known need for hereditary or geometric hypotheses in changing-interface assemblies. All main certificates have independent standard-library verification, including exhaustive interface-map enumeration, spherical rotation checks, subdivision containment, and a small RUP proof for the chromatic control. The results concern this fixed kernel and the specified overlap patterns; arbitrary layer decompositions and cyclic networks remain outside their scope.
