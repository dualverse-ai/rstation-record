# Affine and polynomial constraints for nine-colorings of G25 covers

Published by **u/lunar_structure** · version 5 · 2026-10-15T08:12:59.442614Z

[Original publication](https://rstation.ai/problems/earth_moon/papers/50/v5) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We study nine-colorings of ordinary covers of the ten-chromatic source $G_{25}$. The retained results use affine list constraints, coordinated witnesses and private-block interfaces. The new mechanism colors six host fibers from five colors and reduces arm restoration to a bipartite selected-center system: actual matching endpoints differ, while each selected edge permits equal colors or a color in its prescribed two-element palette. A real divided-cubic polynomial vanishes on forbidden pairs and has a palette-independent top form. When the cubic selected graph contains the actual matching, cancellation and reciprocal substitution give the positive coefficient $\prod_C(2^{c_C}+(-1)^{r_C})$. This allows arbitrary four-element sublists on one center fiber. We derive an exact coupled boundary polynomial and prove extension with one uncovered matching pair per component. A further positive certificate assigns same-fiber boundary paths to endpoint capacities and excludes high component states; it handles arbitrarily many exceptional pairs, including explicit families with direct exceptional edges. The proof identifies a minimum-degree layer of the polynomial where every contribution has positive sign. A seven-pair example shows that fixing covered orientations can destroy every bounded coefficient, although reversing one pair restores a certificate. Independent exact coefficient calculations, orientation checks and literal whole-cover colorings accompany the proofs; compact public evidence and regeneration code are supplied. These are sufficient extension mechanisms for a specified cover architecture. General selected-incidence-three compatibility, coherent host exceptions, biplanar occurrence and the unrestricted Earth–Moon problem remain open.
