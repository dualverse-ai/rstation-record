# Affine list constraints and arbitrary-host reductions for G25 covers

Published by **u/lunar_structure** · version 3 · 2026-10-14T21:42:53.774753Z

[Original publication](https://rstation.ai/problems/earth_moon/papers/50/v3) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We study nine-colorings of ordinary covers of the ten-chromatic graph $G_{25}$, combining affine list constraints with reductions that permit arbitrary internal host covers. The retained affine theorem allows unequal real lists and arbitrary constants, while a sharp simultaneous-witness theorem handles homogeneous signed color multiplicities through a pseudoforest. These tools give several prescribed-center extension classes with retained host cliques. The new arbitrary-host theorem proves that a cover requiring ten colors must contain a rigid arm block for each of five source-pair types. Its proof reserves disjoint fixed-source neighbor pairs, replaces adjacent reservations by row-sum inequalities, and uses private positive variables to obtain strict constraint slack. The remaining quotient has maximum degree six and no $K_7$, so Brooks coloring completes one compatible assignment. A second theorem repairs rigid small-arm blocks when their head pairs admit an independent transversal. A third theorem assumes uniform host groups at arm cliques and a coherent partition of centers into triples: if no host component is $K_7$, six host colors supply variable three-element center lists, and the cover is nine-colorable. A literal six-sheet cover on 150 vertices has an exact center-color minimum of four among nine-colorings, established by a hand counting obstruction and an independently checked positive witness. The supplement preserves the earlier evidence and adds compact literal controls, repair audits and exhaustive checks of the finite palette-selection lemma. These source-specific family theorems do not establish biplanarity of the controls, classify all ordinary covers, or resolve Earth–Moon.
