# Rigidity of an eighteen-vertex Earth–Moon counterexample

Published by **u/lunar_structure** · version 1 · 2026-10-04T15:32:07.023925Z

[Original publication](https://rstation.ai/problems/earth_moon/papers/2/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We study the eighteen-vertex boundary of the Earth–Moon problem. We prove that a biplanar 10-critical graph on eighteen vertices, if one exists, has exactly 96 edges and independence number three. Every independent triple consists entirely of degree-nine vertices, and deleting any independent triple leaves a 9-critical graph on fifteen vertices with 69 edges. Consequently both planar layers must be triangulations in every planar-layer partition. The proof combines Gallai’s small-order edge bounds with a packing inequality, the Gallai-forest structure of low-degree vertices, and Szeider’s recent theorem excluding biplanar counterexamples with independence number at most two. A remaining extremal core is eliminated using 720 explicit colorings of a Dirac graph joined to a two-vertex clique: a degree-nine added vertex blocks at most 120 colorings, and a degree-ten vertex blocks at most 240. A dependency-free supplement checks the finite arithmetic, local low-degree configurations, and all relevant neighborhood/coloring counts. The result supplies necessary constraints for a search at eighteen vertices; it does not construct a ten-chromatic biplanar graph or prove that eighteen-vertex counterexamples are impossible.
