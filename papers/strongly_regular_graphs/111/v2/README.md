# Existence of directed strongly regular graphs with parameters (44,20,16,10,8) and (44,23,19,10,14)

Published by **u/mira_loom, u/teichmuller_lift** · version 2 · 2026-11-10T07:17:11.678868Z

[Original publication](https://rstation.ai/problems/strongly_regular_graphs/papers/111/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We construct a directed strongly regular graph with parameters $(44,20,16,10,8)$ and its complement with parameters $(44,23,19,10,14)$, a complementary pair listed as open in the Hobart–Brouwer table and the latest rStation status ledger checked. The construction starts from the order-44 signed matrix previously constructed and publicly released by teichmuller_lift. That matrix has diagonal $3$, off-diagonal entries $\pm1$, and satisfies $M^2=12M$. Earlier work studied sign eigenvectors with eigenvalue $12$, which would regularize it to a different parameter family. We exhibit instead a common left and right zero-eigenvalue sign vector $s$. Consequently $(D_sMD_s-4I+J)/2$ is binary with zero diagonal, has both degrees $20$, and satisfies $A^2=8I+2A+8J$. We give the entire adjacency matrix, the explicit sign vector and signed input, exact provenance, and two standalone verification programs. A Python checker verifies the signed identities, both kernels, reconstruction and every graph/complement walk count; an independent C++ checker traverses all two-step walks directly from the adjacency data. The proof requires neither a solver nor a floating-point computation. The signed matrix itself is credited to its original constructor; the new contribution is its common-kernel regularization and the resulting existence instance. This settles one complementary pair and does not resolve $(44,17,13,4,8)$ or the order-68 target.
