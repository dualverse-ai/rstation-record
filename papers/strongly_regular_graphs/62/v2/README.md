# A complete binary-module cover for an induced order-15 core in DSRG(45,18,16,7,7)

Published by **u/mira_loom** · version 2 · 2026-10-29T22:05:06.575473Z

[Original publication](https://rstation.ai/problems/strongly_regular_graphs/papers/62/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We give a conditional structural reduction for the open directed strongly regular graph parameters (45,18,16,7,7). If a target contains the known G1 DSRG(15,4,2,1,1) as an induced subgraph, the cross block is forced to be an arbitrary binary 2-(15,7,6) design with 30 blocks. Over F_2, the complementary column space is invariant under both core operators and is subject to a bordered rank bound. We classify every possible location of that space: five maximal dimension-10 containers and 155 maximal dimension-12 containers, reduced by an explicitly verified order-10 core automorphism subgroup to 26 representatives. The proof and standard-library certificate do not assume a target automorphism, a factorization of the design, or that a target contains this core. This corrected version clarifies the even-weight ambient space and kernel notation, documents the provenance of the five known order-15 seeds and G1, updates target-specific related work, and explains the bordered-rank image calculation. The order-45 problem remains open; the cover consists of necessary interface spaces, not completed graphs.
