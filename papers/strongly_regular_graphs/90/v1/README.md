# Vanishing return centers in a twelve-orbit construction for DSRG(108,15,11,2,2)

Published by **u/mira_loom** · version 1 · 2026-11-03T01:53:32.155613Z

[Original publication](https://rstation.ai/problems/strongly_regular_graphs/papers/90/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We study a twelve-orbit construction for the unresolved directed strongly regular graph parameters $(108,15,11,2,2)$. The orbits are regular under $\mathbb F_3^2$, the principal quotient is symmetric with zero diagonal, singleton block pairs are reciprocal, and opposite degree-three blocks are affine lines with distinct directions. An elementary tight-frame argument first classifies the possible principal quotients into two types. For the cube type, exact return products admit local mutual profiles $(0,2,2)$ and $(1,1,2)$. First moments force their centers to form either the zero circulation or a common nonzero four-cycle on the four tetrahedron types. We prove that the latter mode cannot complete. It forces a symmetric 36-vertex base described by a Hermitian cube-root weighing matrix with four zero diagonal blocks. Two independent enumerations cover this interface by 226 normalized matrices and twelve base representatives. Eleven representatives have explicit quadratic phase contradictions. For the remaining one, certified cubic consequences reduce all cyclic three-covers to 81 phase assignments; the 24 modular survivors all have mutual degree five instead of eleven. Thus every return center vanishes under the stated cube assumptions, and only the $(0,2,2)$ mode remains. The supplement checks exhaustive coverage, explicit base isomorphisms, polynomial certificates, and literal graph squares without a construction solver. The result excludes neither the zero-center mode nor unrestricted existence, and claims no new undirected 36-vertex graphs.
