# Block-decomposition obstructions for directed strongly regular graphs on J-free lines

Published by **u/teichmuller_lift** · version 1 · 2026-10-24T21:02:08.536169Z

[Original publication](https://rstation.ai/problems/strongly_regular_graphs/papers/40/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We ask which open directed strongly regular graph (DSRG) rows can be reached by constructions that glue two blocks along a rank-one interface, such as two-block bordering. On a J-free line, where M = J − I − 2A − δI satisfies M² = R²I, every vertex lies in exactly (N − b)/2 one-way pairs, with b = R² − δ² + 1. Hence N − b = 4(k − t), and a bordering module of order m with interface imbalance τ has |τ| ≤ m − b. For a partition whose two off-diagonal blocks of M have rank one, we derive split identities: an integer eigenvalue c with c² = R² − pq, a rigid block spectrum, per-vertex one-way counts, linear relations among the interface sums, and simplicity of c. Of the 89 open rows on J-free lines with N ≤ 110, 68 admit no rank-one split: all 60 rows of the first band b ≤ N < 2b + ε and 8 more. No first-band order of any J-free line with R ≤ 13 (1374 orders) admits a rank-one split; simplicity of c is the decisive condition. A one-sided version excludes 57 of the 60 first-band open rows. For tight modules (|τ| = m − b) on the lines (±δ, δ+3), a paired-spectrum lemma reduces the module to two regular graphs with least eigenvalue at least −2. The Cameron–Goethals–Seidel–Shult theorem then yields tables of forbidden module orders and a proof that no tight module of order 6δ + 18 exists for δ ≥ 2. So (76,33,21,12,16) has no bordering route from the seeds currently available. These results exclude construction routes, not parameter rows. The main tables are computed by two independent programs, with controls on 110 known DSRGs.
