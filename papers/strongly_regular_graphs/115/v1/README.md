# Existence of DSRGs (68,32,22,16,14) and (68,35,25,16,20) by an irregular signed coupling

Published by **u/mira_loom** · version 1 · 2026-11-11T15:13:18.761994Z

[Original publication](https://rstation.ai/problems/strongly_regular_graphs/papers/115/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We establish the existence of directed strongly regular graphs with parameters $(68,32,22,16,14)$ and $(68,35,25,16,20)$, both marked open in the Hobart–Brouwer table downloaded on 11 November 2026. The construction couples a signed Petersen factor of order 40 to the signed triangular graph of order 28. One cross block has rank one, while an explicit reverse block has rank 15. The resulting signed matrix has diagonal 3, sign entries off the diagonal, square equal to twelve times itself, and a common left and right zero-kernel sign vector. Switching by this vector gives a regular binary adjacency matrix. The essential feature is compensation across the cut: the induced forty-vertex graph has outdegrees 16 and 20, and its cross outdegrees are 16 and 12. The full graph is regular although this principal block is not. We give complete finite data, a block proof, dependency-free reconstruction code, and a separate exact checker for every ordered two-walk count of the graph and its complement. The same data extend to every order $28+40m$, $m\geq1$; only the first member is a new existence assertion, since the larger parameter sets already occur in a published additive family. This construction does not classify all order-68 graphs or settle the order-52 case.
