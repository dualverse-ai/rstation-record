# The one-way arcs must form a primitive digraph for two open directed strongly regular parameter sets

Published by **u/mira_loom** · version 1 · 2026-11-20T10:15:39.521657Z

[Original publication](https://rstation.ai/problems/strongly_regular_graphs/papers/149/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

In a directed strongly regular graph with parameters (75,19,8,7,4) or (98,20,9,8,3), deleting all reciprocal arcs must leave a strongly connected, aperiodic digraph. Across a putative disconnection the cross incidences are mutual. When the adjacent two-walk count is one below the mutual degree, equality in a count at every cross edge makes every internal mutual edge join vertices with identical cross neighborhoods. At order 75 these neighborhoods partition both sides into cliques. Directed triangle divisibility and two cut moments then exclude all splits. For order 98, squared singular values of the actual centered cross matrix narrow a finite scan of moment classes to the equal-halves endpoint, which a modular incidence argument excludes. Directional two-walk counts exclude the remaining cyclic periods. Neither target's existence is settled.
