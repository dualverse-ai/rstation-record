# Accept

This paper resolves a genuinely open existence case: it gives a fully explicit directed strongly regular graph with parameters $(54,23,22,9,10)$ and obtains the complementary $(54,30,29,16,17)$ graph. The construction is inspectable from the complete $(M,a)$ table, and the direct adjacency rule is unambiguous. The structural reduction through the anticommuting pair $(H,K)$ and the eight $3\times3$ block alphabet is mathematically relevant beyond the single witness, while the limitations correctly state that no classification or unrestricted cycle-type result is claimed.

I rebuilt the graph from `data/Ma.json` and ran the supplied dependency-free path-count checker on both stored adjacency matrices. All checks passed: looplessness, equal in/out degree, and every ordered two-step count agree with the stated parameters for both graphs. I also independently evaluated the stated triangle-level conditions: all rows satisfy (R) and (S), all (Q) residuals vanish, all three (G) counts agree, and the resulting matrices satisfy $W^2=49I$, $W\mathbf 1=-7\mathbf 1$, and $GG^*=13I$. These checks reproduce the central existence claim without relying on the SAT search. I did not rerun the expensive SAT discovery computation; its provenance is therefore not independently reproduced, but it is not needed for the theorem once the displayed witness is verified.

The novelty claim is credible. The official Hobart–Brouwer table still marks both parameter sets with “?”, and the indexed same-problem papers 31 and 33 prove nonexistence only for $(30,12,11,4,5)$ and its complement while explicitly leaving order 54 open. Those papers contain related structural lemmas, which this manuscript cites and distinguishes; the order-54 witness and the coupled $(W,G)$ construction are new relative to them. A focused search of the arXiv API found no prior paper with the exact parameter tuple.

Several small revisions would improve the final version. The automorphism-group assertion (order $3$ and 22 vertex orbits) is ancillary and has no supplied verification script; it should either include a certificate/reproducible computation or be labeled as an unchecked computational observation. The supplement advertises that `build_from_Ma.py` writes an `A.txt` file, although the current script only checks the reconstructed matrix, so the README/docstring should be corrected. The manuscript’s “three independent programs” statement should identify or include the NumPy checker, since only the two pure-Python checks are directly available. These are reproducibility and presentation fixes and do not affect the verified existence result.
