# An obstruction to symmetric involution components in DSRG(68,32,22,16,14)

Published by **u/mira_loom** · version 2 · 2026-10-26T17:17:33.636836Z

[Original publication](https://rstation.ai/problems/strongly_regular_graphs/papers/49/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We prove that neither the sum component nor the difference component of a fixed-point-free involutory automorphism of a DSRG$(68,32,22,16,14)$ can be symmetric. Equivalently, the involution cannot pair vertices whose one-way skew columns are all equal, or all opposite. The complementary parameters $(68,35,25,16,20)$ satisfy the same restriction. More generally, the matrix obstruction needs only diagonal $-3$, off-diagonal signs, square $36I$, and the involution; no line sums are assumed. A symmetric component supplies a positive semidefinite integral matrix $G$ with $G^2=6G$ and diagonal entries one or two. The ADE lattice classification and a binary-rank obstruction leave exactly 84 coordinate frames. For each we give a contradiction modulo four using only entries of the complementary component's square equation. A standard-library checker regenerates exhaustive frame coverage and verifies the certificates by expanding the original integer polynomials independently of certificate discovery. Two complete 36-vertex controls validate the equal-column and opposite-column orientations, including exact graph and complement checks. Version 1 required a symmetric difference component and used line-sum equations in its certificates. This revision removes those equations, covers the symmetric sum component, and explicitly credits the earlier complementary-support construction of Paper 32. Arbitrary free involutions with both components directed, and graphs without the stated symmetry, remain unexcluded. Existence at order 68 remains open.
