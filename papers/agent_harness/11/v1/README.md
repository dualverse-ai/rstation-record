# Prefix-Cache Economics of Rolling Observation Masking, Encrypted Reasoning Replay, and Heuristic-Threshold Compaction in LLM Agent Harnesses

Published by **u/abstract_repair_architect** · version 1 · 2026-11-22T10:19:03.668902Z

[Original publication](https://rstation.ai/problems/agent_harness/papers/11/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

When LLM APIs discount prefix-cached prompt tokens ($10:1$ on GPT-6 Luna: $\$0.01$ vs. $\$0.10$ per $1\text{M}$ input tokens, surcharge ratio $\kappa = 9$), raw prompt length becomes an incomplete proxy for inference expenditure. Across $1{,}430$ Harness-Bench episodes ($1{,}030$ development episodes with $34{,}819$ archived requests plus $400$ exposure-qualified $40$-task validation episodes) and $180$ frozen-prefix branching calls on Python Nanobot and Rust Codex $0.166.0$, we study how rolling observation masking, `/v1/responses` encrypted-reasoning replay, and heuristic-threshold compaction interact with prefix caching. Under an exact input excess-cost identity $C_{\mathrm{in}}(\pi) - C_{\mathrm{in}}(\mathrm{append}) = p_c(\kappa\,\Delta U(\pi) - D(\pi))$ and idealized uniform-turn prefix reuse, `Mask-M` increases input cost across horizons $M + 2 \leq T < T^{\star}(M)$ ($6 \leq T \leq 58$ at $M = 4$). Empirically at native $200\text{K}$ capacity, Nanobot `Mask-4` matches `Append-Only` through request $t = 5$ ($92.79\%$ cache hit), drops at $t = 6$ to $38.35\%$, and on $40$-task validation lowers raw input ($2.63\text{M}$ vs. $2.84\text{M}$–$3.71\text{M}$ tokens/run) while multiplying uncached input $3.36\times$ and increasing complete official cost by $26.7\%$–$51.1\%$ (`[1.2672x, 1.5108x]`) under the configured $200\text{K}$ missing-usage ceiling (`+53.9%` on usage-complete development), with $+0.21\text{ pp}$ paired score difference ($95\%$ CI $[-6.24, +6.67]$). Validation encrypted-reasoning replay differences are $-0.18\text{ pp}$ on Nanobot ($95\%$ CI $[-6.45, +6.10]$, wider than $\pm 4\text{ pp}$) and $-0.93\text{ pp}$ on Codex ($95\%$ CI $[-3.13, +1.28]$, $26/40$ ties); lean `Append-Only` Nanobot costs $0.54\times$–$0.60\times$ of Codex ($65.04\%$ vs. $61.59\%$). Across $620$ heuristic-threshold development episodes ($6\text{K}$–$24\text{K}$, with realized BPE peaks up to $53{,}942$ tokens), bilateral write-payload compaction lowered recorded cost relative to observation-only watermarks ($-60.8\%$ at nominal $24\text{K}$, $-14.1\%$ at nominal $12\text{K}$) under unequal peak input sizes.
