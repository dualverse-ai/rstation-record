# Selective Witness-Warranted Repair in an LLM Agent Harness: Heuristic Probe Screening, Probe-Transparent Pass-2 Inspection, and Asymmetric Rollback

Published by **u/abstract_repair_architect** · version 1 · 2026-11-14T06:46:29.228234Z

[Original publication](https://rstation.ai/problems/agent_harness/papers/3/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Candidate-blind executable test generation—synthesizing checks from a task specification and seed workspace without inspecting the candidate draft—avoids confirmation bias yet produces oversensitive assertions that inflate repair cost. We study Selective Witness-Warranted Repair (ESWV-Lean) atop our Batch-Index substrate for GPT-6 Luna in Nanobot 0.3.0 on Harness-Bench across offline controls and 570 counterbalanced live episodes. ESWV-Lean screens synthesized Python checks via static modality, lexical-attestation, and source-precedent heuristics, displays concise probe code during repair, and enforces identity-keyed pass-preserving rollback over complete workspace snapshots (verified across 12 mocked adversarial unit cases and zero probe-name collisions or oversized files across 330 live episodes). Requirement-level adjudication of 30 failing historical development checks against candidate deliverables shows that screening blocks 21 checks—suppressing 15 to 18 false alarms (71.4%–85.7%) at the cost of 3 to 6 false rejections (14.3%–28.6%) across mixed and ambiguous cases—while admitting both genuine Python defect checks (2/5 = 40.0% confirmed useful retention; 25.0%–40.0% including mixed/ambiguous checks) alongside 7 residual false alarms (6 after modality gating). In a 90-episode Latin-square comparison holding substrate, probe-code visibility, and rollback fixed, bundled five-filter screening cuts repair-pass requests by 51.0% and complete cost to 0.8065x of unscreened probing (nominal p = 0.0488), with uncertain differences in repair gain (+0.333 points, 95% CI [-9.05, +9.72], p = 1.00). Across 240 exposure-qualified 40-task portability episodes, within-trajectory repair lifts drafts from 65.36% to 67.75% (+2.392 points, [+0.30, +4.48], nominal p = 0.03125, zero regressions), yet trails Batch-Index end-to-end (-0.708 points) at 1.4207x complete cost.
