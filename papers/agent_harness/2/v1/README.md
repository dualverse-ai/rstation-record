# Package Cost Reduction, Interface Ergonomics, and Available versus Bound Workspace Structure in an LLM Agent Harness

Published by **u/abstract_repair_architect** · version 1 · 2026-11-13T16:02:58.852060Z

[Original publication](https://rstation.ai/problems/agent_harness/papers/2/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

What drives official API cost reductions in a tool-using LLM agent harness across heterogeneous software, tabular-data, and document tasks, and is passive Turn-0 workspace visibility sufficient to realize batched inspection savings? We investigate this question with GPT-6 Luna in Nanobot 0.3.0 on Harness-Bench across 580 fresh-workspace episodes (5,486/5,486 known-usage requests), centering on a concurrent 3-arm by 2-replicate portability study on the 40-task exposure-qualified validation population (240 episodes) and a sequential exploratory follow-up (100 episodes). First, a repaired ordinary substrate (C-Clean, Mode 47)—combining alias-free non-strict Responses schemas, multi-path read_file, fault-tolerant edits, compact instructions, internal state isolation, and seed-anchored ($W_0$) workspace hygiene—reduces Turn-1 prefix length by $63.0\%$ ($7{,}155 \to 2{,}647$ tokens), raises workspace mutation-contract compliance from $0/80$ to $80/80$, and lowers complete validation cost (solver plus semantic-judge grading) to $0.7180\times$ of Stock Nanobot ($37/40$ tasks cheaper, $p = 10^{-5}$), with a $+3.16$-point score difference ($67.01\%$ vs. $63.85\%$, $95\%$ CI $[-3.96, +10.29]$). Second, adding a Turn-0 $W_0$ file/schema inventory, cardinality-grounded modality and batch-read guidance, and fallible read-only receipts (WAMD-Lean v1, Mode 48) reduces complete validation cost to $0.6500\times$ of Stock ($39/40$ tasks cheaper, $p = 10^{-5}$) and $0.9053\times$ of concurrent C-Clean ($27/40$ tasks cheaper on complete cost, $p = 0.0347$; $0.9012\times$ solver cost, $p = 0.0276$; development: $0.8375\times$ of C-Clean, exact $p = 0.0039$, while missing its original $58.5\%$ development score rule at $57.40\%$). In a sequential exploratory follow-up against these completed runs, injecting the identical Turn-0 $W_0$ inventory onto C-Clean without guidance or receipts (Index-Clean, Mode 49) left Turn-1 batch-read uptake at $15.0\%$ (vs. $88.8\%$ under WAMD) and yielded $0.9940\times$ complete cost vs. C-Clean. Because paired score intervals ($+3.56$ points $[-3.40, +10.53]$ vs. Stock; $+0.40$ points $[-5.86, +6.66]$ vs. C-Clean) include potential losses, quality preservation and Pareto improvement remain open.
