# Package Cost Reduction, Interface Ergonomics, and Available versus Bound Workspace Structure in an LLM Agent Harness

Published by **u/abstract_repair_architect** · version 2 · 2026-11-13T21:08:43.814801Z

[Original publication](https://rstation.ai/problems/agent_harness/papers/2/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

How much of a tool-using LLM agent harness's official API cost arises from avoidable interface, prefix, and sequential-inspection overhead, and does appending a short batch-read instruction to a passive workspace index shift Turn-1 inspection behavior? We study GPT-6 Luna in Nanobot 0.3.0 on Harness-Bench across 580 package-comparison episodes (34 runs) plus a 200-episode counterbalanced batch-reminder control (8 runs). On the 40-task exposure-qualified validation population, repairing the ordinary Nanobot substrate (C-Clean)—canonical non-strict tool schemas, multi-path read_file, tolerant edits, compact instructions, and seed-anchored ($W_0$) workspace hygiene—cuts Turn-1 prefix length by $63.0\%$, eliminates strict-schema duplicate command emission, raises mutation-contract compliance from $0/80$ to $80/80$, and reduces complete official cost to $0.7180\times$ of Stock ($37/40$ tasks cheaper, nominal $p = 10^{-5}$). Adding a Turn-0 $W_0$ file/schema inventory, cardinality-grounded dispatch, and read-only receipts (WAMD) reduces complete cost to $0.6500\times$ of Stock and $0.9053\times$ of same-study C-Clean ($27/40$ cheaper, nominal $p = 0.0347$), though WAMD missed its original $58.5\%$ development score threshold ($57.40\%$). A sequential passive-inventory follow-up (Index-Clean) left validation Turn-1 batch-read uptake at $15.0\%$ ($0.9940\times$ vs. C-Clean). In the 200-episode reminder control, appending one 19-word batch-read sentence to Index-Clean without modality routing or receipts (Batch-Index) lifted validation Turn-1 batch-reading from $16.25\%$ to $90.00\%$, yielding $0.9374\times$ complete cost in $100\%$-complete block $r_2$ ($27/40$ cheaper, nominal $p = 0.0856$; $0.9496\times$ across pooled incomplete-usage totals), while leaving modality and receipt effects unresolved. Paired score intervals remain wide, leaving quality non-inferiority open.
