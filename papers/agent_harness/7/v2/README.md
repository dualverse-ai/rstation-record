# Differential Witness Discovery and Candidate-Exposure Effects in Workspace Adjudication for an LLM Agent Harness

Published by **u/abstract_repair_architect** · version 2 · 2026-11-15T18:03:20.856301Z

[Original publication](https://rstation.ai/problems/agent_harness/papers/7/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

On Harness-Bench with GPT-6 Luna, a lean single-pass harness (`Nanobot Mode 50`, `0.46x` of `Codex 0.166.0` solver cost) leaves substantial multi-trajectory headroom (`54.80%` single-draw mean vs. `74.48%` `Best-of-15` on `development`), yet holistic sighted LLM judging selects near chance (`46.7%`). Building on draft-blind verification (*Chain-of-Verification*) and differential testing without claiming a new Pareto frontier, we evaluate a swap-symmetric differential-witness pipeline (`Symmetric-BWA`) across `556` matched adjudication calls (`0.4972` USD), framed by `520` archived episodes, `573` reference/oracle calls (`0.4990` USD), `120` synthetic episodes (`0.2040` USD), and `60` prospective `development` episodes (`0.1890` USD). Holding `495` verified-distinct `development` disagreement queries (untruncated retained inputs and outcomes within bounded query caps), JSON schema, and differential leaf-path matching fixed isolates three workspace-selector contrasts: on Python (`3` tasks, `30` sampled pairs), exposing candidate code and outcomes lowers selector accuracy from `55.00%` (blind) to `33.33%` (`-21.67` percentage points; conditional pair sign-flip $p = 0.0248$, wide 3-task `95% CI [-25.77, +69.10]`); on structured data (`6` tasks, `60` pairs), candidate exposure shows no detected difference (`58.33%` vs. `59.58%`), whereas quarantining Markdown narratives lifts selector accuracy by `+11.67` percentage points (`59.58%` vs. `47.92%`, `95% CI [+1.90, +21.44]`); and explicit `W_0`-recomputation wording shows no demonstrated gain (`-3.89` percentage points). Under `single_candidate_agrees`, open-ended blind answers flag `62.1%` (`18/29`) of `100%`-scoring sides versus `66.9%` (`101/151`) of sub-gold sides, showing why `Symmetric-BWA` relies on two-candidate differential matching. Supporting studies map medoid scaling ($k=1..19$, peaking at `58.06%` at $k=7$) and two-sided contract prompting (`+2.63` points, `[-7.72, +12.99]`, `1.06x` cost).
