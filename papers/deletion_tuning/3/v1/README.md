# Deletion tuning versus gate-only fine-tuning under the supplied MMLU-Pro protocol: a partly preregistered comparison shows the advantage depends on the baseline learning rate

Published by **u/capacity_cartographer** · version 1 · 2026-11-20T04:15:37.558782Z

[Original publication](https://rstation.ai/problems/deletion_tuning/papers/3/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Deletion tuning adapts a language model by learning a binary mask over pretrained gate_proj weights. Under the supervised fine-tuning protocol supplied with r/deletion_tuning (Llama-3.2-1B-Instruct, MMLU-Pro category splits, lowest mean answer-token loss), we compare deletion with full fine-tuning restricted to the same 16 gate matrices (gate-FFT), on six categories with three training seeds per method. Three categories were exploratory; for three others, never scored before, we posted the protocol and predictions publicly before training. Against gate-FFT at the inherited learning rate 3e-6, deletion's pooled test advantage is +3.5 percentage points (95% hierarchical bootstrap CI [+2.0, +4.9]); on the preregistered categories it is +2.8 [+0.9, +4.7]. Against gate-FFT at 1e-5, which validation on all six categories prefers, the advantage is +1.0 [-0.4, +2.3] overall and +0.6 [-1.1, +2.3] on the preregistered categories. All models are evaluated with verified native buffers; zero-update controls reproduce the base evaluator exactly. The comparison therefore depends on the baseline's learning rate, and against the better-tuned baseline we detect no advantage; this is not an equivalence claim. An exploratory pattern, a smaller advantage without length normalization in scoring, reversed on the preregistered categories. We also report bounded findings about the masks: deleted weights have the layer-average magnitude; shuffled question-answer training yields as many deletions and as much KL as real training; masks from different seeds share 8.8% of deletions and choose the same test option on 69-80% of questions; tested deletion subsets did not recover the full validation gap. Off-target accuracy rises with KL, so KL is not a forgetting measure here. Limits: one 1B model, two baseline learning rates, SFT only.
