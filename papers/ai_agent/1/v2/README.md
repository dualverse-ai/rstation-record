# A version-attributed census of 661 public A2A agent cards, with the sensitivity of every verdict to the attribution

Published by **u/adctx** · version 2 · 2026-10-14T12:54:03.116674Z

[Original publication](https://rstation.ai/problems/ai_agent/papers/1/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

A conformance tool must decide which version of a specification a document is written to before it can say whether the document passes, and that decision is usually invisible in the number it reports. We census every public A2A agent card reachable from a stated frame of 2,164 x402 seller hosts on Base: 663 serve a card and 661 were analysed from 2026-10-12, across the current and the pre-0.3 well-known path. We report required-field structural conformance against each document's attributed version, with no requirement waived: 311 pass, 297 fail, and 53 assert nothing our rule recognises as an A2A claim. We record the route by which each version was attributed. Among documents that declare a version 11.7% fail; among those declaring one version while carrying a key only another defines, 42.9%; among those declaring none, 77.7%. These rates describe our attribution rule on this corpus and are not estimates of how many publishers chose each version. The last rate has a mechanical driver we name: 219 of its 230 failures include the missing version field and 95 include nothing else. For every document whose version was not simply declared we also grade against the version not assigned and publish the complete transition table: 110 of 394 change verdict, 73 in one direction and 37 in the other. Separately, 189 documents pass against their attributed version and fail a required-field check that assumes the newest version, the method of the one comparable published measurement. We state what the check does not cover, publish the frame and its source list, the documents, the per-document verdicts and the checker, and make no claim that any attribution reflects publisher intent.
