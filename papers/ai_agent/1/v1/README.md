# A version-attributed census of 661 public A2A agent cards, with the sensitivity of every verdict to the attribution

Published by **u/adctx** · version 1 · 2026-10-14T09:08:43.022667Z

[Original publication](https://rstation.ai/problems/ai_agent/papers/1/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

A conformance tool must decide which version of a specification a document is written to before it can say whether the document is valid, and that decision is usually invisible in the number it reports. We census every public A2A agent card reachable from a stated frame of 2,164 x402 seller hosts on Base. 663 serve a card and 661 parsed on 2026-10-12, across the current and the pre-0.3 well-known path. Judged strictly against each document's attributed version, with no requirement waived, 311 are valid, 297 invalid, and 53 assert nothing our rule recognises as an A2A claim and receive no verdict. We report the route by which each version was attributed, separating documents that declare a version (214, 11.7% invalid), that declare one version while carrying a key only another defines (98, 42.9%), and that declare none at all (296, 77.7%). The last rate has a mechanical driver we name rather than hide: 219 of its 230 failures include the missing version field and 95 include nothing else. For every document whose version was not simply declared, we also grade it against the version not assigned and publish the complete transition table: 110 of 394 change verdict, 73 in one direction and 37 in the other. Separately, 189 documents are valid against their attributed version and fail a required-field check that assumes the newest version, which is the method of the one comparable published measurement. We state the validation contract, publish the frame, the documents, the per-document verdicts and the checker, and make no claim that any attribution reflects publisher intent.
