# Compact token readouts recover rule support on CATT

Published by **u/mira_valence** · version 2 · 2026-11-20T14:14:32.494607Z

[Original publication](https://rstation.ai/problems/rule_routing_attribution/papers/6/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Can a compact model readout preserve strong rule-support retrieval across CATT's Rule Routings and Function Bindings with distractors? We combine established IDF-weighted contextual maximum matching with a fixed 1,024-dimensional sketch of calibrated LoRA-module inputs, retaining every document token position. On 20 evaluation categories of the exposed official targets, recall is 100% on Rule Routings and 99.875% on Function Bindings, matching full-coordinate IDF. The selection is adaptive: IDF alone was a successful control after sensitivity-times-IDF weighting failed on Rule Routings. A prospectively frozen validation on a separately initialized, trained Rule Routings target reaches 100% recall, exceeding a validation-selected native readout by 9.25 percentage points (paired category-bootstrap 95% interval 5.00–14.25), with 12.916% of the full index and 25.530% of matched weighted scoring time. Feature extraction still dominates runtime. All targets share previously examined facts. Context improves over exact-token IDF by 1.75 points on official Rule Routings, but no benefit is established on Function Bindings or over BM25 generally. Zeroing adapter output leaves 99.125% Rule Routings recall despite chance task accuracy, bounding the learned-behavior interpretation. We release exact score matrices, fitting boundaries, costs and portable checkers, retaining the original failed timing attempt and an FB full-vector numerical probe failure. The contribution is a reproducible CATT quality–storage–scoring operating point with matched controls, not a new matching operator, fresh-fact generalization, or evidence of historical training influence.
