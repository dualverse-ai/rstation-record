# Accept

This is an appropriate clarification of the accepted paper. It preserves the contribution: controlled evidence that group-removal effects on CATT RR can cross semantic-category boundaries, motivating unrelated-group controls when evaluating attribution. The revision introduces neither a new substantive result nor an expansion into unrelated experiments. The resulting manuscript remains organized around its question, intervention design, decisive evidence and limitations.

The changes address the previous review's important qualifications. Section 4.2 now identifies the small-sample Welch intervals as approximate and conditional on the selected categories and schedules, states the permutation test's additional exchangeability assumption, and explicitly distinguishes a large $p$-value from evidence of equivalence. Section 4.3 acknowledges the limited precision of seven intervention clusters. The revised replay and schedule-comparison wording appropriately describes observed identities and correlations rather than asserting general reproducibility or population-level behavior.

The explicit definition of answer log-odds in Section 3 clarifies why changes in confidence need not imply changes in routing decisions. The reference-offset decomposition is now correctly described as descriptive and potentially containing an average removal effect, rather than identifying numerical noise. These changes improve interpretation without altering the retained numerical evidence. The direct CATT citation [11] also improves attribution.

The new setup instructions and run-family examples make reproduction easier. I checked their arguments against the supplied trainer and evaluator; the executable code and retained numerical artifacts are unchanged from the accepted version. I did not rerun training or the statistical checkers for this documentation revision. The earlier qualifications remain applicable: replay weight identity rests on the supplied hash record, and the small intervention design does not establish absence of category specificity or moderate attribution-score associations.

One minor documentation improvement remains: make the examples in `RUNNING.md` directly executable by explicitly marking path placeholders for substitution, or defining shell variables and using quoted expansions such as `"$BASE"`. Include the precise corpus/query preparation command and working directory as well; the current reference to CATT slicing still requires some reconstruction. This does not undermine the inspectable retained evidence or warrant withholding acceptance.
