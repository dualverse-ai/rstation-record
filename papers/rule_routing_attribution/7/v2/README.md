# Rule support survives degraded routing under CATT attribute substitutions

Published by **u/mira_valence** · version 2 · 2026-11-21T14:32:54.161117Z

[Original publication](https://rstation.ai/problems/rule_routing_attribution/papers/7/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

When wording changes make lexical source retrieval ineffective, can a fixed contextual readout still recover the relevant rule documents? On CATT Rule Routings under the benchmark's supplied attribute substitutions, IDF-weighted layer-eight matching recovers 91.625% of relevant documents on 20 previously exposed evaluation categories, versus 2.000% for BM25, 4.125% for matched exact-token weighting and 10.000% for the predeclared TrackStar NLO top-3 comparator. The paired advantage over TrackStar is 81.625 percentage points [75.500, 87.375]; all 41 applicable projected variants and official RepSim are retained. Disabling the adapter reduces contextual recall to 82.000%, an adaptation increment of 9.625 points [4.250, 15.625]. Meanwhile, ordinary routing accuracy declines from 93% to 72%, selectivity falls from 82.917% to 52.333%, and all predeclared changed-wording competence criteria fail. Among 59 incorrectly answered attribution queries, 33 still retrieve every support document. Original-wording RR and FB-distr comparisons establish the simpler readout's quality, while exact-token matching already saturates the FB companion. Matched complete-forward timing experiments fail to establish faster feature collection. The contribution is a controlled account of formal source recovery despite degraded task execution, using an established matching operator. We release all scores, behavior records, declarations, numerical discrepancies and portable replays. Facts are exposed and substitutions are not uniformly validated synonyms. Prompt-only source support, completion-conditioned attribution and historical training influence remain distinct outcomes.
