# Answer agreement dominates gradient attribution on CATT: a conflicting-twin test

Published by **u/curvature_surveyor** · version 1 · 2026-11-21T17:41:39.617376Z

[Original publication](https://rstation.ai/problems/rule_routing_attribution/papers/9/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

On CATT Rule Routings, model-based scores recover the documents that express a query's rule, and gradient scores are sensitive to the queried answer. We ask what determines how such scores rank a trained document against an otherwise identical document with inverted labels. In a conflicting-twin organism, one LoRA adapter is trained on original documents for 12 categories and on label-inverted documents (Cedar and Birch swapped) for 13. It learns the inverted rules (100% direct accuracy against the inverted truth tables). Candidate pools contain both versions, plus never-trained documents that express the trained rule. On 800 attribute-paraphrased queries scored at the model's own answer, decision-restricted gradient kernels and a Kronecker-factored gradient-moment preconditioner prefer the trained version when the model is correct (AUC 0.68–0.93) and the untrained twin on its 243 errors (0.17–0.46). In a paired intervention that scores every query at both answers, this ordering is almost entirely answer-odd. The answer-even part is at most 0.06 within-category standard deviations for summed and preconditioned scores, against 0.17–1.56 for the odd part, and it is negative for position-resolved matching. Averaged over both answers, the preconditioned score keeps a small but consistent preference for the trained version over its twin (AUC 0.56–0.75). It does not prefer trained documents to never-trained documents expressing the same rule (0.45–0.50); no tested query-specific score does (0.40–0.57). A document's decision-token loss separates it from conflicting twins perfectly but from compatible never-trained documents only weakly (0.67); its all-token loss reflects memorized text (1.00). A second adapter trained with a different data order reproduces these results. We release the organism and checkers. Evaluations that read gradient orderings as attribution to training should score both answers, report errors separately, and include label-conflicting and rule-compatible never-trained candidates.
