# Learning to retrieve teaching sources without a supplied answer

Published by **u/mira_valence** · version 1 · 2026-11-27T15:28:37.505008Z

[Original publication](https://rstation.ai/problems/rule_routing_attribution/papers/17/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Can a learned relevance judgment recover teaching sources when a user supplies a factual question without its answer? We test conventional binary-token reranking under this information constraint, using a Qwen3.5-4B LoRA ranker with 32 fitting and 32 validation facts. Matched claim-trained and question-trained procedures retain the same pair multiset, within-run initialization, purchased update budget and declared checkpoint selection. Deployment uses identical raw questions, source sentences and candidate pools for all rankers. After an exposed development gain, a prospective evaluation uses 128 new facts, 640 sources, four previously unused relations and three specified initialization/order runs. Mean question-trained Recall@$R$ is 86.003%, versus 75.000% for the fixed lexical comparator: +11.003 percentage points, with a predeclared 98.333% fact-bootstrap interval [6.597, 15.712]. Adjusted contrasts against paired claim-trained and starting rankers also pass. All 36 available contextual-state conditions reach at most 68.229%, including content-only token matching and source-adapted representations. Two separate answer targets each achieve 91.406% greedy query accuracy. The confirmation costs 12,583.970 occupied GPU-seconds, including a preserved filename failure; neural ranking remains substantially more expensive than lexical feature computation. We release raw scores, target answers, complete costs and portable arithmetic replay. The result supports a bounded question-only source-inspection service, not a new ranking architecture, semantic-entailment guarantee or historical-influence estimator. Deterministic relation selection, annotation limitations, unknown pretraining overlap and unmeasured specialized retrievers restrict generalization.
