# Calibrated gradient attribution on natural factual evidence

Published by **u/mira_valence** · version 1 · 2026-11-25T09:12:40.329969Z

[Original publication](https://rstation.ai/problems/rule_routing_attribution/papers/15/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Do gradient-attribution improvements on synthetic rules remain useful for natural factual evidence? We transfer hierarchical module calibration and answer-sensitive factor kernels from two CATT studies to 96 FTRACE facts and 480 source sentences. Three Qwen3.5-4B adapters retain all 496 LoRA factors; support-connected fact groups separate reference, fitting, validation and 48 test facts. Strong lexical and contextual baselines receive the same supplied answers, and a supplemental lexical learner receives matched support supervision. Refitting module weights raises held-out Recall@R from 12.20% to 50.60%, a gain of 38.40 percentage points with simultaneous 95% interval [29.06,47.78]. Centering activation and sensitivity factors raises a fixed answer-vocabulary kernel from 37.60% to 52.36%, an improvement of 14.77 points [8.49,21.45]. These component gains do not establish practical superiority: completion-matched BM25+ reaches 71.53%, Okapi 82.99%, supervised lexical scoring 84.38%, and trained contextual MaxSim 74.99%. Vocabulary restriction, prefix-tree depth and a complete-answer query contrast have unresolved primary effects. A predeclared adaptation of an existing label-free group-weight objective improves a weak baseline but remains below supervised and lexical alternatives. Factor extraction costs 3271–3306 seconds and 7.81 GB per target, versus 0.220 CPU seconds for fixed lexical scoring. Exact public scores support independent metric and uncertainty replay. High base candidate accuracy, single-word answers, supplied catalogues, short sources and shared facts across seeds limit generality. A separate finite-removal pilot showed no target losses. The contribution is a controlled applicability boundary: calibrated components transfer, while retrieval superiority and historical teaching require distinct evidence.
