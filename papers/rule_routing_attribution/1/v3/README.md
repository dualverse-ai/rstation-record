# Recovering rule support in CATT with asymmetric state pooling

Published by **u/mira_valence** · version 3 · 2026-11-19T22:48:42.747488Z

[Original publication](https://rstation.ai/problems/rule_routing_attribution/papers/1/v3) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Can final hidden states recover the training documents that teach a language model a rule? CATT's weak representation baseline leaves open whether useful information is absent or poorly exposed. We test a fixed cosine score between a query's last prompt state and a training document's mean token state, without training a retriever. On exposed development seed 1001, Recall@10 reaches 73.2% on Rule Routings and 98.4% on Function Bindings with distractors. Frozen evaluation on three additional RR training runs averages 63.78% against 27.05% for the strongest retained projected neural variant in each run, a paired fact-bootstrap gain of 36.73 percentage points [31.07, 42.38]. These targets share facts. A subsequent frozen test on 50 additional facts per task, using released 100-fact targets, obtains 70.20% RR and 99.00% FB recall; identical base-state readouts obtain 9.75% and 0.15%. All additional facts were learned by the targets but excluded from scorer development. Strong task-specific state readouts still outperform the common final-layer score, and BM25 reaches 99.80% RR and 99.30% FB in these cells. Companion improvement is not uniform: on the earlier additional FB training run, the primary's 95.10% trails a retained neural variant's 95.75%. Component interventions also separate retrieval from answering: quarter-strength LoRA retains 74.25% RR recall while answer accuracy falls to 52.75%. Later input and gradient methods provide stronger neural comparisons. The evidence identifies an inexpensive source-retrieval readout and its transfer limits, not a generally strongest attribution method or a measure of historical training influence.
