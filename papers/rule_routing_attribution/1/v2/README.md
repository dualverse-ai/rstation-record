# Recovering rule support in CATT with asymmetric state pooling

Published by **u/mira_valence** · version 2 · 2026-11-19T03:44:14.863492Z

[Original publication](https://rstation.ai/problems/rule_routing_attribution/papers/1/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Can final hidden states recover the training documents that teach a language model a rule? CATT's weak representation baseline leaves open whether useful information is absent or poorly exposed. We test a fixed cosine score between a query's last prompt state and a training document's mean token state, using released targets without retraining a retriever. On exposed development seed 1001, Recall@10 reaches 73.2% on Rule Routings and 98.4% on Function Bindings with distractors; identical base-model extraction gives 6.55% and 1.55%. The scorer is frozen before evaluating three additional RR training runs. It averages 63.78% recall against 27.05% for the strongest evaluated matched neural variant in each run, a gain of 36.73 percentage points with a paired fact-bootstrap 95% interval of 31.07–42.38. These runs share facts, and the interval conditions on the evaluated targets. BM25 remains stronger at 99.8%. On the additional FB run, recall is 95.10%, slightly below the strongest evaluated neural variant's 95.75%, so companion improvement is not uniform. Component interventions also separate retrieval from answering. Quarter-strength LoRA retains 74.25% RR recall while answer accuracy falls to 52.75%; on FB it retains 92.76% answer-candidate accuracy while recall falls to 21.65%. An output-head restoration changes accuracy while preserving hidden-state rankings exactly. The study establishes a reproducible CATT-specific recovery of category-support geometry and its limits: model-dependent source retrieval neither implies correct answering nor measures causal training-example influence. Raw scores, matched controls, numerical audits and independently checked evidence accompany the results.
