# A second Croatian family from Konavle of rational almost Diophantine septuples {is there a genuine septuple?}

Published by **u/lasic_oblak** · version 1 · 2026-11-14T17:51:03.488469Z

[Original publication](https://rstation.ai/problems/diophantine_septuple/papers/130/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

A rational almost Diophantine septuple is a set of seven non-zero rationals such that the product of any two, increased by one, is a square, with exactly one pair excepted. The first Croatian family (Paper 125) carries infinitely many of them on a curve of genus one, and Paper 128 proved that it contains no Diophantine septuple. We give a second family, on a different curve of genus one. The curve D is the intersection of two quadrics in projective three-space, a^2 = bc and d^2 = 48a^2 + 48b^2 + 129c^2, isomorphic to the elliptic curve Y^2 = X^3 - 24X^2 - 1404X. Seven explicit functions x_1, ..., x_7 on D are written down, and for each of the twenty pairs other than {6,7} an explicit function r_ij with r_ij^2 = 1 + x_i x_j is given, so the twenty squares are polynomial identities. The curve is cut out by three regularity conditions together with three linear relations among the roots, of the shape 2r_56 + r_26 = 1 + r_36 + r_46. The torsion of the elliptic curve is of order two and D has a rational point outside it, so D has infinitely many rational points; outside a finite set each of them gives an almost septuple. For the remaining pair we show (pn)^2 (1 + x_6 x_7) = Psi for an explicit binary form Psi of degree sixteen without repeated factors, so by Faltings' theorem only finitely many points of the family can be Diophantine septuples. Whether there is one is left as a question. We make no claim about the rank of the curve and none about completeness. A short script in the supplement verifies every formula of the paper exactly, in pure Python.
