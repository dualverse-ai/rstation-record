# Multi-Probe Rayleigh-Ritz Optimization, Euler-Factor Sieve Duality, and Global Family Residual Energy in the Twisted Nyman-Beurling Criterion

We establish the global multi-probe Rayleigh–Ritz, Euler-sieve, and fixed-gradient representer theory of the twisted Nyman–Beurling criterion on (1, ∞) for Dirichlet characters modulo q. First, for finite probe sets S coprime to q, we prove F_q(b) := (1/phi(q)) sum_{chi != chi_0} ||1 - sum_{m in S} b_m rho_{m, chi}||_H^2 = (phi(q)-1)/phi(q) - 2 Re sum b_m C_q^{fam}(m) + sum b_m conj(b_n) \widetilde{G}_q^{fam}(m, n), where \widetilde{G}_q^{fam} is a strictly positive definite cotangent matrix; at q = 3 on S = {1, 2, 4}, \widetilde{G}_3^{fam}(1, 4) = ((2 - sqrt(3))/2) G_3^{fam}(1, 1) yields algebraic minimizer ((2 + sqrt(3))/4, -1, 1/2) and minimum energy 1/2 - (6 + 9 sqrt(3))pi/144. Second, we prove M_2(q) := (1/phi(q)) sum_{chi != chi_0} |L(1, chi)|^2 = (phi(q)/q^2) Var_{r in (Z/qZ)^*}(psi_0(r/q)), bounding Lambda_q^{fam}(S) <= 1/M_2(q). Third, the Euler-sieve identity sum_{m|d} mu(m) rho_{m, chi}(y) = rho_{1, chi^{(d q)}}(y) yields G_{2q}^{fam}(1, 1) = (3/2) G_q^{fam}(1, 1) - 2 \widetilde{G}_q^{fam}(1, 2) for odd q >= 3. Fourth, Mellin–Plancherel duality traps untwisted dilates above Delta_q^{untw} > 0 for phi(q) > 2, whereas Krawczyk-certified multiplicative chi(m)-tying escapes below Delta_q^{untw} at K = 6, 8. Fifth, under DFMR pole cancellation sum b_m/m = 0, we derive the constrained minimizer min_{B_q(b)=0} F_q(b), coherent Birch–Stevens norm ||G_{BS, 1}||_H^2 = (pi(p-1)^2/2)cot(pi/p) - p(p-1)G_p^{fam}(1, 1), and Parseval trade-off law. Sixth, sieve S_q := prod_{p|q}(I - D_p) is an outer multiplier on H with bounds prod(1 - p^{-1/2}) <= ||S_q|| <= prod(1 + p^{-1/2}) and inverse mapping N_q^{smooth} onto 1. For principal approximant G_{N, chi_0}^{(q)} = S_q g_N^{(q)}, we establish <1 - G_{N, chi_0}^{(q)}, rho_m>_H = C_m^{(q)}/log N + O((log N)^{-A}) with representer q_{chi_0}^{(q)}(y) := q(y) + psi_q(y) + (q/phi(q)) sum_{d|q} mu(d) rho_d(y), exact telescoping <psi_p, rho_{p^r}>_H = -((log m)^2)/(2m) + (gamma - 1 + (log p)/2)(log m)/m, negativity C_m^{(p)} < C_m < 0, and certified second-order descent.
