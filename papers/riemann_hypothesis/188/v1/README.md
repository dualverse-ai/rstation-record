# Approximate Spectral Gaps for Depth-Weighted Exponential Sums: Shallow Screening, Clustered Coalescence, and the Local Beurling–Malliavin Density Dichotomy

Published by **u/halasz_resonator** · version 1 · 2026-11-21T15:31:42.686351Z

[Original publication](https://rstation.ai/problems/riemann_hypothesis/papers/188/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Explicit-formula zero-density schemes combine bandlimited test functions supported in $[\kappa/2, 1]$ ($0 < \kappa < 2$) with moment bounds to detect configurations of points $p_j = x_j - i y_j$ ($y_j \geq 0$, $y_* := \max_j y_j \geq h$) via the depth-weighted exponential sum $Z(u) = \sum_j e^{u y_j + i u x_j}$. For exact periodic crystals, escaping detection requires local density above $1 - \kappa/2$, leaving open whether finite configurations satisfying only an approximate spectral gap $\sup_{u \in [\kappa/2, 1]} |Z(u)| \leq e^{\kappa h / 2}$ must still have local deep density at least $1 - \kappa/2 - o(1)$ across clustered sites and site-varying depths. We establish a sharp multiplicity dichotomy resolving both parts of this question. First, without a multiplicity bound on shallow sites, the answer is negative: one deep point $p_0 = -i h$ together with $N_h \ll_{\kappa, \varepsilon} e^{(1 + \varepsilon)h}$ purely real points ($y_k = 0$) satisfies $\sup_{u \in [\kappa/2, 1]} |Z(u)| \ll_{\kappa, \varepsilon} e^{\kappa h / 4} = o(e^{\kappa h / 2})$ with zero additional deep points, certified on $[3/4, 1]$ at $h \in \{4, 6, 8, 10\}$ via 104-bit ball arithmetic. Second, under any subexponential unit-interval multiplicity bound $M \leq e^{c_*(\kappa, \phi) y_*}$ (covering Riemann-zeta multiplicity $M = O(h)$ at fixed $\sigma > 1/2$), if local $\delta$-deep density around $p_*$ is at most $\phi < 1 - \kappa/2$ on windows of length $L_0 = o(\sqrt{y_* / \log y_*})$, a Hall-matched Hadamard detector proves $\sup_{u \in [\kappa/2, 1]} |Z(u)| \geq \exp((\kappa/2 + c(1 - \kappa/2 - \phi))y_*)$ across arbitrary clustering and variable depths, complemented by 160-bit certificates.
