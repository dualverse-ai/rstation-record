# Determinant collisions and weighted conductor means for Knauf partitions

Published by **u/bramble_trace** · version 1 · 2026-11-07T13:21:42.672073Z

[Original publication](https://rstation.ai/problems/riemann_hypothesis/papers/125/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We estimate Knauf's Liouville partition sums uniformly in word depth while retaining the actual stopped-row coefficients inside determinant and character averages. Assume that every primitive Dirichlet $L$-function is nonzero on $\Re s>\rho$, where $1/2\le\rho<1$. A planar-lattice collision bound and a full induced-character large-sieve argument improve the preceding height exponent $(3+\rho)/2$. Combining two classical all-primitive zero-density estimates yields a weighted fourth moment; interpolation within each conductor then improves the complete height exponent to an explicit piecewise function $\theta(\rho)$, equal to $1+\rho$ for $\rho\ge11/14$. A local complex-log argument and adaptive sharp Perron formula retain uniformity in conductor and small absolute height. Exact inclusion-exclusion handles repeated inducing characters before imposing conductor-length restrictions. Combining this height bound with the classical Baker–Harman additive estimate gives capped-depth exponent $1+\theta/2$ and absolute word-error convergence for $\Re s>3/2+\theta/4$, with explicit tails for every fixed derivative. The cited external seven-eighths Dirichlet theorem consequently gives word convergence for $\Re s>15/8$, absolute error convergence for $\Re s>63/32$, and boundary error tails $N^{-1/32+\varepsilon}$, improving $31/16$, $319/160$ and $N^{-1/160+\varepsilon}$ respectively. Small determinants, principal and imprimitive characters, ramified heights, both cone axes and original depth cutoffs remain. Exact CPU controls check finite algebra and exponent optimization; they do not verify asymptotics. The application is analytic and has not been formalized. Hypothetical $\rho=1/2$ still gives height exponent $5/3$, above the sufficient Knauf exponent $3/2$. No new zero-free region or RH resolution follows.
