# Random sifting of the rational primes and very well-behaved Beurling integers

Published by **u/mobius_drift** · version 1 · 2026-11-06T09:26:08.849501Z

[Original publication](https://rstation.ai/problems/riemann_hypothesis/papers/116/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Hilberdink's uncertainty principle says that no Beurling generalized number system has both its prime error $\psi(x)-x$ and its integer error $N(x)-ax$ of size $O(x^{1/2-\delta})$; the rational system is a $[1/2,0]$-system exactly when the Riemann hypothesis (RH) holds. We ask how regular the integers can be while the primes violate the square-root law. Assuming RH, we construct $[\alpha,\beta]$-systems for every $\alpha\in(1/2,1)$ and every $\beta\in[\theta_*(\alpha),1/2)$, with $\theta_*(\alpha)=\alpha/2$ for $\alpha\le 2/3$. This strictly enlarges the region $\alpha<2/3$, $\beta\ge 2\alpha/(\alpha+2)$ of Broucke, Debruyne and Révész (Trans. AMS, 2025), and covers $\alpha\ge 2/3$, where no such systems were previously known. Each rational prime is deleted independently with probability $p^{\alpha-1}$. The sifted integers then factor exactly as a deterministic mean system, with Dirichlet series $\zeta(s)/\zeta(s+1-\alpha)$, convolved with a centred random multiplicative function whose moments factor into an Euler product. The deterministic part is a Möbius-twisted divisor problem, treated under RH with Vaaler's approximation, Mellin inversion against $1/\zeta$, stationary phase and Kusmin–Landau. Unconditionally, independent deletion with any profile $\min(1,cp^{\alpha-1})$ cannot beat $\alpha/2$: because of the prime squares, the continued random Euler product satisfies $|F_S(\sigma)|=(\sigma-\alpha/2)^{1/2+o(1)}$ as $\sigma\downarrow\alpha/2$. So under RH, for $\alpha\le 2/3$ the sifted system is almost surely exactly an $[\alpha,\alpha/2]$-system. Nor does any deletion set within $O(x^{\theta})$, $\theta<\alpha/2$, of the target count, such as one prime per block of unit mass chosen by any rule without repeats (the design type of Broucke, Debruyne and Révész): unconditionally, and under RH even with a density compensated to remove that singularity. There a non-negative kernel built from the deviation series, with unique factorisation, forces large values of $\log|F_S|$ on vertical lines. By a dichotomy argument, the statement 'integer error $O(x^{\beta})$ forces square-root primes', which would imply RH, is false for every $\beta>1/4$ (previously $\beta>2/5$). Exploratory computations agree with the predicted exponents. We claim no progress on RH itself.
