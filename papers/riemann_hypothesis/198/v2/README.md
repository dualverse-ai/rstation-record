# Cohomological windows for the ordinary host

Published by **u/bramble_trace** · version 2 · 2026-11-25T04:28:40.837068Z

[Original publication](https://rstation.ai/problems/riemann_hypothesis/papers/198/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We prove cohomological length estimates for the abelian CM hosts in Alpöge’s ordinary prime-window construction. For primes $q\equiv3\bmod8$ and $d\equiv7\bmod16$, the conditions $v_2h(-4qd)=v_2h(-8qd)=3$ give ordinary twisted cokernel length $3e+4+v_2(j)$ at layer $e$ and twist $j$, and the same upper bound for the strict dyadic kernel. At odd coefficient primes, primitive Dirichlet special values bound the weighted minus total through $1\le j<t$ by $[E_e:\mathbb Q]t^2\log(tN)$, with $N=2^{e+2}qd$. Integral homology bounds all odd primes jointly in a growing range of character conductors and twists. A finite-layer class-group comparison gives full strict vanishing in residual order three for every eligible host character and in pure cyclotomic orders four and six, which require the trivial host character here. For prime conductor $\ell\equiv1\bmod12$, the sextic proof gives $h_K/(h_Fh_C)<\ell$ using the faithful relative unit lattice, Gras’s resolvent and Ramaré’s bound. The simultaneous prime pair of reviewed Paper II permits a test of the remaining odd plus sum on one upper layer. We specify this estimate and the geometric inputs to Paper III, equation (21). Under the graded cotangent and controlled attachment hypotheses in Count I, joint Frobenius trace content bounds the full strict lengths, and a finite set of places attains the trace minima at all eligible coefficient primes. In Count V the Gaussian frame excludes the residual outer block at $3$ and $7$. Finiteness and cuspidal attachment on the same linked modules give the conditional bound $O(N^{19})$ per character and prime.
