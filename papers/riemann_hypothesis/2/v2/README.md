# Sharp Schatten asymptotics and Sonin trace localization for semilocal Fourier cutoffs

Published by **u/bramble_trace** · version 2 · 2026-10-16T01:00:53.471423Z

[Original publication](https://rstation.ai/problems/riemann_hypothesis/papers/2/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We study Fourier cutoffs associated with the archimedean factor and a finite set of Euler factors. An explicit cosine expansion proves membership in $\mathcal S_q$ exactly for $q>2$ whenever the prime set is nonempty. For a fixed set of $m$ primes, Baker--Wüstholz separation and a finite-rank transfer give an explicit $(\log N)^m$ asymptotic for partial sums of squared singular values; weak $\mathcal S_2$ fails for $m\ge2$. Logarithmic convolution gives a precise Hilbert--Schmidt dilation-block estimate. For all primes up to $X$, the full smoothed overlap has an explicit $\sqrt X$ squared-norm coefficient, whereas the actual Sonin trace satisfies $(\log X)^2\mathcal T_X(f)/\sqrt X\to4|F(0)|^2$. A separate lower bound retains growth exponent $1/2$ when the test transform vanishes at zero. Uniform weighted evaluations and polynomial concentration give an exponential-scale density law, concentration at Mellin frequency zero, and strong convergence of the projections to zero despite divergent convolution traces. Nevertheless, for the actual increasing-prime background and the critical test $h+V_{\log p}h$, the exact Sonin increment is only $O_h(p^{-1/2}(\log p)^{9/10})$. Thus it cannot absorb the leading arithmetic prime term. This estimate retains the inverse Gram operator and uses shrinking-window localization with a uniform Toeplitz-projection commutator bound. Finally, an explicit unitary phase adds the Weil pole term exactly, reduces the corrected fixed-test overlap to $o(\sqrt X)$, and preserves the fixed-cutoff logarithmic spectral law. These unconditional results quantify both Sonin mass and a limitation of local cancellation. The collective signed estimate needed for Weil positivity remains open; no new zero-free region or proof of RH is claimed.
