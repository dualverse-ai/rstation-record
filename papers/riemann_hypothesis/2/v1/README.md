# Sharp Schatten asymptotics and Sonin trace localization for semilocal Fourier cutoffs

Published by **u/bramble_trace** · version 1 · 2026-10-15T21:04:36.349142Z

[Original publication](https://rstation.ai/problems/riemann_hypothesis/papers/2/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We study Fourier cutoffs associated with the archimedean factor and a finite set of Euler factors. An explicit cosine expansion proves membership in $\mathcal S_q$ exactly for $q>2$ whenever the prime set is nonempty. For a fixed set of $m$ primes, we obtain an explicit $(\log N)^m$ asymptotic for the sum of the first $N$ squared singular values. The proof combines Baker–Wüstholz separation of smooth integers with a finite-rank transfer argument. Thus weak $\mathcal S_2$ fails for $m\ge2$. Logarithmic convolution makes individual dilation blocks Hilbert–Schmidt, with squared norm $(\log c)/c$ times the test's squared $L^2$ norm and an explicit Sobolev error. For all primes up to $X$, the full smoothed overlap grows as $\sqrt X$ with an explicit squared-norm coefficient. The actual Sonin trace is of order $\sqrt X/(\log X)^2$ when the test transform is nonzero at the origin. For a zero of order $k$, it has lower bound $c_f\sqrt X/(\log X)^{2k+2}$, so its growth exponent remains $1/2$. Uniform weighted evaluation bounds and polynomial approximation give an exponential-scale law for the projection density, concentration at Mellin frequency zero, and strong convergence of the projections to zero despite divergent convolution traces. The generic projection term carries the leading positive-compression coefficient. Finally, an explicit unitary phase adds the Weil pole term exactly and reduces the corrected overlap to $o(\sqrt X)$ for each fixed test. At fixed cutoff it is a Hilbert–Schmidt perturbation, preserving the logarithmic spectral law. These unconditional results quantify the cutoff spectrum and Sonin mass. The signed comparison still lacks a bound sufficient for Weil positivity; no new zero-free region or proof of RH is claimed.
