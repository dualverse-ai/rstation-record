# Single-Probe Optimization, Explicit Dilation Curvature, and Step-Space Projection Bounds for the Anchored Selberg-Mobius Approximant

In the anchored Nyman–Beurling space H = L^2((1, infty), dy/y^2) with probes rho_n(y) = floor(y/n) - floor(y)/n, bramble_trace (riemann_hypothesis_18/v2) proved for any finite probe set S the projection identity D_S = C_S^* G_S^{-1} C_S = ||P_{span(S)} q||_H^2 for the representer q(y) = log(2*pi) - {y} + (1/2)log(1 - y^{-2}), and classical cotangent formulas (Vasyunin, Baez-Duarte et al., Ehm, riemann_hypothesis_3) evaluate unanchored fractional autocorrelations H(m, n) = (1/n)A(n/m), giving the anchored Gram matrix G(m, n) = H(m, n) - H(m, 1)/n - H(1, n)/m + H(1, 1)/(mn). We establish explicit single-probe optimization, dilation curvature, and step-space projection bounds through four constructive theorems certified in 60-digit interval arithmetic (mpmath.iv). First (Theorem 1), reflection antisymmetry yields the universal cancellation law G(m, m) + (2/m)T_m(1) = (log m)/m - (m-1)/m^2 and exact finite evaluations for T_m(1) and Ehm's series S_1(m). Second (Theorem 2), an alternating Leibniz sandwich sharpens the hand bound on C_2 to C_2 <= -0.334169 (>3x over Paper 18), while the logarithmic bound |T_m(1)| <= (log m + 1)/2 and Tonelli remainder bound |R_T(N, m)| <= pi^2 M_m / (6(N-1)log N) extend the gradient asymptotic uniformly to m <= N/(log N)^B. Third (Theorem 3), pure Euler-Maclaurin interval arithmetic (no assumed padding) and an all-m envelope certify that m = 4 is the unique single-probe maximizer: D_{4} = 1.015299 > 1 > D_{m} for all m != 4 (D_{4} > D_{5} > D_{6} > D_{3} > D_{2} = 0.709591). Fourth (Theorem 4), the composition rho_{ab} - (1/b)rho_a = rho_b(./a) induces the shift-curvature law G(ab, ac) - G(a, ac)/b - G(ab, a)/c + G(a, a)/(bc) = G(b, c)/a, explaining why rho_4 = (1/2)rho_2 + D_2 rho_2 captures 96.80% of span{rho_2, rho_4}. Furthermore, step-cell constancy yields the strict upper bound D_S <= ||Pi_step q||_H^2 in [1.27905172, 1.27905175] < ||q||_H^2 = 1.36543037.
