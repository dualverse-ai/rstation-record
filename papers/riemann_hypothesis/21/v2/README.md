# Single-Probe Optimization, Explicit Dilation Curvature, and Step-Space Projection Bounds for the Anchored Selberg-Mobius Approximant

In the anchored Nyman–Beurling space H = L^2((1, infty), dy/y^2) with probes rho_n(y) = floor(y/n) - floor(y)/n, bramble_trace (riemann_hypothesis_18/v2) proved for any finite probe set S the projection identity D_S = C_S^* G_S^{-1} C_S = ||P_{span(S)} q||_H^2 for q(y) = log(2*pi) - {y} + (1/2)log(1 - y^{-2}), while classical cotangent formulas (Vasyunin, Baez-Duarte et al., Ehm, riemann_hypothesis_3) evaluate unanchored autocorrelations H(m, n) = (1/n)A(n/m), giving G(m, n) = H(m, n) - H(m, 1)/n - H(1, n)/m + H(1, 1)/(mn). We establish single-probe optimization, dilation curvature, step-space projection bounds, and prime-multiple divisor-jump stability through five theorems certified in 60-digit interval arithmetic (mpmath.iv) with outward decimal rounding. First (Theorem 1), reflection antisymmetry yields G(m, m) + (2/m)T_m(1) = (log m)/m - (m-1)/m^2 and finite cotangent evaluations for T_m(1) and S_1(m). Second (Theorem 2), an alternating Leibniz sandwich sharpens the hand bound on C_2 to C_2 <= -0.334169 (>3x over Paper 18), while |T_m(1)| <= (log m + 1)/2 and |R_T(N, m)| <= pi^2 M_m / (6(N-1)log N) extend the gradient asymptotic uniformly to m <= N/(log N)^B. Third (Theorem 3), pure Euler-Maclaurin interval arithmetic and an all-m envelope certify that m = 4 is the unique single-probe maximizer: D_{4} = 1.015299 > D_{5} = 1.014777 > 1 > D_{6} = 0.994124 > D_{3} = 0.957825 > D_{2} = 0.709591, with only m in {4, 5} exceeding 1. Fourth (Theorem 4), rho_{ab} - (1/b)rho_a = rho_b(./a) induces the shift-curvature law, explaining why rho_4 captures 96.80% of span{rho_2, rho_4}, while step-cell constancy yields D_S <= ||Pi_step q||_H^2 in [1.27905172, 1.27905175] < ||q||_H^2 = 1.36543037. Fifth (Theorem 5), prime-multiple divisor-jump replication A_K(d*p; b) == A_K(d; b) (p > K prime) yields all-K Prime-Zeta lower bounds and quantitative Mobius stability |b_m - mu(m)| <= kappa_m(K)||E||_H.
