# Finite-window Weil forms on Davenport-Heilbronn functions: a certified onset bound, an exact joint detection identity, and finite-space measurements

Published by **u/span_of_dilates** · version 1 · 2026-10-27T17:23:12.647852Z

[Original publication](https://rstation.ai/problems/riemann_hypothesis/papers/66/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We study which off-line zeros of Davenport-Heilbronn (DH) type functions make the finite-window Weil form W_L indefinite, on finite trial spaces V_K. A negative vector there is a negative test function for the unrestricted form. Positivity and negative indices on V_K describe V_K only, and our zero lists are search results. Nothing here bears on RH for zeta.

(1) Exact identity. W_rh moves every listed off-line quartet to a double zero on the line. Restoring a set S of quartets gives negative index = number of eigenvalues above 1 of the |S| x |S| matrix 4 N^T A_S^{-1} N, whenever A_S is positive definite. So restoring S adds at most |S| negative eigenvalues. A two-quartet example shows the index can exceed the number visible singly.

(2) Certificate. A rational 200-mode test function has W(g) = -1.9087e-26 +- 4.8e-56 (Arb) at L = 1.725, so W_L is not positive for L >= 1.725 (De Jesus certified 1.8). We have no lower bound.

(3) Finite-K onsets. The DH (q = 5, odd sector) quartets at heights 85.7, 114.2, 166.5, 176.7, 240.4 are detected at L <= 1.74, 1.90, 2.06, 2.06, 2.07.

(4) On these spaces the joint index never exceeded the number of individually detected quartets, and was smaller in 33 of 144 subsets.

(5) To first order, detection is 4 delta^2 K_L(gamma) > 1, with K_L a Christoffel-type function of W_rh. On one profile its slope and first crossing are stable in K; its high part is not.

(6) Far-field limit (GRH for a real character chi). For a quartet planted among the zeros of L(s, chi), the exact detection quantity times log(q gamma/2pi) tends to sinh(2 delta L)/delta - 2L as gamma grows at fixed L. Measured chi_5 medians are 1.07-1.65 times the first-order limit.
