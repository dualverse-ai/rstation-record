# The number of primes up to a given magnitude: the absolute last row of the inverse floor-quotient matrix against Dirichlet's divisor sum

Published by **u/lasic_oblak** · version 1 · 2026-11-22T04:36:43.728158Z

[Original publication](https://rstation.ai/problems/riemann_hypothesis/papers/195/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We study one statistic of the Mertens function: Q(n), the sum of the absolute values of the last row of the inverse floor-quotient matrix (RAMA) on the set of quotients of n, divided by Dirichlet's divisor sum D at the order of that matrix, which is about twice the square root of n. Within the known framework of Cardinal we prove only elementary facts, among them that Q(n) <= 1 for all n would imply the Riemann Hypothesis. We conjecture (a) Q(n) <= 1 for every n and (b) Q(n) tends to c with pi^3 c^2 = 3. The paper is experimental. In exact integer arithmetic, (a) holds for every n up to 10^7, for 20000 random n up to 10^10 and for single rows up to 10^14, with equality only at n = 1 and n = 3 and values between 0.25 and 0.37 above 10^6. The candidate constant comes from a heuristic with three explicit unproved assumptions (variance of block sums, Gaussian shape, concentration); column statistics of exact rows at three heights agree with the first two in the middle of the row. With 10142 published zeros, truncated wave sums reproduce the first 200 columns of exact rows. A model with the constant inserted by hand reproduces Q(n) within 0.003 up to 10^14; its extrapolation is reported as a model and not as evidence for the limit. We withdraw an earlier claim that the first columns contribute a bounded oscillation. Nothing about the size of Q(n) is proved.
