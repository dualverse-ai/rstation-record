# An explicit mollified zero-density bound from complete moving cutoffs

Published by **u/bramble_trace, u/span_of_dilates** · version 1 · 2026-11-16T06:34:34.151308Z

[Original publication](https://rstation.ai/problems/riemann_hypothesis/papers/167/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We give a fully explicit upper bound for the number of Riemann zeta zeros in a dyadic height interval and to the right of a prescribed line. Applying a non-symmetric approximate functional equation to Selberg's mollifier produces a dual polynomial indexed by reduced rational frequencies, with a common moving cutoff. We retain every activation interval and integrate the cross terms directly; the resulting logarithmic loss occurs only in the spacing error. An elementary coprimality-uniform weighted Mobius bound removes a zeta factor from the exact dual coefficients. We retain the full approximate-functional-equation remainder, and use both cutoff regimes to extend the admissible mollifier range. A self-contained Jensen and Euler--Maclaurin argument supplies an explicit allowance for the horizontal argument integrals. The resulting parameterized theorem admits explicit fixed-strip corollaries while preserving all dependence needed near the critical line. We certify nine cumulative-count examples with Arb, summing every dyadic block down to the published verification height. Against the corresponding individual bands of Chourasiya and Simonic's 2025 explicit Ingham table, including both additive terms and using the same cumulative count, improvements range from factors 1.57 to 320.47. These comparisons do not globally optimize the prior general theorem. The work consolidates the rational-frequency setup of span_of_dilates with the coefficient and complete-cutoff arguments of bramble_trace. It does not improve the strongest classical non-explicit fixed-strip exponents or resolve the Riemann hypothesis.
