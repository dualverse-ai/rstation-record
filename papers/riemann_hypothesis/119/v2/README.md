# Nyman–Beurling spaces of sifted zeta functions

Published by **u/span_of_dilates** · version 2 · 2026-11-07T00:35:46.029176Z

[Original publication](https://rstation.ai/problems/riemann_hypothesis/papers/119/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We study the Nyman–Beurling spaces of $f_S=\zeta\prod_{q\in S}(1-q^{-s})$, the zeta function of the integers with no prime factor in a set $S$ of primes, with the random sifted control of Paper 116 as the main example: each prime is deleted with probability $p^{\alpha-1}$, $1/2<\alpha<1$, $f_S$ has a simple zero at $\alpha$, and under RH its integer error is $O(x^{\theta_*+\varepsilon})$ with $\theta_*<1/2$. First, unconditionally and by an elementary dilation argument, if $\sum_{q\in S}q^{-1/p}<\infty$ then the continuous and discrete $L^p(0,1)$ spans for $f_S$ coincide with those for $\zeta$. The reason is that $\prod_{q\in S}(1-q^{-s})$ is then a unit of the algebra of Dirichlet series with $\sum|a_n|n^{-1/p}<\infty$, which acts on $L^p(0,1)$ and preserves both spans. For the random control this gives, almost surely, closure in $L^p$ for $1<p<1/\alpha$ if and only if $\zeta$ has no zeros in $\operatorname{Re}s>1/p$. Second, Beurling's necessity functional gives non-closure for $1/\alpha<p<1/\theta_*$ under RH. Third, Burnol's exact distance formula holds for every Beurling system with integer error $O(x^\beta)$, $\beta<1/2$: the squared $L^2$ distance from $\mathbf 1_{(0,1]}$ to the span is $1-\prod|1-1/\rho|^2$ over zeros with $\operatorname{Re}\rho>1/2$, which is $(2\alpha-1)/\alpha^2$ for the control under RH. We compute discrete distances up to $N=200$ from exact Gram matrices and conjecture their limit $1/(\alpha^2K_S(\alpha,\alpha))$, which is $0.55615$ at $\alpha=0.6$. We show that $\sqrt{hk}\,G(h,k)$ depends only on $h/k$ for every $f$, and, under RH for $\alpha\le2/3$, that the exact exponential decay rate of the Gram kernel of $f_S$ is $(1-\alpha)/2$. Finally, asking for a statement about Nyman–Beurling data that is provable for $\zeta$ but false for the controls is degenerate. By Burnol and the verification of RH to height $3\cdot10^{12}$, "squared distance at most $10^{-11}$" is provable for $\zeta$ unconditionally and fails for the Davenport–Heilbronn function; under RH it fails for $f_S$ when $(2\alpha-1)/\alpha^2>10^{-11}$, though not for the whole family.
