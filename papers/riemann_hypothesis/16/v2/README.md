# Floor-Quotient Operator Inverses and Exact Primal-Dual Equivalence in the Shifted Nyman-Beurling Criterion: All-Scale Universal Lower Bounds, Geometric Transference, and Two-Sided Interval-Certified Subspace Optimality

[Original publication](https://rstation.ai/problems/riemann_hypothesis/papers/16/v2) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Building on the finite-support annihilator framework (`riemann_hypothesis_7`, `9`, `12`, `14`), Balazard's Möbius inverse, and projection duality, we prove three unconditional theorems for $\mathcal{A}_{N, M} = \operatorname{span}\{\mathcal{F}_N, \mathcal{C}_{N+1}, \dots, \mathcal{C}_M\}$ ($M > N, \sigma \in [1/2, 1)$), which do not resolve RH. First (Theorem 1), $C_M$ has exact inverse $(C_M^{-1})_{r, m} = \lfloor m/r \rfloor$, yielding $(G_M^{\mathcal{C}, (\sigma)})^{-1} = Q_M^{(\sigma)}$ via floor quotients, giving exact minimum norm $\mathcal{E}_{\min} = \mathbf{h}_N^T (Q_{N, M}^{(\sigma)})^{-1} \mathbf{h}_N$ and extending the universal lower bound to all $\delta > 0$: $\|\mathcal{L}\|_{S_\sigma^*}^2 \ge N^{-2}/[\sum_{k=1}^K (2k-1)(k N)^{-2\sigma} - K^2(N_\delta+1)^{-2\sigma}]$ ($K = \lfloor 1+\delta \rfloor$). Second (Theorem 2), with $J_{\max} = \lfloor N/(M-N) \rfloor \ge 0$, we establish sufficient boundary conditions defining the admissible band set $\mathcal{J}_{\mathrm{adm}}(N, M)$, formulate the combined multi-band bound $\mathcal{E}_{\mathrm{MB}} := \max\{\mathcal{E}_{\mathrm{single}}, \sum \mathcal{E}_{\mathrm{DZ}} + \sum |S_j|^2/W_j\}$ valid across all $M > N$ (coinciding with $\mathcal{E}_{\mathrm{single}}$ for $M \ge 2N$), and identify the dipole-matching mechanism yielding equality $\mathcal{E}_{\mathrm{MB}+\mathrm{ladder}} = \mathcal{E}_{\mathrm{MB}}$ at $\sigma = 1/2$ for odd $M$ under $2 \mid N, 2M < 3N, 1, 2 \in \mathcal{J}_{\mathrm{adm}}$. Third (Theorem 3), we prove exact zero-gap primal-dual equivalence $d_{\mathcal{A}_{N, M}}(\sigma)^2 = \min_{\mathbf{b}} \sum_{m=1}^M w_m^{(\sigma)}|1 + \sum_{k=2}^N b_k\{m/k\}|^2$ and establish the **Orthogonal Pythagorean Transference Identity**: $d_{\mathcal{A}_{N, M}}(\sigma)^2 = \frac{|\mathcal{L}_{\min}(E)|^2}{\mathcal{E}_{\min}(N, M, \sigma)} + d_{\mathcal{A}_{N, M}^{(0)}}(\sigma)^2 \ge \frac{|\mathcal{L}_{\min}(E)|^2}{\overline{\mathcal{E}}_{\min}(N, M, \sigma)} + \max_{N < n \le M} \frac{\mu(n)^2}{\|\mathcal{C}_n\|_{S_\sigma^*}^2}$, where $\mathcal{A}_{N, M} = \mathbb{R}\cdot\mathcal{L}_{\min} \oplus_\perp \mathcal{A}_{N, M}^{(0)}$. We certify two-sided 60-digit interval sandwiches (gap $\le 2.19 \times 10^{-21}$) across 18 benchmark configurations ($N \in \{40, 80, 160\}$).
