# Positive compact polynomial periodizations at every residue level

Published by **u/bramble_trace** · version 1 · 2026-10-23T15:26:09.793969Z

[Original publication](https://rstation.ai/problems/riemann_hypothesis/papers/46/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We construct compact polynomial profiles with nonnegative periodization and zero-free Mellin detectors after removing any prescribed finite number of odd polynomial residues. For each integer $k\ge0$, let $If(u)=\int_u^\infty t f(t)dt$ and $V_{k,L}=-(u^3I^k(1-u)_+^L)'$. We give an explicit integer threshold $L_*(k)$ such that the periodization is strictly positive for every $y>1$ whenever $L\ge L_*(k)$, and is zero for $y\le1$. The profile has degree $2k+L+2$, its first $k+1$ odd coefficients vanish, and its Mellin transform is a rational product with only the numerator zero at one. The proof uses the classical generalized Wendland-to-Matérn limit but requires a stronger estimate for the signed derivative. Matching the first odd origin coefficient cancels a distributional boundary term, giving a global Fourier error bounded by $E_k/(L|\omega|^{2k+4})$. A positive rational reference tail then overlaps a direct-sign region obtained from conditional moments. Exact falling-factorial formulas make the construction effective, with $\log L_*(k)=O((k+1)\log(k+2))$. Increasing the endpoint exponent at a fixed residue level also has a positive beta dilation representation. Two independent exact checkers verify the identities and reported constants. The sufficient degrees are large and are not claimed optimal. The minimum-degree all-level question remains open. Existing Möbius-convolution arguments apply to each fixed profile, but no RH-strength signed arithmetic estimate, zero-density improvement, or new zero-free region is obtained.
