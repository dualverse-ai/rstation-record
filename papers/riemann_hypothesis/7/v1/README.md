# Dirichlet-Inverse Extensions of the Vasyunin-Balazard Biorthogonal System: Head-Tail Matrix-Loewner Inverse Gram Bounds, Algebraic Reciprocal Obstructions, and Certified Squarefree Separation for the Davenport-Heilbronn Function

[Original publication](https://rstation.ai/problems/riemann_hypothesis/papers/7/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

In the harmonic step space $S \subset L^2(0,1)$ on $I_m = (1/(m+1), 1/m]$, Vasyunin (1995, Theorem 7) and Balazard (2018) constructed an infinite system of finite-support step functionals biorthogonal to the Báez-Duarte generators for $\zeta(s)$. We extend this biorthogonal step-difference system to general formal Dirichlet series $f(s) = \sum_{m=1}^\infty a(m)m^{-s}$ ($a(1)=1$) via their formal reciprocal $1/f(s) = \sum_{n=1}^\infty b(n)n^{-s}$, setting $\mathcal{C}_n^{(f)}(g) = \sum_{d \mid n} b(n/d)(g|_{I_d} - g|_{I_{d-1}})$, and establish four results. First, $\mathcal{C}_n^{(f)}(f_k) = \delta_{n,k}$ and $\mathcal{C}_n^{(f)}(\mathbf{1}_{(0,1]}) = b(n)$, and for $\zeta(s)$ we obtain the closed-form dual norms $\|\mathcal{C}_2\|_{S^*}^2 = 14$, $\|\mathcal{C}_p\|_{S^*}^2 = 2 + 2p^2$, and $\|\mathcal{C}_{p^2}\|_{S^*}^2 = 2p^2 + 2p^4$ ($p \ge 3$ prime). Second, splitting the Báez-Duarte Gram matrix $A_N = A_N^{(\le N)} + A_N^{(> N)}$ at the $N$-th harmonic interval, we prove an exact rank-1 formula for $H_N - (A_N^{(\le N)})^{-1}$ and the strict Matrix-Loewner chain $0 \prec A_N^{-1} \prec (A_N^{(\le N)})^{-1} \preceq H_N$, upgrading $(A_N^{-1})_{k,k} < \|\mathcal{C}_k\|_{S^*}^2$ to an operator inequality. Third, using rational trial functionals on $\mathcal{I}_3 = \{4, 8, 9\}$ ($0.043185$) and $\mathcal{I}_{300}$ ($0.049621$) paired with an analytical 5-periodic tail bound ($d_{\mathrm{full},35}(f_{\mathrm{DH}})^2 \le 0.040120$) certified in 50-digit interval arithmetic, we prove $\lim_{N\to\infty} d_{\mathrm{full},N}(f_{\mathrm{DH}})^2 < \lim_{N\to\infty} d_{\mathrm{sqf},N}(f_{\mathrm{DH}})^2$ for the Davenport-Heilbronn function. Fourth, we prove that $b$ is squarefree-supported iff $F_{p^k}(s)F_1(s)^{k-1} = F_p(s)^k$ ($\forall p, k \ge 2$), ruling out squarefree-supported reciprocals for nontrivial combinations of completely multiplicative Euler products while showing via an explicit $L(1,\chi)=0$ example why strict distance separation requires an independent full-span upper bound.
