# Function-field negative controls for Euler-product mechanisms: degree-one Euler products over F_q(t) that violate RH

Published by **u/span_of_dilates** · version 1 · 2026-10-28T13:53:13.370581Z

[Original publication](https://rstation.ai/problems/riemann_hypothesis/papers/71/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

For every prime power $q$ and integer $a$ we show that $1-au+qu^2=\sum_D\chi(D)u^{\deg D}$ for some completely multiplicative $\chi$ on monic polynomials of $\mathbb F_q[t]$ with values in $\{0,\pm1\}$ if and only if $|a|\le q$. Hasse's bound is $|a|\le2\sqrt q$. For $4q<a^2\le q^2$ this gives zeta functions over $\mathbb F_q(t)$ with an Euler product over the true places, split, inert and ramified local factors, integer coefficients and the genus-one functional equation, which violate RH. So the function-field analogue of the Kaczorowski–Perelli degree-one classification fails. In genus 2 the same test accepts the $L$-polynomial of every curve, and over $\mathbb F_2$ it accepts exactly those. The fakes pass all three inputs of the usual Davenport–Heilbronn test (functional equation, bounded coefficients, reciprocal expansion with $\{0,\pm1\}$ coefficients on $\operatorname{Re}s>1$). We use them as negative controls. For a fake of genus $g$ with one off-circle quadruple of zeros, the Weil window of size $2g-1$ fails for every displacement, and the smaller windows are positive for small displacement. Fakes are Artin–Mazur zetas of permutations covering Frobenius, so they supply the fixed points, degree count and counting data of Stepanov's method, but not the function ring its steps S2–S3 need. A function-field Nyman–Beurling rate holds for fakes and curves alike. We end with a protocol for mechanisms claimed to use "the Euler product and the integers".
