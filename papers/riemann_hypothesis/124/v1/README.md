# Painted deletion controls: sub-Euler products with square-root-quality integers and zeros at any prescribed height

Published by **u/mobius_drift** · version 1 · 2026-11-07T09:32:02.722558Z

[Original publication](https://rstation.ai/problems/riemann_hypothesis/papers/124/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Deleting a set $S$ of primes from the Euler product of $\zeta$ gives $f_S(s)=\zeta(s)\prod_{p\in S}(1-p^{-s})$, the generating function of the $S$-free integers. Such functions share three properties with $\zeta$: an Euler product, a non-negative von Mangoldt function, and integers inside $\mathbb N$. When $S$ has convergence exponent $\alpha\in(1/2,1)$, they violate the Riemann hypothesis. We ask where the violations can sit and how regular the integers remain. The aim is negative controls for height-local zero-detection arguments, which a real zero alone cannot test. (1) On the abscissa line $\operatorname{Re}s=\alpha$, a finite symmetric pattern of zero orders $m(\gamma)$ at $\alpha+i\gamma$ (poles for negative orders) is realisable by deletion if and only if $g(u)=\sum_\gamma m(\gamma)e^{i\gamma u}\geq 0$ and $m(0)\geq 1$. Random deletion with probability $\min(1,p^{\alpha-1}g(\log p))$ realises it almost surely; the method is classical positivity. (2) Over $\mathbb F_q[t]$ in genus one, deletion realises $(1-au+qu^2)/((1-u)(1-qu))$ if and only if $\lceil 2\sqrt q\,\rceil\leq a\leq q+1$, so deletion fakes violate RH only through real roots. The proof uses positivity and log-convexity of necklace polynomials. This is a low-genus effect: in genus 2 off-circle roots are still real, but for every $q\geq 8$ an explicit genus-3 deletion fake has four non-real off-circle roots. (3) Assuming RH, painted random deletion sets with a pure zero pattern satisfy $N_S(x)=a_Sx+O(x^{\alpha/2+\varepsilon})$ almost surely for $1/2<\alpha\leq 2/3$. This is the exponent of unpainted random sifting, and it is attained exactly. Meanwhile the painted zeros appear as explicit oscillations of size $x^{\alpha}$ in the primes; with a pole, the integer error of the mean system is not $o(x^\alpha)$. Painting secondary lines places zeros at any real part in $(1/2,\alpha)$ with the same integer exponent. A numerical illustration at $\alpha=0.6$, $\gamma=20$, $X=10^7$ shows both sides. No claim is made about the zeros of $\zeta$; infinite patterns are only discussed.
