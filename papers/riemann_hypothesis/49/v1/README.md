# Shifted-Legendre Rodrigues–Beta Projections, Delayed Bernstein–Beta Spline Decompositions, and Positive Ward–Ramanujan Inversion in Nyman–Beurling–Báez-Duarte Space

We establish four constructive theorems governing polynomial tapers and Mobius-dual tau_k Gram geometry in the Nyman-Beurling-Baez-Duarte (NBBD) and Bettin-Conrey-Farmer (BCF) approximation programs. First, for f_{m,r}(u) := u^{m-1}(1-u)^r/(m-1)! (1 <= m <= r), we prove the Shifted-Legendre Rodrigues-Beta Decomposition (Theorem 1): the first m shifted Legendre projections <D^m f_{m,r}, P_n^*> equal (-1)^{n+1} for 0 <= n < m, so D^m f_{m,m} is the L^2(0,1)-orthogonal projection of D^m f_{m,r} onto P_{m-1} with norm m^2, while excess modes m <= n < r obey a closed-form alternating Beta sum with c_{m,m+1} - m^2 = m^2/(2m+1). We also diagonalize the prefix-clamped minimum c_m(b) (0 <= b < 1) via shifted Legendre polynomials on [b,1], proving c_m(b) - m^2 = m^2(m-1)^2 b + O(b^2) as b -> 0+, lim_{b->1-} (1-b)^{2m-3} c_m(b) = 4(m-1)^2 C(2m-3,m-2)^2/(2m-3) (m >= 2), and the Cramér-Chebyshev prefix identity with sum_{j>=1} delta_j^{(0)} = log(2*pi) - 1 - gamma. Second, for the delayed incomplete-Beta spline w_{k,b}(u) (Theorem 2), (1-v)Q_k(v) is the midpoint truncation of 1-v in the degree-(2k-1) Bernstein basis with a two-term Bernstein-dipole second derivative, yielding c_1(w_{k,b}) - 1 = (1-b)(k-1)^2 C(2k-2,k-1)^2/((4k-3)C(4k-4,2k-2)) and an intrinsic Bernstein base B_{1/4}^{Bern} = 125/9 (reducing 200^2 by 207.36x per order k). Third, in the Mobius-dual basis tau_k (Theorem 3), higher-order rho_m-tapers suffer a Primorial Mertens-Lag collapse to 0 along k = prod_{p<=x} p, N = kx, whereas tau_k-prescribed Euler tapers invert via the Positive Ward-Ramanujan Identity. Fourth, on the dyadic octave N < k <= 2N (Theorem 4), we prove the Orthonormal Mother-Wave Box-Indicator Isometry for delta_j := j*rho_j - (j-1)*rho_{j-1}, the unweighted l^2(Z_{>=N}) decomposition on ell^perp, and O(N) banded-Cholesky + rank-2 Woodbury inversion of M_N(alpha_N) = L_N + alpha_N P_N, benchmarked across N in {10,...,320}.
