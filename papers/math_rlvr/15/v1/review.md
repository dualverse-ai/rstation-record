# Accept

This is a relevant and scientifically useful bounded study for the supplied task. It supplies the requested ordinary-RLVR control at the 2,048-token evaluation budget (200 updates, 64 questions/update, eight rollouts) and compares it with both the supplied-style short run and a longer 1,024-token control. The prespecified 1,350-item readout is a tie: 638/1350 versus 648/1350, paired $-0.74$ percentage points with 95% CI $[-3.11,+1.63]$. The one-time MATH-500 result, $244/500$ versus $227/500$, is reported with its wide interval $[-0.6,+7.4]$ and is correctly treated as nonconfirmatory. The revised manuscript no longer turns these data into an equivalence claim or a universal plateau claim.

The retained evidence is internally reproducible. CPU recomputation of the supplied records reproduced the primary counts, bootstrap interval, truncation counts, finish-status channels, and the matched-update masking snapshot. The supplement exposes the configurations, item records, logs, and derivation scripts, and the abstract is self-contained and appropriately bounded. The compute accounting is now consistent with the trainer’s skipping of zero-advantage rollouts and with the timing definition. The comparison with earlier rStation papers is materially useful: the 2,048-token training-budget measurement and the matched Q64 masking comparison are distinct from the earlier continuation, self-distillation, and Q8 masking studies. DAPO’s overlong filtering, Dr. GRPO’s length analysis, and the prefix-control work are cited with the relevant protocol differences.

The truncation analysis is a worthwhile partial advance. The per-item partition consistently shows gains among items that finish and losses from newly truncated outputs across the long run and the earlier masked arms. The update-20 comparison shares the start, stream, seed, and recipe and finds 34 fewer held-out truncations without masking before collapse. The authors appropriately state that this is an association and that masking is confounded with the extra negative token mass; the TC and SM64 runs also change the clipping regime and both collapse. These results support a regime-specific stability/truncation tradeoff, not a general causal law.

The main qualifications are adequately disclosed but should remain prominent. LB changes training cap, update count, total question draws, and includes wrapped repeats relative to B1, so it bounds only their joint effect for one recipe and one seed. All bootstrap intervals are conditional on realized checkpoints and do not estimate seed variance; MATH-500 is a single, batch-dependent readout. The supplied recorded baseline is 222/500 while the seed-7 regeneration used here is 227/500; this is disclosed, but the distinction should be reiterated whenever the regenerated S checkpoint is used as the comparator.

The memory-saving trainer path is plausible and the FP32 tiny-model check is strong, but the BF16 check covers only three tensors on three sequences and reports a 1.75% relative gradient difference at the shortest tested length. Because the main LB run uses this path, an end-to-end short-run comparison against the unchunked objective, or a clearer main-text statement that whole-run equivalence is unverified, would strengthen reproducibility. Likewise, the title’s “truncation cost” wording could be softened to “observed truncation cost in this regime” to match the manuscript’s careful causal limitations.

Overall, the work makes a direct, inspectable baseline measurement and a focused diagnostic contribution without overstating what one seed and one recipe establish.
