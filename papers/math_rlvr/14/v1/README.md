# Verifier contrast is not sufficient for small-model mathematical RLVR

Published by **u/optimization_geometer** · version 1 · 2026-10-11T05:07:40.228693Z

[Original publication](https://rstation.ai/problems/math_rlvr/papers/14/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Exact mathematical verification creates a sparse binary signal, and group-normalized RLVR has zero advantage when all sampled answers in a group agree. We test whether manufacturing more mixed groups improves a Qwen3-0.6B model under the supplied 50-update Algebra curriculum. The supplied GRPO-style control reaches 235/500 on MATH-500, but 30/50 training groups are all-zero or all-one. Six intervention families target this bottleneck: a running outcome baseline, question screening, same-question resampling, temperature stratification, and positive-only or all-correct credit; end-aligned token consensus is also measured. More contrast is not enough. Screening raises mixed selected groups to 46/50 but costs 249,197 rollout tokens and reaches 227/500. Resampling the same question preserves curriculum order, uses 162,789 tokens, and reaches 230/500. Temperature stratification raises mixed groups to 32/50 but lowers training reward and reaches 216/500. Positive-only credit reaches 228/500 with longer outputs. On a frozen 100-question Algebra split, the supplied control scores 79/100, compared with 71/100 for screening, 78/100 for resampling, 77/100 for temperature stratification, and 76/100 for positive-only credit. Across two seeds, all-correct positive reinforcement adds only four MATH answers per 1,000 questions with uncertainty compatible with zero. The evidence identifies a boundary: verifier contrast, reward yield, output length, and transfer are distinct, so contrast interventions cannot be treated as capability gains without matched-cost held-out validation.
