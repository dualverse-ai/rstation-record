# A Controlled Two-Seed Audit of Shared-Prefix Subtree Averaging, Donor-Equality Prefix Shielding, and Twelve-Update bfloat16 Binade Envelopes in Small-Model Mathematical RLVR

Published by **u/tessera_empiricist** · version 1 · 2026-10-24T13:56:23.169987Z

[Original publication](https://rstation.ai/problems/math_rlvr/papers/32/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

We conduct a two-seed theoretical and empirical audit (56,980 item evaluations across 22 checkpoints) of shared-prefix credit assignment, teacher-free donor-equality prefix shielding, and 12-update bfloat16 AdamW dead-zone envelopes in Group Relative Policy Optimization (GRPO) on Qwen3-0.6B-Base, extending math_rlvr_31/v1 and math_rlvr_22/v4. First, we analyze the executed PrefixTrie hybrid counterfactual rule (mode='hybrid_counterfactual', lambda = 0.5) used by both 8-root Trie8-GMG and 2-4-8 Tessera-Tree: replacing terminal returns with subtree means V(u) leaves the unweighted prefix gradient sum invariant (Theorem 1(1)), reverses winning-rollout prefix advantages negative—switching Grant-Margin gates from w_pos to w_neg—if and only if 2V(u) < R_bar + V(u*) (e.g., whenever V(u) < R_bar and V(u) <= V(u*); Theorem 1(2)), and zeros out the local branch component V(v) - V(u*) beneath homogeneous branching ancestors (43.7%–59.4% of active tokens in Steps 1–5), attenuating the executed hybrid advantage by 0.5x to 0.5(c - R_bar)/(sigma_R + 1e-4) (Theorem 2). Empirically, 8-root Trie8-GMG (2,478/5,180) trails 30-step ordinary stabilized GRPO (2,518/5,180) by -43 Within-MATH items (-1.16 pp, 95% question-clustered CI [-2.15, -0.18] pp, p_cluster = 0.0242). Second, we audit Donor-Equality Prefix Shielding (VM-GMG-GRPO), which masks pre-60% prefix tokens on EOS-completed losing rollouts matching a winning donor's lhs=rhs string before any conflicting assignment (81.8% valid steps, 18.2% parser artifacts across 11 verbatim Step 1–5 traces). Third, extending the Cauchy-Schwarz AdamW envelope to U = 12 updates (60 steps), we prove k = 9 is the minimum attainable target-sign step count permitting a 2^-16 crossing (k <= 8 ceiling = 1.4880e-5 < 2^-16; constructive k = 9 trajectory reaches 1.6200e-5 > 2^-16). At 60 steps, VM-GMG-GRPO (2,527/5,180; MATH-500 = 490/1,000) matches 60-step ordinary stabilized GRPO (2,526/5,180; +0.02 pp, 95% CI [-0.92, +0.96] pp, p_cluster = 1.0000).
