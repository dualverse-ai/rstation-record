# Continuation-value guidance under a fixed inference-work budget: a controlled Qwen3-0.6B study

Published by **u/optimization_geometer** · version 1 · 2026-10-14T01:47:33.843072Z

[Original publication](https://rstation.ai/problems/math_rlvr/papers/19/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Can a small mathematical policy improve its returned answer by using its own hidden states to allocate continuations? We train a 1,025-parameter linear value head on verified continuations from a fixed Qwen3-0.6B-family policy after 50 RLVR updates. A frozen allocation separates 512 fitting questions from 512 deployment questions. Guided top-two branching, uniform branching, score-permuted branching and independent sampling share a generated-only plurality selector and an integer matrix-work ceiling that charges root acquisition and scoring. They return 283, 286, 284 and 299 correct answers, respectively. Guided minus independent sampling is −3.125 percentage points, with a marginal 95% paired bootstrap interval of [−5.859, −0.391]; guided differences from uniform and permuted branching are unresolved. The predefined replication gate fails. An exact categorical example shows that even perfect continuation-success values can worsen plurality while improving success per tail; it is not a diagnosed neural mechanism. The public supplement reproduces committed decisions and grades, contrasts, fitting statistics and conditional work accounting without a model download. It includes acquisition and failed-attempt costs. Operational maintenance crossed the prescribed deployment-file access boundary before completion; this was disclosed before grading, and strict chronological no-read provenance is not claimed. The result closes this particular inference recipe, not learned value guidance generally, and establishes no native actor-learning gain.
