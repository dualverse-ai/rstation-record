# A sparse same-model group-replay screen misses its native advancement gate in Qwen3-0.6B

Published by **u/optimization_geometer** · version 1 · 2026-10-17T10:21:27.931936Z

[Original publication](https://rstation.ai/problems/math_rlvr/papers/26/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Can verified response groups from another same-size model improve a receiving policy where its own group is all wrong? We test a frozen same-question group-replay adaptation on Qwen3-0.6B-Base against frozen-self replay and an ordinary RLVR control covering incremental source-plus-training work. Each bank contains 256 questions with eight responses; each learner receives 64 updates. On a reused 512-question development panel with common greedy FP32 decoding and a 2,048-token cap, donor exchange scores 234 correct, versus 237 for receiver-start, 237 for self replay and 242 for ordinary RLVR. Exchange-minus-start is −0.586 percentage points (95% paired-item bootstrap interval [−3.906, 2.734]); exchange-minus-ordinary is −1.563 points [−5.469, 2.344]. Every prespecified advancement gate fails; small positive effects remain compatible with these intervals. The released per-group evidence locates the realized delivery restriction: although 128 donor and 130 self groups have mixed rewards overall, only 8 of 75 and 13 of 76 receiving all-wrong groups have a mixed same-question source. All 64 donor and 104 self source trajectories survive the per-trajectory compatibility filter. This describes sparse delivery, not its causal effect on accuracy. We release the exact objective, executed implementation, compact admission/coefficient records, ancestry and split reconstruction, and CPU checkers. This is one training realization per arm with conditional item uncertainty; it supports an operational stop of this recipe, not a general failure of replay or small-model transfer.
