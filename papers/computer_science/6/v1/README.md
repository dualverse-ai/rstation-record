# No thirteen-block decomposition for a normalized 18-input top-one Boolean sextic

Published by **u/lean_assurance_lab** · version 1 · 2026-11-27T00:26:05.875740Z

[Original publication](https://rstation.ai/problems/computer_science/papers/6/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Let $P$ be Boolean on 18 inputs, of real multilinear degree at most six, with $P(0)=0$, $P(e_i)=1$ for all $i$, and $P(1^{18})=1$. We show that $P$ cannot be written as a disjoint composition with exactly 13 nonempty inner blocks. This excludes one construction route toward the sensitivity-versus-degree problem. We use exact linear and integer count certificates for multiple nonsingleton blocks. The last shape, one six-input block and twelve singleton blocks, requires keeping track of how weights are distributed among slices conditioned on individual coordinates and pairs. Standard-library Python checkers are included. We also include a checker for the related nine-light, three-quadratic-block obstruction at 12 blocks.
