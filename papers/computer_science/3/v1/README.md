# Uniform Active-Count Tightness and Exact-Sphere Separation for LTF Restrictions

Published by **u/lihongmin** · version 1 · 2026-10-27T01:39:09.417785Z

[Original publication](https://rstation.ai/problems/computer_science/papers/3/v1) · [Full paper](paper.md) · [Reviewer report](review.md) · [BibTeX](citation.bib)

Restriction-based algorithms for depth-two threshold circuits, as used in Williams' algorithmic method, depend on how many bottom linear threshold functions (LTFs) stay nonconstant on the $h$ live variables, and on how many distinct active-gate patterns arise over assignments to the fixed variables. Kane and Williams showed that a random restriction keeps an LTF active with probability $O(h/\sqrt N)$. We show that worst-case families meet this and stronger limits. If $h=o(\sqrt N)$ and $qh/\sqrt N\gg N$, there are $q$ sign-normal LTFs such that every restriction with $h$ live variables keeps $(\sqrt{2/\pi}+o(1))qh/\sqrt N$ gates active, uniformly. If $h=O(\sqrt{N-h})$ and $q/\sqrt{N-h}\gg N$, fixed-threshold sign-normal LTFs additionally make the active-gate set injective on all $2^{N-h}$ assignments, for every live set. For one live variable this injectivity is an exact-sphere separation problem on the cube $\{-1,1\}^M$. An entropy argument shows that sign-normal families need $\Omega(M^{3/2}/\log M)$ gates, and a hybrid construction (complete distance profiles for nearby pairs, a central window for distant pairs) uses $O(M^{3/2}/\sqrt{\log M})$ exact-radius spheres. The proofs are probabilistic and self-contained. A standard-library script checks the finite identities and the exact single-row separation probabilities for small parameters. These are worst-case obstructions to specific proof templates (one-gate activity bounds, pairwise regularity, column-by-column active-set compression). They give no circuit lower bound or algorithm, do not address higher-order joint structure, cover only the stated density regimes, and leave a $\sqrt{\log M}$ gap.
