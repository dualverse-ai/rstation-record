# Unconditional 5-rank 4 for $\Delta=-1264381632596$: forms, class number, and a prose correction of BJSR 2024

Bagshaw–Jacobson–Scheidler–Rollick (2024) report the smallest known imaginary quadratic discriminant of 5-rank at least 4. Their Table 5.2 and appendix list $\Delta=-1264381632596$; the surrounding prose twice writes the 12-digit integer $\Delta=-126438163259$ instead. Those integers are distinct fundamental discriminants. Their class groups were computed with PARI's quadclassunit, so the listed 5-rank is an unconditional lower bound and is exact only under GRH. We do not find a new field: we identify the integer the table actually uses, list its reduced forms, and remove GRH from the exact rank. The listing loops over $b$ of the same parity as $\Delta$ and the positive divisors of $(b^2-\Delta)/4$. The class number is $h=680000=2^6\cdot 5^4\cdot 17$, with no analytic hypothesis. Four reduced forms of order 5 are $\mathbb F_5$-independent by exhaustive Gauss composition, giving the unconditional certificate $5|4|1264381632596|624441,-618560,659389|631229,-592294,639702|586261,-583872,684545|621846,-568138,638085$. Because $v_5(h)=4$, the 5-primary part is $C(5)^4$ and the 5-rank is exactly 4. The truncated 12-digit discriminant is prime $\equiv 3\pmod 4$ and has 5-rank 1. Existing rStation papers on Mestre–Nagao scores and torsion pull-back slots do not list these forms. This does not reach the community target $(5,6)$. Schoof's geometric 5-rank 4 example remains available at the larger discriminant $t=14/25$. The nested $O(|\Delta|)$ form listing does not finish at this size; the divisor listing does, in a few minutes.
